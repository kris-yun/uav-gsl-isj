这个结果反而把理论又校正得更严谨了。**不要补同 seed 回放，也不要重新生成配对 plume。** 我前一版把“同随机扰动配对”设成必要条件，设得过强了。

我们真正要证明的是：

\[
\boxed{
p(\tau\mid do(S=A),C)
\neq
p(\tau\mid do(S=B),C)
}
\]

其中随机 plume 扰动 \(\eta\) 应该被**积分掉**：

\[
p(\tau\mid do(S),C)
=
\int p(\tau\mid S,C,\eta)\,p(\eta\mid C)d\eta.
\]

所以 S2 和 S2X 使用**独立随机 realizations**并不是理论缺陷，反而正好是对这个边缘分布的 Monte-Carlo 采样。相同 seed 只是一种 common-random-number 方差削减技术，不是 source identifiability 的必要条件。

因此保留：

\[
\texttt{CDSI\_T01\_MATCHED\_INTERVENTION\_FAIL}
\]

作为“原配对协议失败”，但**不能据此停 CDSI**。下一步改成一个新的、独立预注册协议：

\[
\boxed{\texttt{CDSI-T0.1B Independent-Realization Information Audit}}
\]

---

### 现在三个问题也因此更精确

**科学问题**不再是“同一随机羽流里把源挪一下会不会变”，而是：

> 当随机湍流 realization 本来就不可控时，两个不同源位置是否仍诱导出统计上可区分的整条 plume trajectory 分布？

这是实际部署真正需要的：

\[
\eta_{\rm train}\neq\eta_{\rm test}
\]

仍然要定位源。

**现有方法为什么会失败**也更清楚：PMFS相当于用某个有限 forward realization / 固定模型去近似整个

\[
p(\tau\mid S,C),
\]

所以 realization/model mismatch 会被吸收到源位置上；普通 U-Net则可能直接利用训练 source prior。

**我们的方法为什么有理论希望**：不是消除某一个 realization，而是寻找在

\[
\eta\sim p(\eta\mid C)
\]

积分之后仍然存在的 source-specific distributional signature：

\[
\boxed{
P_A(\tau)\neq P_B(\tau)
}
\]

如果连这个都不存在，CDSI直接 NO-GO。

## 下一刀不用新模拟，现有64条就够

每个 context 现在有：

\[
4\times S_A
\qquad\text{和}\qquad
4\times S_B
\]

而且非 source 环境条件已经 32/32 匹配。

所以每个 context 是一个标准的：

\[
4\text{ vs }4
\]

独立 two-sample problem。

这里反而**不能再做 sign-flip**。正确 exact null 是：

> 在8条 realization 中，若 source 对 trajectory 没影响，则 A/B 标签可交换。

共有：

\[
\binom84=70
\]

种精确标签分配。

70种全部穷举即可。

# 我建议 primary 不再用 crossnobis，而用 Energy two-sample distance

原因很简单：我们现在不只关心均值差异。

随机 plume 下可能出现：

\[
E[\tau\mid A]\approx E[\tau\mid B]
\]

但：

- temporal structure；
- variance；
- multimodality；
- cross-time dependence

不同。

Energy distance 检验的是整个分布：

\[
\boxed{
P(\tau\mid A,C)
=
P(\tau\mid B,C)
?
}
\]

只要两个分布不同，population energy distance 就大于0。

因此它比“平均 source tangent”更贴近我们现在真正的理论命题。

而且每个 context 只有4+4，完全可以做 exact 70-permutation test，不需要正态假设。

## 这里还有一个必须现在写死的限制

复核包还暴露了一个理论问题：

> 当前每个 House 的 A/B source 不仅 XY 不同，**z 也不同**。

因此这64条当前最多能证明：

\[
\boxed{
\text{不同 source configuration }(x,y,z)
\text{ 的动态分布可区分}
}
\]

不能写成：

> “二维 XY source displacement 可辨识”。

这一点非常重要。

所以 T0.1B 如果 PASS，结论只能叫：

\[
\boxed{
\texttt{SOURCE-CONFIGURATION DYNAMIC INFORMATION PASS}
}
\]

然后下一阶段才专门要求：

\[
z=\text{constant}
\]

只改变：

\[
(x,y)
\]

来证明二维 source localization。

这也回答你上一轮问的“要不要现在把 PMFS改3D”：

> **仍然不要。**

现在只是承认原数据中的 source \(z\) 是一个混入的变量。我们先证明有没有 source-configuration information；之后如果目标论文继续做二维地面/已知高度源，就必须用 fixed-z source interventions 来验证 XY，而不是把整个 PMFS立刻3D化。
