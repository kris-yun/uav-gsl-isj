# PMFS 官方基线冻结裁决与执行合同（2026-10-18）

**决定：采用作者公开源码固定快照作为方法血统，用审计过的兼容运行版作为公平主基线；论文公式重建版只作独立对照。当前公开代码版的 A2/B2 性能尚未实跑证明，不得挪用重建版的指标。**

## 1. 输入证据与确定事实

输入审计包：`PMFS_提前错误声明_时钟与B2核清_四回合原始证据_20261018_最终验收版.zip`，包含另一个 `previous_qualified_baseline.zip`。已读取其中 `核查结论_zh.md`、`independent_review/独立复核_源位置与时钟_zh.md`、`analysis/FORMULA_CONTROLS_NATIVE_CPP_READOUT.csv`、原始官方源码及源码补丁分类。

作者开源仓库 `https://github.com/MAPIRlab/GasSourceLocalization`；2024-09-18 锁定源码提交 `a8d5a764b7cbfc1d5d1887aebfe890e2c75d7533`，并非论文 30 次实验已确认使用的真实提交。

作者开源启动配置：`sourceDiscriminationPower=0.2`、`convergence_thr=1.5`（m²）、`maxSearchTime=300`（PMFS 墙钟秒）、`stop_and_measure_time=0.4`（墙钟秒）、`scale=25`、`use_sim_time=False`。作者源码的置信度使用线性 Ω：`alpha = 1-exp(-Omega/sigmaOmega²)`。实际停止只检查 `variance < threshold`，`convergence_steps` 参数未参与 `checkSourceFound()` 的判定。原代码另有矩形地图方差计算遍历错误：y 的循环上界误用 `dimensions.x`，已审计的兼容版修正为 `dimensions.y`，属于补丁，不能声称字节级原始代码未变。

论文优先重建版与之不同：`D=1`、论文 Eq.6 的 `Omega²`、声明门限 `1.0 m²`；这是研究者根据论文解读所构造的版本，未证作者的实际实验中用 D=1。

原启动配置 `useWindGroundTruth=True`，而 2026-10-18 的实际重建二回合×两案例为 `useWindGroundTruth=False`、`USE_GADEN=OFF`，实际运行 GMRF 估计风。当没有编译 `USE_GADEN` 时，该项启动布尔值并不能使算法获得真风（源码落入 GMRF 分支）。为避免对未来湖岸部署使用不可能获得的全场真值，主公平对照必须使用现实可用的风观测/GMRF，并单独注明偏离作者启动文件；真风只能进入 Oracle 对照，不能和部署可用数据的成绩直接混比。

原生离线重算：用四次论文重建版 ROS 的**固定历史和已保存候选响应**，将**两项公式同时恢复为源码**（D=0.2、线性 Ω），末态见下表。**不是新官方版 ROS 闭环跑出的成绩。**

| 原有运行末态 | 论文重建在线方差/m² | 源码两公式离线方差/m² | 源码两公式离线 Top-5% 误差/m |
|---|---:|---:|---:|
| A2 R01 update2 | 0.560741 | 8.661671 | 5.376225 |
| A2 R02 update3 | 0.090753 | 5.167700 | 4.316123 |
| B2 R01 update1 | 0.381075 | 4.578203 | 4.009206 |

四个末态均未达到开源启动文件的 1.5m² 声明门。由此只能得出同一历史上系数/公式对概率地图和停止决定具有显著影响。实际改用源码规则后，源候选细化、后续导航、观测、运行时间均可能变化；离线 Top-5% 误差不能冒充源码版线上性能。

## 3. 唯一主基线的源码、输入、运行冻结门

### A. 源码与补丁

以固定上游提交初始化只读目录；在独立分支构造 O24 兼容版；`PMFSLib.cpp` 恢复**官方线性Ω公式**；`Simulations.cpp` 保持**官方源评分**，严禁修改或添加似然因子。不要拿 P24 的已编译 ELF 直接改一个参数充当 O24。`PMFS_utils.cpp` 矩形遍历 `dimensions.y` 改动保留，但必须计入补丁并记录与字节原版差异。地图启动保护、空测量与 TF 接线、播放器接线、被动观测导出、编译依赖修改分级登记：建构/可观测技术补丁、可能影响输入轨迹的适配、科学算法改动三类。任何修改气团运动、源支持、地图、评分、阈值或单位定义的“修复”，不得默默并入官方基线。

最终记录：源 git SHA、补丁 SHA、编译命令、编译宏 `USE_GADEN`、ELF SHA256、运行时所有 ROS resolved parameters、各依赖二进制 SHA、地图/气体场文件 SHA 和 RNG 随机种子。所有新版本只允许创建新的冻结身份，不修改既有结果。

### B. 输入权限与时间

风模式主公平基线采用 GMRF（与实际 PID/局地测风所允许的数据一致），仿真全场真风不得成为免费辅助输入。导航二维地图仍为官方 0.01m PGM，经 0.25m 粗格/原生全格判自由规则；B2 真源的粗格被排除，最近合法格约 0.2483m，**不可专门解封或移动真源**。三维气体网格与二维导航搜索支持不一致作为事实报告，不能直接归因为四米错误。

保留官方混合时钟用于 O24 作者开源源血统对照：PMFS 墙钟、BasicSim 大约 5 倍速机器人钟、PID/风传感器时间戳、GADEN 帧索引分别记录。记录 `(wall_time, ros_time, physical_frame_id, frame_physical_time, sensor_query_id, consumption_window_id)` 的映射；不把所有时钟直接乘除 5。A2 播放循环首次 200 一次、此后 100..199，B2 从 500 起非循环，不将循环端点当剩余待修故障。

### C. 结果与统计

每回合保存原生成功标志、声明原因、原生搜索墙钟时间、机器人钟时间、真实源—Top-5% 距离、全概率均值误差、MAP 误差、后验空间方差、真源 1/2m 邻域概率质量、锁定源对 margin、完整候选支持、观测窗、候选模拟次数和 CPU 时间。`Success=true` 是源码定义的方差宣告，**不是**“定位准确”。

公布两种清晰分开的表：一张是原生停止规则下的真实闭环误差/成功率/成本，另一张是指定固定观测/计算预算下的源概率图和排序诊断。固定预算的 `no-stop` 影子运行必须另设标签，不可反过来称作官方原生停止成绩。

重复单位须区分机器人/预测 RNG 种子与独立气体世界。论文30次均值不能与我们在一份自建气体世界上的2次重复直接作统计等价。没有作者原始世界/随机种子，论文性能复现应继续标 HOLD；这不妨碍我们定义可重现的公开源码衍生公平 Baseline，但不能写“已复现作者0.6m”。

## 4. 分阶段实施，避免继续无目的跑大量实验

**阶段 0：不新增任何 ROS/CFD/气体世界。** 从本包取 `official_exact`、`source_runtime`、PATCH_CLASSIFICATION、4 次存储的候选图，构造 5 种身份、源码 diff 与冻结 parameter manifest；对比评分/归一化/Top-5%/方差的原生 C++ 单元与矩形地图修复，确认日志和被动 I/O 不改随机消费。确认每项补丁是否导致科学行为变化；若不可证明无影响，则显式记为适配。

**阶段 1：最少量真实官方源码版 ROS 资格测试。** 在已审核 A2/B2 世界上运行 `PMFS-O24-PORT-GMRF` 两案例，每案例先 2 次；提前冻结 seeds、起点、地图、时间、风输入、完整 ELF 和依赖；保留失败，预算和候选固定。与 P24 进行**同世界不同规则的历史事实比较**，绝不把结果假装成相同轨迹单因素因果效应。记录每次停止曲线，尤其源对排名/真源邻域质量，判断是否早停或是持续错误高概率。绝不因为误差大临时改 D、alpha、阈值、地图或播放节律。

**阶段 2：决定发布级别。** 若 O24 在该自建世界仍失效，标 `SOURCE_FAITHFUL_OPEN_IMPLEMENTATION_TESTED_BUT_PAPER_PERFORMANCE_HOLD`，围绕观测/前向一致性进行归因；别冒称论文方法原理已被证明不适用。若恢复良好，也不能据 4 次宣布论文30次复现，需在多源/独立世界下分层增加重复。进入枫树岭前首先通过地图/源支持、真实连续观测到 PMFS 代理统计、物理时间和前向数值收敛等数据资格门；在同一合格世界上比较 A、A′、A′+B。

## 6. 结论与不能越界的表述

- **已证明：** 四个固定历史中的 D 与 α 改动足以造成不同的概率收缩/早停资格；作者代码和论文公式存在差异；B2 源支持投影与时钟语义已核对。
