# 数据与代码范围

此包是用户课题的新建研究原型及证据归档。原生 PMFS、GADEN 和所引用作者代码的原有权利与许可证不因本工程改变；本包没有把完整第三方软件重新许可为本项目成果。

- `src/gsl_discrimination/` 为本轮实现；文献来源与结构适配/二次设计边界详见理论及跨领域矩阵。
- `evidence/discovery/` 是本轮独立意见、源码/数据核验收据及用户既有项目的开放 discovery 元数据。冻结独立稿保持原字节，可能使用工作区路径；发布文档提供随包映射。
- `results/control_matrix_v7_frozen/` 包含解析受控后端的原始观测与完整步骤，是 Level 1 构造资料。
- `results/ocb_static_v1/` 是真实切片的统计结果、冻结代码及协议；不重复打包私有物理数组。按固定提交与哈希运行 fetch 脚本取得授权数据。
- `docs/source/PMFS_ORIGINAL.pptx` 是用户提供的方法图底稿；可编辑新图保留其对象来源。
- 科学声明按证据分层，未将测试通过或条件证明写成原生定位增益。

GitHub 分支保存源码、方法文档、PPTX、预览和主要结果收据；数千个受控 episode 原始块与完整步骤保存在下载 ZIP，避免逐块填充仓库。ZIP 的 `SHA256SUMS.txt` 覆盖完整随包实验成员。不同介质的数据范围在 `DELIVERY_RECEIPT.json` 中明确。
