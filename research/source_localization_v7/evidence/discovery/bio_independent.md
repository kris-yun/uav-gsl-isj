# V7：计算生物学／动物行为视角的独立发现冻结稿

**冻结时间：2026-10-23 09:21 UTC（09:17 开始落稿）。范围：仅独立原始文献检索，未读取新附件或其他代理文件。**

本稿是一份可被淘汰的候选记录，不是建议立刻修改 PMFS。独立检索后保留两个不同层级的机制：**双侧时序的低阶对抗计算**与**感觉驱动的持续采样状态及退出规则**。二者分别改变测量中可用的空间时间线索、以及新测量的获取方式。没有充分证据支持任何一个直接解决当前 B4 的错高置信；在数据条件未知时，不将分数补到 7 分。

## 1. 任务解释与不可绕过的边界

已知任务事实由主代理提供：PMFS/TRO 2024 的 B4 出现错误而高置信；更好的浓度预测没有改善真源排序；五个观测允许至多一位错误时仍有平均 15.7/16 个候选相容；历史记忆、源差异生成、蒸馏已经失败。以上尚未由我读取原实验复核，因此以下是**以这些事实为条件的设计判断**。

设源编号为 S，现有五位观测为 Y，任何新增确定性特征为 Z=f(Y)。若各候选在 Y 上的条件分布几乎相同，重新编码、加记忆或重新校准不能产生此前不存在的候选区分信息。这不是说五位必然不够，而是当前测量设计和容错规则没有形成有效区分。必须检查的是：**新方法是否增加一个在候选源之间有差别、又不被传感器和环境不确定性淹没的观测通道。**

据此，以下两种实现均应直接判失败：

- 将原五位输入一个更大网络，再把更尖锐的 softmax 当成可辨识性改善。
- 让机器人更稳定地留在羽流里，只报告成功到达高浓度区域，而不检测真源在候选中的排名、被排除风险和停止错误。

检索覆盖过果蝇、线虫、小鼠、蜜蜂、蝙蝠、弱电鱼、灵长类运动补偿；选择没有预设某一动物。Nature 2026 Bee-Nav 的视觉归巢和 Nature Communications 2026 小鼠间歇嗅觉均找到，但前者主要是已知家的视觉向量修正，后者主要是感官采集边界，不足以直接成为源位置判别模块。

## 2. 候选一：环境依赖的双侧低阶滤波与方向性抑制

### 2.1 原论文、实际新意、证据级别

**Brudner et al. “Fly navigational responses exploit plume-specific odor motion and gradient cues.” PNAS 123(29), e2608896123，2026-07-14。**已读正式论文作者保存 PDF 的结果、图 2–5、讨论及方法概述；另读作者代码仓库的复现实务。正式全文原始来源 [A1]，代码 [A2–A3]。

论文比较两种实测羽流：较平滑结构与横向随机气流扰动产生的复杂结构。其任务标签是**羽流中心线在左还是右**。双侧信号和对照量的实验表明：梯度与运动线索的效用随环境变化；将与环境匹配的双侧模块放入已有迎风策略，改善模拟寻源；光遗传虚拟羽流下的步行果蝇转向与此相符。**这不是 16 个源位置的识别实验。**

2026 原创价值在于：由任务优化得到的可解释双侧时间滤波与非线性结构、羽流依赖性，以及与行为的对应。**不能把早已有之的 Reichardt 乘法减法叫作 2026 新算子。**论文也明确：一个固定的时间平均梯度／运动组合可以解释所见行为，实验没有证明动物显式在线切换两个算法。[A1]

\[
G=\langle L(t)-R(t)\rangle_T,\qquad
M_\delta=\langle L(t-\delta)R(t)-L(t)R(t-\delta)\rangle_T.
\]

\[
q(L,R)=\operatorname{ReLU}\!\left(b+\sum_k f_{1k}L_{t-k}+\sum_k f_{2k}R_{t-k}\right),
\qquad p_{\rm side}=\sigma(q(L,R)-q(R,L)).
\]

| 项目 | 原模型的实际含义 |
|---|---|
| 输入 | 左右两位置的浓度时间序列；样例间距 0.46 mm，0.5 s 历史，记录步长约 0.017 s |
| 状态 | 有限时间缓冲／滤波输出；不是候选源后验、不是长期空间记忆 |
| 计算 | 两个时间滤波器、整流、镜像相减、sigmoid；复杂羽流的延迟负瓣可抑制非偏好先后顺序 |
| 输出 | 中心线侧别概率；在导航中只影响左右转选择 |
| 对照 | 和信号无侧别预测力；纯梯度／纯运动输入检验；匹配／失配羽流；移除滤波时间不对称 |

### 2.3 代码复核带来的实用限制

作者复现说明 [A3] 写明：历史数组形状为 `(sample,30,1,2)`，通道 0 是右、通道 1 是左；滤波输入有固定的 `log(max(I-5,0)+1)` 变换。其可执行代码与稿件按字面读取的左右符号约定不同；求和还相差 0.5 倍。标准化使和项的倍数不影响 AUC，但**左右交换会改变系数与运动符号**。复现文档另指出一个已发表图的复杂羽流误差条来自原笔记本固定值，和载入数组计算的标准差不同。该事项是作者仓库说明，未由本代理运行重算。

这一发现支持一个明确动作：迁移前必须用“已知左→右运动”的校准输入验证整个链路，而不能照搬公式符号。仓库和数据入口存在；本轮未下载大羽流电影、未训练网络、未声称复现结果。[A2–A3]

### 2.4 迁移成气源候选判别：需要改变的不是网络规模

以下均为本稿设计推演，**没有原论文的气源排名验证**。

将左右量理解成两处采样点，先定义真正的测量模型：

\[
y_i(t)=b_i+\int_0^\infty h_i(\tau;\eta_i)
c(x_i(t-\tau),t-\tau\mid s_j,\psi)\,d\tau+\epsilon_i(t).
\]

这里 \(s_j\) 是候选位置，\(\psi\) 包含释放强度、流场等干扰参数，\(h_i\) 包含传感器及管路动态。历史必须跟随实际采样位置，而不能把当前位置与过去的传感器响应拼成一个伪同步观测。

可实施的最小模块是：**成对采样动作 → 低阶时序侧别证据 → 与候选位置预测的侧别关系比较 → 保留或排除候选。**它不负责更精确地预测整张浓度图。

1. 从当前相容集选择一对难区分源位置，寻找一个横风短基线，使其预期中心线位于采样点不同侧。
2. 在该基线获取同步双点短序列；若只有单传感器，采用可重复的往返轨迹，并把其非同时性显式纳入检验。不能假设往返构造了同步双鼻。
3. 计算原始差分、延迟相关及可解释滤波输出；最终使用哪个量，依据在目标流场和真实传感器带宽下的留出验证。
4. 将输出转换成**候选源的观测相容性**，而非直接输出飞行转向。一个只知道“中心线在左”的量只应排除与此矛盾的候选。
5. 仍沿同一流线、仅上下游不同的源通常不会因侧别而分开。必须增加不同位置／风向的第二个观测几何，或承认该机制仅减少横向歧义。

关键优点在于侧别算子的反对称性可以消除部分共模浓度变化；这是可检验的结构性假设。关键局限在于沿羽流中心线的多个候选可能产生相同侧别，即使测得运动方向完全正确，也不能识别源的纵向距离。

**不建议直接重新训练浓度生成器。**更小的试验是利用源标签真实可知的记录，比较同一动作下各候选的 \(G,M\) 或两滤波输出分布，检验它们在消除强度、风场与传感器参数干扰后是否仍有差别。如果没有这样的记录或可验证的高频物理模拟，先停在可辨识性假设，不制造“源差异”。

### 2.5 可迁移 C 的证据与缺口

**确认的较弱先例：**视觉方向选择性计算被用于技术运动传感／视觉伺服。IEEE ICRA 2009 的 “An explorative study of visual servo control with insect-inspired motion detector” 明确应用 Reichardt 模型 [C1]。这证明延迟的双通道方向计算能进入工程控制，但本轮只取得该旧文的原始出版摘要，尚未读全方法和实验。

**更严格判断：**这一先例不是 2026 PNAS 中训练后 MNM 的完整跨域复制，不能据此宣称新模型已有成熟 C 迁移。PNAS 自己与兔视网膜延迟抑制的比较只是机制相似性。故 C 证据记为“低阶计算家族有工程先例，精确新模块的第三领域验证缺失”。

### 2.6 最短证伪实验

在同一条真实轨迹、相同传感器、相同采样时间预算上比较五项：浓度标量；双点梯度；运动特征；最小双滤波器；二者混合。必须加入左右交换、时间反转、随机破坏双点相位关系，以及“静止传感器但人为引入异步迟滞”的对照。

评估真源排名、真源被排除概率、候选相容数、校准误差、单位真实秒数带来的相容集缩减。若时间打乱不影响排名改善，收益很可能不是气味运动；若只改善中心线分类，不改善候选缩减，应降级为导航辅助。

**独立暂评：6.1/10；保留作条件性主候选。**高分项是明确算子、2026 正式论文和可检查代码；主要扣分是目标错位、双点带宽需求、未有精确 C 迁移和未知目标数据条件。若只有五个离散位，本候选当前可落地性趋近零。

## 3. 候选二：感觉驱动的持续采样状态，尤其是退出规则

### 3.1 原论文与原始证据

**Chen, Pillow & Leifer. “State-switching navigation strategies in Caenorhabditis elegans are beneficial for chemotaxis.” PNAS 123(25), e2519999123，2026-06-17。**正式出版信息及摘要在 [B1]；细读的方法、结果、公式来自作者 2025 arXiv 原稿 [B2]。正式 PNAS 网页反复出现 cookie 页面，尚未取得最终 PDF，故本稿不默认预印本每个数字、公式编号与终稿一致。

staPAW 分出持续的转向富集 T 状态与前进／微调富集 S 状态。感觉输入同时影响进入和退出状态；观察与光遗传扰动支持这种因果关系。普通的无感觉状态转移 HMM、单状态模型、增加到三／四状态构成对照。其收益是梯度攀爬和行为解释，**没有证明在不规则湍流中对离散源位置排序。**[B1–B2]

### 3.2 输入—状态—算子—输出

以下将原稿的转移规则规范化表示，避免将符号当作已经实施的新模型：

\[
P(z_{t+1}=j\mid z_t=i,C_{\le t})=
\frac{\exp(K_{ij}*C+b_{ij})}
{\sum_m\exp(K_{im}*C+b_{im})}.
\]

\[
P(\Delta\theta,\Delta r\mid z,C)=
p_{\rm turn}(z,C,\Delta\theta_{\rm hist})P_{\rm turn}
(1-p_{\rm turn})P_{\rm steer}.
\]

| 项目 | 已读作者原稿所支持的内容 |
|---|---|
| 输入 | 沿轨迹浓度、横向浓度差、历史角度变化；扰动实验另有光刺激 |
| 状态 | 两个离散持续状态，而不是将每次转向都定义为一个状态 |
| 核心算子 | 感觉历史的线性核决定转移概率；每个状态有不同的转向／微调混合和运动分布 |
| 关键机制 | 变差时进入采样状态，变好时更可能退出；一连串转向的结束偏向好方向，无需在单次转向中保持全局方向图 |
| 原始输出 | 下一步角度和位移的条件分布；不是源位置 |
| 限制 | 互抑神经回路仅是有效模型，没有定位到真实生物神经实现 |

数据与 MATLAB 分析代码在 [B3]。原稿中的 14 Hz 轨迹、降采样以及数秒驻留时间反映线虫实验，不可直接搬成无人机控制周期。[B2–B3]

### 3.3 为什么它不是已失败的“增加历史记忆”

单纯将 T/S 加进 PMFS 后验计算不会解决现有问题。本候选唯一值得保留的迁移是**改变采样动作及停止条件**：当高置信候选无法经受一段针对性观测时，进入一个持续的验证动作，保证完成可比的观测单元，再决定是否恢复靠近。

它针对的故障是：机器人在第一次高读数时提前退出探索；每一步都重新贪心规划，未走完能区分源位置的动作；或者置信度暂时高时停止了验证。这里需要的是控制逻辑中的“完成一段探测并检测它的结果”，而不是存更多旧浓度。

但原论文的“浓度上升则退出”不能原样搬来。PMFS 已经显示浓度拟合与真源排序可以脱钩，因此无人机应把退出信号改成**候选间区分证据的增加或一次事先指定的检验完成**。这是明显的跨任务改写，不应包装成原论文已有结论。

### 3.4 一个可审计的气源版本

建议用控制器状态 \(z\in\{E,V\}\)：E 是向当前候选推进，V 是执行候选验证。V 内的一条探测轨迹可以是一段横风扫描加回访，也可以是两个不共线观测基线。轨迹选择要来自源候选的几何差异和可观测性，不能只是随机增加转弯。

**进入 V 的信号：**当前最佳候选对一个新观测产生可复现的预测矛盾；候选集合长期不缩减；或者一个高置信结论尚未经过能区分其最近竞争者的观测。只用后验熵低／高作触发不够，因为 B4 正是错误低熵。

**V 中保持：**完成实际传感器响应足以覆盖的一组测量。该保持可以是有限状态机，不需要 HMM 学习或 RL。为避免把定时状态机说成生物复现，只将其称为工程实现。

**退出 V 的信号：**在预设容错与不确定性范围内，一对关键候选的预测观测集合已被区分；或者验证动作结束但没有区分，显式转入另一个观测几何。浓度上升、高浓度命中次数增加、轨迹更平滑都不单独构成退出成功。

可以定义一个没有新神经网络的操作量。令 \(\mathcal C_k\) 为第 k 个完整测量单元后保留的候选集，\(R_k=\log(|\mathcal C_{k-1}|/|\mathcal C_k|)\)。R 仅衡量候选缩减；必须同时要求真源覆盖在独立测试中达标。若 \(R_k=0\) 反复出现，控制器换探测动作；若缩减来源于错误排除真源，则任何正的 R 都是失败。更精细的排序分数可以以后加入，但这个最小实验已经能区分“多采到气味”和“多分开了候选”。

### 3.5 第三领域 C：已读的近邻先例，不冒充精确复制

另独立找到一条可实际核查的工程链：弱电鱼等动物的运动产生时变感觉输入，进入 2025 European Journal of Control 的主动感知理论 [C2]，又进入 **2026 IEEE Control Systems Letters** 的事件相机地面机器人视觉伺服 [C3–C4]。后者在 QCar 上使用线性／二次对数亮度图样，使事件通量提供速度以及位置×速度，主动小幅运动解决静止时的不可观测性；有作者代码。

这条链支持“主动改变采样运动能恢复任务需要的信号”的工程可行性，**不是 staPAW 感觉驱动进入／退出规则的已验证迁移**。其结构化视觉图样也比自然气味场更可控。故候选二在严格 C 条件下仍缺一个精确先例，应扣分而不是用相似的‘探索—利用’术语补足。

### 3.6 最短证伪实验

固定同一个候选评分器、相同总飞行时间与距离，比较：每步重规划、固定周期探测、随机时机探测、预测矛盾触发且完成验证单元的持续探测。另比较“浓度变好退出”与“候选分开退出”。记录单位秒数候选缩减、错误排除、最佳源排名、进入 V 后从错源恢复的概率。

若所谓收益只来自更多总采样时间或更长飞行距离，状态机制不成立。若所有动作在所有候选下仍预测相同观测，则切换再聪明也无法解决不可辨识性。

**独立暂评：5.3/10；保留作动作与停止逻辑的补充候选。**它在生物因果证据和可解释控制结构上明确；当前缺口是从梯度收益转换成源判别收益、目标动作可行性、终稿方法逐项复核、精确 C 先例。不是建议重做历史记忆模型。

## 4. 两候选共同的真实时间、延迟和相关长度门槛

| 必须知道的量 | 为什么影响是否可用 | 未知时的正确处理 |
|---|---|---|
| 每条浓度记录的真实时间戳与采样频率 | 运动特征需要先后顺序；控制预算要按秒计算 | 不用数组索引冒充秒 |
| 上升／恢复曲线与进样管延迟 | 差分延迟可以伪造运动方向；驻留结束后仍可能记录前一位置 | 先做阶跃与脉冲校准 |
| 双传感器时钟差与响应差 | 左右时间不对称未必来自羽流 | 交换传感器、输入端和已知移动信号校验 |
| 采样点间距、相对运动和姿态 | 太近信号重复，太远信号无相关；自身运动改变测得的纹理速度 | 用实际轨迹重建，明确参考系 |
| 风、流动稳定性、空间相关长度 \(\ell_c\) | 决定同一结构是否能经过两点，及侧别是否有一致物理意义 | 对每种工况估计，不能默认全场一个值 |
| 浓度自相关与事件率 | 高频采样数不等于独立观测数 | 以块为单位统计，使用相关校正 |
| 真实源标签和候选间距 | 判断侧别证据是否转成源排名 | 不只以羽流命中或中心线 AUC 代替 |
| 动作权限、最大速度、停留预算 | 候选二只有可取得新观测时才有意义 | 若离线五位数据封闭，明确不可实施 |

一组仅供检查而非参数承诺的尺度关系是：基线 d 要大于定位／安装误差且不大到超过相关尺度；典型结构过境时间约 \(d/|v_{\rm relative}|\)；采样间隔、同步误差和可恢复的传感器动态必须允许分辨该时间。若传感器响应带宽远低于羽流结构频率，后端模型不能恢复已丢失的原始时序。

对单传感器往返，要求更强：往返时间、环境非平稳时间、传感器恢复时间必须一起评估。一个回访既可能是有用的条件对照，也可能已经面对不同羽流；不能默认其为‘相同气团’。

相关采样下可用经验近似 \(n_{\rm eff}\approx n/[1+2\sum_{k>0}\rho(k)]\)，但非平稳羽流不一定满足这个近似的前提。这里不指定 \(n_{\rm eff}\)、\(\ell_c\)、最小飞行秒数，因为目标数据尚未提供。
