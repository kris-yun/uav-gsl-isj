## 1. 当前判断与明确取舍

**保留当前 V7 主线，暂不把它评为已经完成的高水平创新。**有价值的研究问题已从“改善浓度拟合或重新包装记忆”变为：在实际可取得的双点观测中，哪些时空结构能区分仍然竞争的源位置，如何按物理和资源限制取得这些结构。静态试验支持这一问题值得继续，但没有支持新 M1 在静态条件下超过强联合基线。

主模块应表述为 **面向源对覆盖的物理受限镜像滤波通道选择**。辅助模块取 Nature 相对进入方向记忆，形成动态返回方向管，并以候选响应差挑选双点基线；管内无判别能力时允许管外复测。staPAW 不再占第二个主贡献，它的持续行为及退出思想只宜作为控制流程参考。这个取舍保持第二轮意见，不因当前负结果临时换题。

M1 的多通道选择、M2 的响应差几何、M3 的竞争源分配能组成一个可检验方案。三者同时存在并不自动产生三项论文贡献。能否成为主贡献，取决于在相同真实资源下是否降低错误排除、改善真源排名或减少达到同一可靠程度的成本。

### 2.2 Bio-Nav 的身份更正与有限但明确的先验约束

正确论文为 Tianyi Xu、Yizhu Guo、Zhigang Wu、Jianing Wu，*A Bumblebee-Inspired Spatial Memory Navigation Framework for Robotic Odor Source Localization*，Biomimetics 11(5):350，2026-05-18，DOI `10.3390/biomimetics11050350`。它不是 Nature 的 *Efficient robot navigation inspired by honeybee learning flights*。

PubMed 收录的原摘要与图注确认 Bio-Nav 含概率估计、短期访问抑制、长期方向参考及自适应感觉—记忆融合，并展示无显式记忆、仅短期记忆和双记忆的消融。因此，“间歇羽流下靠记忆维持方向”“用记忆避免来回搜索”本身不能成为 V7 的新颖性主张。当前 MDPI 返回 429，PMC 为验证码页，EuropePMC 合法全文接口也未返回正文；本审查不补造其公式、代码或独立测试设计。[B1]

### 2.3 npj Robotics 的实际机器人先例

Shigaki 等的 *Insect-inspired adaptive behavioral compensation strategy against olfactory sensory deficiency for robotic odor source localization*，npj Robotics 4:12，2026-02-09，DOI `10.1038/s44182-026-00080-5`，确为可读完整原论文。机器人使用双侧各三个气敏器件和主动抽气，依据触角上接触位置与当前转动情境修正搜索。室内包含算法与嗅觉完整性的组合对照；室外仅比较完整触角的传统策略与单侧触角的补偿策略，不能据此分离全部因素。作者也明确尚未检验硬件在运行中突然损坏后的自动切换。数据给出 Zenodo；代码为向作者索取。[R9]

这已经排除了“首次机器人双侧嗅觉”“首次利用气味接触和运动情境”“首次嗅觉丢失后恢复搜索”之类表述。V7 若有差异，应落在竞争源条件下的观测结构与错误排除，而非双侧硬件形式。

### 2.4 跨领域 C 链的保守用法

PNAS 的 reference 57 是 Barlow–Levick 1965 兔视网膜方向选择性原论文。PNAS 将复杂羽流下训练得到的即时与延迟反号敏感结构与该视觉计算比较。因此“视觉方向计算结构在嗅觉任务中被实际学习、检验”是合理的跨模态先例。不能把经典延迟抑制或 Reichardt 乘减重新命名为 2026 原创；也不能声称该新嗅觉模型已有 UAV 验证。原稿与第二轮已记录这一界限。[R1, R3]

## 3. M1 的具体 B′，以及它还缺少什么

### 3.1 已实现的算子与联合观测单位

对一块真实同步的双点窗口 \(W=(L(t),R(t))\)，第 \(k\) 个母结构为

\[
q_k(L,R)=\operatorname{ReLU}\left(b_k+\int f_{1k}(\tau)L(t-\tau)d\tau+\int f_{2k}(\tau)R(t-\tau)d\tau\right),
\]
\[
h_k(L,R)=q_k(L,R)-q_k(R,L).
\]

交换左右输入使 \(h_k\) 变号。偶部强度 \(E\) 保留，最终只生成一个联合符号

\[
Z_F=Q(E,h_{k_1},\ldots,h_{k_K}),\qquad
P(Z_F\mid s,m,a).
\]

其中 \(s\) 是源假设、\(m\) 是观测机制或其他已建模干扰、\(a\) 是实际双点动作。窗口原始值与派生值不能再各当一份独立证据相乘。跨窗口的同一个干扰机制也不能每次重新抽取来制造证据。

当前代码的滤波器是可解释的受限指数核族：即时指数核与延迟指数核的线性组合，配合整流和镜像差。它不是母论文自由训练得到的滤波器的精确复现，论文应称“PNAS 算子族的受限实现”。0.2、0.5、1 s 等候选尺度是代码配置，并非已有 UAV 实验确认的最佳尺度。

### 3.2 与单一中心线分类器的实际差别

每个动作先用训练世界估计联合符号分布。令

\[
\psi_{ij}(F,a)=\min_{m,n}\mathrm{JS}\{P_F(\cdot\mid s_i,m,a),P_F(\cdot\mid s_j,n,a)\},
\]
\[
J_a(F)=\sum_{i<j}\min\{\psi_{ij}(F,a),\kappa\}.
\]

从偶部开始，贪心加入使 \(J_a\) 增益最大的合法通道，达到数量上限、增益不足或源对已覆盖时停止。这一结构把目标从“左右侧别正确”改成“减少尚未区分的源对”，可以选到不同时间尺度服务不同源对。它是可执行的测量压缩和通道配置规则，不是简单更换 side-classifier 的标签或损失。

但是，JS、联合频数表、贪心选择和截断覆盖目标本身都不是新统计工具。当前实现也没有证明该目标次模、贪心最优或得到最小通道数。训练 JS 只能作为训练诊断，不能称总体可辨识性证书。最保守的算法贡献表述应是：**用物理合格的有限算子库构造源条件的联合测量，并用剩余竞争源对确定有限通道资源的分配。**

### 3.3 数据处理界限决定强基线怎样设计

确定性编码不能增加相同原始窗口中的信息：\(I(s;Z_F\mid a)\le I(s;W\mid a)\)。因此不能以“新增滤波后凭空产生源信息”为理论主张。可以检验的是：在有限校准样本、通信或计算预算下，受限联合表示是否更容易估计、更稳健，或者它是否使主动策略选到原来没有取得的新观测。

连续版本的 raw-joint 强基线必须取得**同一整块原始双侧时间窗口**。让新方法使用一秒历史，却让 raw-joint 仅用末端两个浓度值，会混淆数据增加与编码收益。若声称样本效率，应画校准世界数与错误率、校准误差的关系；若声称动作收益，应固定编码，比较动作选择。不能靠缩弱任一侧基线完成两种主张。

至少保留四类对照：同 bank 训练选出的最强单通道、预先固定的等数量通道、受控复杂度的原始联合时序模型、源对覆盖选择。使用相同窗口、相同两路传感器、相同训练世界、相同计算及查询预算。若比较自由训练的原论文滤波器，须另行明确系数估计合同与目标，不能把当前手工指数核称为已完成该对照。

## 4. 冻结静态试验究竟说明什么

原始记录：`source_localization_v7/results/ocb_static_v1/STATIC_PILOT_RESULT.json`。协议、探针选择与运行时代码快照位于同目录。以下描述的是这一次冻结结果，不是修复后重跑的数字。

| 方法 | 开发集逐快照判断正确数 | 可以支持的判断 |
|---|---:|---|
| 双点均值 Gaussian | 31/40 | 均值压缩在部分世界丢失判别所需信息 |
| 原始双点 joint Gaussian | 40/40 | 冻结双点中存在可用于区分这两个已给源的联合信息 |
| 可逆偶奇换基 Gaussian | 40/40 | 换基保留相同信息；与 raw-joint 后验最大差约 \(4.51\times10^{-17}\) |
| M1 静态联合直方图 | 31/40 | 本次新编码没有胜过强 raw-joint 基线 |

训练仅用两源各 r01/r02，开发用两源各 r03/r04。训练从 435 个探针对中按 pooled Mahalanobis 冻结原探针 12/17，距离约 7.003 m；没有用开发标签继续选探针。四个开发世界各有十张快照，因此有 **4 个开发世界、40 个相关快照**，不能报告为 40 次独立世界实验。

正证据是“应该保留并有目的地取得双点联合观测”。当前负证据是“静态 M1 的离散表示和估计没有超越原始联合模型”。两者并不矛盾。亦不能把后者自动归因于某一个原因：量化、对数变换、低样本估计及模型假设都可能相关，当前冻结实验没有逐项隔离它们。不应用已看过的开发世界逐项调到成功后再称确认实验。

其他重要资格仍缺失：快照间隔约 50 s，没有连续时间结构、局部风测量、传感器带宽标定或原生主动闭环；探针对并未取得可飞行资格；固定高度切片不是含旋翼与机载传感器的 UAV 验证；两源坐标同时有 x/y/z 差异，z 差 0.7 m，不能称纯平面源移动实验。源占据/障碍图的必要本体文件也未在这次数据资格中完成验证。

该试验没有验证 16 候选问题，没有未见源位置泛化，没有 native PMFS 同场比较，也没有证明 40/40 对应校准的高置信。准确率满分与后验可靠是两个问题。由静态两源结果外推 B4 错高置信已经解决，证据不足。

## 5. 代码审查：已完成的修复与下一版门槛

### 5.1 三项正确性修复已复读确认

1. **母机制基线公平性。**原 `mother` 固定取 bank 第 0 项，而默认第 0 项是静态梯度。当前已改为同 bank、同训练覆盖目标的最强单项选择。只有这样，多通道收益才不会来自故意弱化母机制对照。
2. **扩展字母表时的平滑一致性。**原每格相同 \(\alpha\) 使增加一个三值通道时先验总质量扩大三倍，导致边缘分布也变化。当前默认固定总 Dirichlet 质量，每格 \(\alpha/|\mathcal Z|\)，边缘化后与原维度一致；显式 `legacy_per_cell` 仅用于追溯冻结结果。此修复避免把平滑改变误当新增通道信息。
3. **非均匀真实时钟。**当前偶部与梯度使用梯形时间权重，避免将不均匀采样的帧数平均当时间平均。该修复不创造缺失的连续样本，也不能将 50 s 快照变为运动数据。

上述为前瞻的算法正确性修复。静态 pilot 的旧数字、协议和代码快照应保持原样，不用新版本悄悄替换。

### 5.2 后续门槛检查

补读确认主代理也已加入时间不确定度、滤波尺度和浓度尺度的 finite 检查，避免 NaN 绕过比较；`strictly_temporal_claim` 已改为同时要求连续资格和实际选中的非 gradient 通道。在线原生适配器仍应明确传入实际时间戳；`encode(times=None)` 只适合作为已声明时钟的重播便捷接口。本代理未改动 M1 文件。

## 6. M2 已实现的具体内容与贡献边界

M2 文件位于 `source_localization_v7/src/gsl_discrimination/m2_boundary/`，接口与公式见该目录 README。`tests/test_m2_boundary.py` 的 21 项 unittest 已通过。此结果只证明所列接口和构造性性质，不是气源定位性能验证。

### 6.1 相对方向记忆与不确定管

进入记忆保留原论文形式 \(m\leftarrow a m+b\hat v\)，其中 \(\hat v\) 是真实运动方向，不能把机头 yaw 当作穿越方向。事件必须由截至当前的稳定 off/on 历史确认，确认延迟与物理采样时刻分开。无风版仅保留进入记忆；有风版要求带时间戳的当下局部风，才允许退出初始化和上风角度门控。二者不冒称完整重现 Nature 全部状态驻留与运动模型。

返回管从**当前位置**沿 \(m/\|m\|\) 延伸。它的不确定度由定位、方向散布、记忆老化及延迟残差组成；不保存固定边界坐标，不等于一个源后验。M2 不接收真源标签，不更新源概率，记忆也不作为独立证据。该“方向管”是新工程构造，不声称原论文已经给出相同不确定性计算。

### 6.2 源响应差决定双点基线

训练或因果预测模型提供候选均值 \(\mu_s(q)\)、响应梯度 \(g_s(q)\) 与联合协方差。对端点 \(q\pm du/2\)，局部有效范围内

\[
\bar z_s(a)=\begin{bmatrix}\mu_s(q)\\(d/2)u^\top g_s(q)\end{bmatrix},
\quad
D_{ij}(a)=(\bar z_i-\bar z_j)^\top
[\Sigma_i(a)+\Sigma_j(a)+\lambda I]^{-1}(\bar z_i-\bar z_j).
\]

当前实现交出完整动作×源对矩阵、偶部差、奇部差、端点、成本及管内外诊断，M3 决定关注的竞争源对和动作分配。\(D\) 是设计分数，不是似然。固定协方差模式表示调用方明确接受同一标定适用于所给动作；也支持逐基线、方向、候选源的协方差输入。

几何门槛包括两端点合法性、基线范围与梯度局部线性化半径。返回管约束中心，端点可以横跨管边界以取得差分。若管内对当前关注源对没有判别动作而管外有，返回管外复测候选；没有管外候选时明确要求扩充动作。不会把重复回到同一无信息边界标记为源定位进展。

### 6.3 能区别普通几何规则的正反例

两源在同一中心具有相同均值，但梯度差为 \((0,\eta)\)：沿 x 取双点仍不可分，沿 y 可产生非零奇部差。旋转响应梯度差而不移动源坐标，最佳基线随之旋转。这是单元测试已验证的结构性质，区别于只依靠源坐标、上风方向或羽流中心线的规则。

若管内所有源的均值和梯度都相同，进入记忆再精确也不能让它们变得可分；应退出管或承认当前动作集不可辨识。若所有位置的真实联合响应本就相同，任何主动选择都无法完成源定位。这一反例必须保留，不能通过更高温度、更尖后验或更复杂记忆掩盖。

M2 的源响应梯度仍是模型量，不能在测试动作前读取未观测的整幅真实浓度场。完整 filaments 可用于模拟执行与离线诊断，不代表在线策略拥有未来真风或真梯度。

## 7. 使主张成立的最小实验链

### 7.1 先取得真实动态资格，不从快照插值

需要原始连续 filaments/场生成接口、源与地图坐标、原生时间戳、两采样点实际位置、同步误差、两传感器响应/恢复标定、可用的当下局部风及完整动作耗时。由训练数据估计相关时间/长度，随后冻结尺度；没有量测就不写具体最优秒数、米数、自由流传播速度或无人机延迟。大于相关时间的快照无法补回短时运动信息。

传感器门必须包含滞后不匹配：双点时间差或不同恢复速度足以产生伪方向信号。每个动态滤波器应有明确的可观测时间支持、传感器可分辨带宽及同步误差余量。关闭动态资格后应严格退化到静态结构，而非保留一个被误称 motion 的数值输出。

### 7.2 首先构造至少两种需要不同通道的真实源对

为了检验“覆盖”而非单滤波器重命名，需要至少两个不同竞争源对：某一合法时间结构能分开一对，另一尺度或结构能分开另一对，单通道在相同资源下不能同时完成。优先在已知困难布局中寻找，不能用测试标签反复筛选到成功后才定义任务。

对照至少包含：偶部、最强单项母结构、固定等数量通道、覆盖选通道、受控复杂度的整块 raw-joint 模型。所有版本共享训练/验证世界与窗口。量化和滤波参数必须训练内确定；新增数据先做事前冻结，再按完整 seed/world 留出，不随机拆同一 plume 的相邻帧。

可加入时间打乱、左右交换与传感器滞后扰动作为机制诊断，但这些不替代真实独立源条件。时间打乱应明示破坏的统计；左右交换应遵循反对称关系；时延扰动应覆盖实际测得的不确定范围。若收益只在不真实的理想传感器下存在，应收窄适用条件。

### 7.3 将 M2 的生物记忆收益与主动几何收益分开

| 比较 | 需要固定的条件 | 判定问题 |
|---|---|---|
| 普通返回方向 vs 返回管内响应差基线 | 同 memory、端点预算和观测模型 | 是否从重捕获走向源判别 |
| 全局响应差规划 vs 有方向管的响应差规划 | 同响应模型和总运动/等待资源 | 记忆是否减少到位代价，还是限制了有用探索 |
| 管内锁定 vs 管内不可分时管外复测 | 同候选库、评分器、资源上限 | 是否能恢复错误搜索方向而不盲目追踪 |
| 无 memory vs 完整 M2 | 同 M1/M3、起点、传感器与预算 | memory 本身是否有必要成为贡献 |
| 正确源响应差 vs 预先固定基线 | 同中心、距离和同步双读数 | 新观测方向是否带来额外判别信息 |

若无 memory 的响应差规划已经取得全部收益，则保留方向记忆作可选导航辅助，主贡献归于判别观测设计。若只有羽流命中率提高，而在同预算下真源排序不变，M2 不能宣称第二项源定位创新。

### 7.4 指标以错误定位和资源为中心

主指标至少包括真源排名/相容集大小随资源的变化、错误排除率、给定停止规则的错误率及到达可靠判断的成本；另报各独立世界和跨源布局表现。后验极端置信应同时有覆盖与校准检查，不能用准确率代替。时间成本纳入两平台到位、传感器恢复及实际窗口；未知时只报告确定的查询或路径预算。

需要原生 PMFS 同条件比较，才能回答原问题的 B4 错高置信是否改善。比较中应区分观测结构改变与后端推断改变；否则改动两个环节后无法知道有效机制。不得把 M3 的数学保证直接移植到相关 plume 窗口和估计误差下，必须满足条件或报告条件不成立。

## 8. 可发表门槛与停止条件

**进入强主张的条件：**连续数据与传感器资格明确；多源对确实需要不同物理合法观测；覆盖选择在同预算下稳定超过最强单项与固定通道；强 raw-joint 基线公平；响应差几何带来新增测量收益；在独立世界和干扰条件下错误高置信下降；复现代码与冻结协议可追溯。此时可主张一种面向候选消歧的测量与动作机制，并明确其在有限样本/资源下的价值。

**只能支持较窄论文的情况：**低维联合编码更省标定样本或通信，但不改善理想信息；返回管只减少航程；某些传感器带宽下运动分支失效。这些仍可成为真实工程结果，题目和结论必须对应有限贡献，不靠生物论文层级抬高评级。

**停止主机制的条件：**公平最强单通道覆盖全部源对；所谓时序收益可由传感器不匹配解释；主动几何相对同资源 raw-joint 规划没有收益；增加源或干扰后保持错高置信；现有真实场上所有合法动作仍不可分。出现这些结果应保留失败证据并缩减主张，不追加新损失、教师或记忆网络来绕开。

当前状态是“有明确可实现算子、已完成重要资格与正确性控制、主性能假说尚未验证”。静态结果既不支持将方案判为已成功，也不足以否定动态源对覆盖这个尚未执行的假说。本轮不把设计稿硬凑为 7 分以上成果。
