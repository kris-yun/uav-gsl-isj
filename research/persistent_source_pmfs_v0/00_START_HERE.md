This package is deliberately narrow.

It does **not** ask Codex to find a theory, invent a model, train a network, or decide what research should be done.

The research hypothesis and computation are already fixed:
**Does Native PMFS lose source-discriminative information because a persistent but unknown source position is re-sampled for every filament inside a quadtree leaf?**

Read in order:
1. `01_MECHANISM_FINDING.md`
2. `02_EXPERIMENT_SPEC.md`
3. `persistent_source_r1_replay.cpp`
4. `evaluate_persistent_source_r1.py`
5. `03_CODEX_EXECUTE_ONLY.txt`

Interpretation boundary:
- This is an OPEN-data development ablation.
- A positive result is evidence for a failure mechanism, not yet a main innovation.
- A null/adverse result kills this mechanism as the next main-method basis.
