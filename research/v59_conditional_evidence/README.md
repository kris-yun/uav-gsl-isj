# V59：条件取证理论、可复算实验与原生增量接口

## 先运行什么

在本目录执行 `python3 run_all.py`，运行六项新解析/实现证书。完整私有交付还可执行 `python3 run_all.py --include-v58`，重跑保留的V58原解码器、冻结fixture和局部动作反馈证书。六项新证书结果写入 `evidence/`，可选V58重跑结果写入 `prior_v58/evidence/`，过程日志写入 `run_logs/`。

依赖固定在 `requirements.txt`，本轮实际使用Python 3.12和列出的NumPy/SciPy。代码不调用ROS、CFD、网络或新物理世界。

## 研究问题

输运干扰可能决定哪次采气有判别力。即时源信息很低的准备测量，因此可能被单步评分及受限动作提案遗漏。条件策略树在未来观测的不同分支重新选择动作，能在明确的模型中解决这个失败；普通完整贝叶斯树同样能做到。

待证明的专门贡献是：体心历史提案能否在相同原始输入与全部计算成本下，更好地保留有效条件分支，并改善实际二维源定位。当前没有体心优于普通强对照的定位结论。

## 结果解释

匹配信道无误码时，条件树 `C -> G_W` 得到0.693147 nat；最佳固定两步序列和滚动单步均0.346574 nat。前者不是生物专属收益，也不是无人机定位误差减半。未匹配的气体信道仍含随机噪声。

高斯混合证书评估的是局部曲率选定方向的有限步长完整MI，不能叫有限步长全局最优。准备线索的物理时间和能量在该曲率检查中未计入；完整策略必须恢复这些成本。

预算证书只验证接口诚实性。有限信道缓存不能自动转移到非定常物理前向，各方法共享缓存的整套运行时间不能作为逐方法速度比较。

## 与原生环境的边界

解析 `C` 可观测风模式只是模型假设。原生环境必须用可执行的未来原始风/气测量证明其对历史输运模式有判别力，不能回传隐变量真值。415状态缺失的时间、风历史和轨迹不得伪造。共享前向、完整输入与实际执行未合格之前，保留诊断，暂不宣称闭环创新成立。

此包不修改冻结原生算法或终点，也不启动新House/seed。GitHub的研究目录仅分发新代码、解析结果和执行合同；真实fixture与未公开LaTeX未上传。
