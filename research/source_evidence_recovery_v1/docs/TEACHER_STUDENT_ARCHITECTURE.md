# V2 教师—学生架构与可执行接口

版本：2026-10-23。本文依据实际实现 `m1_neural/model.py`、`teacher.py`、`training.py` 与 `m1_distill/projection.py`。架构已运行；物理正确性和未见源定位增益仍须由实验合同验证。

## 1. 输入、状态与容量

| 对象 | 张量或数据结构 | 物理含义 |
|---|---|---|
| 候选源 | `s:[2]` | 连续二维坐标；不是训练源编号 |
| 静态几何 | `landmarks:[J,3]`、`occupancy:[J]` | 地形/障碍采样点及占据属性 |
| 动作序列 | `[T,5]` | x、y、z、时间、停留时长 |
| 历史观测 | `wind:[T,2]`、`gas:[T]`、`mask:[T,3]` | 已发生的局地水平风、气体及可用性 |
| 教师专用 bank | `points:[K,P,7]`、`log_weights:[K]` | 每个外生世界的 xyz、时间、三维风及先验 |
| 递归状态 | `h:[K,h_dim]` | 各传播模式自己的因果历史状态 |

学生先把“几何点相对源的三维坐标＋相对动作点的三维坐标＋占据值”组成 `[J,7]`，经两层 MLP 后平均池化。动作查询再加入相对源的三维位移、对数停留时长和相邻时间差。缺测数值不进入网络，只使用零占位与显式掩码。空几何允许工程运行，但不能因此声称已表达障碍物效应。

默认学生为几何宽度 16、查询宽度 32、GRU 隐宽 48、4 个持续模式；教师为 32、64、96，另加 32 维风场编码。在 **K=4** 时，实际实例化得到教师 **82,733** 个总参数（82,349 可训练），学生 **20,139** 个参数。教师冻结且清零的模式嵌入仍计入总参数。改变模式数或宽度会改变上述数字。

## 2. 教师知道什么，学生能使用什么

教师对每个风场点构造十维特征：相对源坐标、相对查询点坐标、三维风、时间差；用空间—时间距离 softmax 加权池化风场 MLP 输出。局地风均值直接由场插值得到，气体响应由递归概率代理学习。教师初态也接收风场编码，latent prior 来自 bank 权重；没有学习世界编号嵌入。

训练数据提供合法的世界索引 `world_index`，教师优化该原子的完整观测负 log 似然；源码称 `complete_state_nll`，这里的“完整”只表示外生世界被指明，**不表示已知全部湍流、气团或传感器内部状态**。训练源标签用于监督和条件查询，不能作为实际未知源送入在线推断。

学生没有 bank、世界索引或未来实测风场。每个候选源只接收同一合法历史、动作、静态几何与机制假设。其模式先验由源相对几何产生，随后按该源对历史的解释更新。在线加载拒绝教师 checkpoint、`NUMERICAL_ONLY` 和记录索引伪装的物理时钟；正常学生 checkpoint 可独立运行。

工程顺序是：先按传播实现划分数据，再训练教师，冻结其权重及风场 bank，生成绑定教师版本与数据哈希的训练目标，最后训练学生。续训检查数据、教师目标和优化目标身份；教师续训另保存历史曲线快照及连续训练收据。部署包只需要学生权重、几何和配置。真实源与真实世界编号只属于训练监督或环境评测器，规划请求不接受这些字段。

## 3. 归一化风—气联合分布

每个模式在一步输出七个数：水平风均值 2、标准差参数 2、气体 logit 1、对数浓度均值和标准差参数各 1。标准差通过 softplus 与正下限构造。给定模式和历史，当步水平风两分量及气体条件独立：

\[
k_j(o_t\mid H_{t-1},s,c)
=\prod_{d=1}^2\mathcal N(u_{td};\mu_{jd},\sigma_{jd}^2)
\,r_j(y_t\mid H_{t-1},s,c).
\]

二值模式使用同一数值截断后的 Bernoulli 概率评分与采样。连续模式设潜在浓度为 lognormal、检出限为 \(\tau\)、检出保留率为 \(v\)，则

\[
P(y=0)=1-v+v\Phi((\log\tau-\mu)/\sigma),\qquad
p(y)=v\,\mathrm{LN}(y;\mu,\sigma^2),\quad y>\tau.
\]

这是零点质量与连续密度组成的归一化读出，禁止把 \(0<y\le\tau\) 作为未删失数值输入。混合模式及历史递归产生跨变量和跨时刻相关性；当前实现不声称单模式 emission 已表示任意瞬时相关结构。

完整历史由持续模式混合：

\[
p_\theta(H\mid s,c)=\sum_j\pi_j(s)\prod_t k_{\theta,j}(o_t\mid H_{t-1},s,c).
\]

`log_prob` 返回上述联合 log 密度。`sample_future_batch` 先用相同历史得到每个源自己的模式后验，每条轨迹只抽一次持续模式，再逐步采样风与气体、更新同一 GRU。因此评分和完整未来采样来自同一概率法则，不是把边际检出率相乘。`sample_future` 为单轨迹包装，供 M2/M3 共用。

固定缺测掩码下，当步未观测通道不贡献密度，状态使用零占位与掩码。该模型定义的是 **给定掩码的观测数据法则**，不是把全观测 GRU 的全部潜在缺测历史精确积分；对跨时刻潜在缺测轨迹的精确边缘化尚未实现。

## 4. M1 两边缘投影与实际训练目标

对同一合法历史 \(H\) 和未来块 \(F\)，定义

\[
L_s(D)=\log\sum_j\pi_j(s)p_{T,j}(D\mid s,c),\qquad
\ell_s(F\mid H)=L_s(H,F)-L_s(H).
\]

源条件过滤权重为 \(w^D_{sj}\propto\pi_j(s)p_{T,j}(D\mid s,c)\)。完整源导数必须包含两边权重及先验导数：

\[
\nabla_s\ell_s=
\sum_jw^{HF}_{sj}\nabla_s\log[\pi_j(s)p_j(H,F\mid s,c)]
-\sum_jw^{H}_{sj}\nabla_s\log[\pi_j(s)p_j(H\mid s,c)].
\]

不把 log 混合改成混合 log，不冻结源相关 belief，也不共用真实源的气团快照。上述恒等式已知；二次创新候选是将其作为气源任务的可部署监督算子，而非声称重新发明贝叶斯或 Fisher 恒等式。

`build_targets` 只从训练源坐标取 \(a,b\)，固定训练历史和合法动作，按教师完整条件法则生成未来。它保存两个实际监督量：

\[
\Delta_T=\ell_b-\ell_a,\quad
v_T=(b-a)^\top\nabla_s\ell_s\big|_{s=(a+b)/2}.
\]

学生从自身归一化模型计算对应 \(\Delta_\theta,v_\theta\)，使用

\[
R=\tfrac12[(\Delta_\theta-\Delta_T)^2+(v_\theta-v_T)^2],\qquad
\mathcal L=\tfrac12(\mathcal L_{\rm real\ NLL}+\mathcal L_{\rm teacher\ CE})
+\lambda(R-\varepsilon).
\]

原始 NLL 与教师 CE 均按观测长度归一；证据误差按源对样本平均。截断对偶更新调节 \(\lambda\)，不是新的理论保证。路径积分与端点差用于标签审计；当前训练使用端点及中点方向，不声称已约束整条路径的最大误差。分布锚不可缺少：只有源似然比仍不能确定未来事件质量和主动信息价值。

预期作用具有明确条件：教师对不同候选源给出的条件响应必须比现有学生更可信，且合法观测仍包含源差异。若教师沿用了错误传播统计、有限世界库遗漏主要风况，证据微分也可能精确传递错误；若两源在所有合法动作下的观测法则相同，任何监督都不能创造可辨识性。有限训练误差降低只支持待检验假设，不能直接推出未见源排名提升。需要同时检查生成校准、真源相对竞争源的评分以及原本正确案例的退化。

## 5. 机制、消融与算力边界

机制按全历史索引、起点与持续时间生效。`wind_bias` 改变第一水平风分量均值；`sensor_offset` 改变二值 logit 或连续对数浓度均值，后者不是 ppm 加性偏置；`detection_loss` 改变检出保留率。未声明机制直接拒绝，不让源坐标无限吸收新故障。M2 用这些规范化法则重算后缀，诊断输出不新增似然因子。

实现的独立对照为：`nll`、`distribution`、`privileged_pair`、`mean_log`、`projected_evidence`、`projected_no_anchor`，以及 `--no-directional` 端点消融。前两者检验结构与普通蒸馏，后几者检验特权原子偏差、交换 log 与混合的偏差、正确投影和密度锚的作用。更大容量 NLL 需要单独对照，不能把容量收益归因于源证据监督；原生 PMFS 仍由外部真实基线记录代表。

若单步状态运算代价为 \(C_h\)，\(N\) 源、\(M\) 机制、\(K\) 模式的历史评分约为 \(O(NMKT C_h)\)。教师另有逐世界、逐场点编码成本；未来 \(R_f\) 条轨迹共享过滤前缀后约增加 \(O(R_fLC_h)\)。方向监督需要 \(\nabla_\theta\nabla_s\log q_\theta\) 混合二阶反传，未显式形成完整 Hessian，但计算图和显存均高于普通 NLL。

本轮实际运行环境为 CPU；CUDA 设备选择、显存份额和预算保护已实现，**没有实际 RTX 5060/3090 吞吐或显存成绩**。字段单位、世界独立性、时间支持和读出资格必须另审；哈希字符串存在仅证明元数据填写，不能自行证明物理资格。当前没有 PDE 守恒约束，没有完整 GADEN 原生无偏源导数；`require_native=True` 始终 BLOCKED。可微风场条件代理、数学单测和工程闭环不能替代真实传播验证。
