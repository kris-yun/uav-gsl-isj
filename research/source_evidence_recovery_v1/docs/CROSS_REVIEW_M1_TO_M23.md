# 第二轮交叉审核：M1 实现者审阅 M2 / M3

审核对象：`m2_replay/engine.py`、`m2_diagnosis/network.py`、`m2_diagnosis/demo.py`、`m3_codebook/`、`m3_planner/`、`pipeline.py`。这是独立代码/数学审查，未冒充真实教授或期刊编辑。以下意见已发给研发负责人，修复情况以最终审计及测试收据为准。

## 已核对正确的核心关系

1. **后缀替换**。当机制在起点前不生效且每次重算沿完整实际前缀进行，
   `base - (base-old_prefix) + (full_new-mode_prefix) = full_new`。
   当前 exact 路径真的执行这些算术并检查前缀相等，且不把上轮后验再次当先验。机制影响的后续条件因子包含在全历史重算中，不在机制持续段结束处人为截断。
2. **诊断输出没有重复入证据**。当前概率计算使用固定机制 prior 和生成模型 likelihood；预算路径只使用 `pi(e)/q(e|H,s)` 重要性修正。未归一化证据估计可无偏，有限样本归一化后验一般有偏，源码已经如此注明。
3. **零 MC 半径的容错反证 LP 正确**。`u_c >= phi_y` 对允许污染邻域所有 y，`v_c <= phi_y`；对 null 的期望上界约束误拒绝，对每个 challenger/mechanism 的期望下界约束功效。原生间歇性已经在联合软码分布里，额外翻位/擦除预算没有再把正常间歇当作错误。
4. **TV 界保守而非伪精确**。`radius * (max-min)` 是合法的期望差上界；非零半径的 LP 可能比精确 TV-鲁棒最优解保守，源码未宣称全局最优。求解后独立质量搬运重新计算 risk，进一步防止错误证书。
5. **完整块与唯一观测**。执行动作必须等于事前动作块；重复观测 ID 不能第二次作为新反证，过期模型版本拒绝检验。这是有效 alpha-spending 的必要工程条件。

## 明确反对点与修复要求

### R1 — 恢复列表最初没有影响规划（高优先级）

首次审阅时，`RecoveryList.update` 只更新日志；`_challengers` 只取全局轮转与后验排名，没有读取恢复列表。因此当时“可恢复列表规划”是未接通的表述。

**修复要求**：保留一个全局轮转挑战槽确保任何合法源不会永久失去资格；额外槽优先检查近期恢复/当前列表候选，再回退到后验竞争源。加入相同后验但恢复列表不同会改变挑战集合的测试。不允许通过永久删除非列表候选制造计算收益。

### R2 — 诊断检查点的机制类别语义未被冻结（高优先级）

首次审阅时，诊断 demo 的三类是 `[nominal, wind_bias(onset4,.9), sensor_offset(onset4,1.2)]`；pipeline 的三类是 `[nominal, sensor_offset(onset3,+1), sensor_offset(onset3,-1)]`。保存文件只有权重，推断只检查类别数量，可能把不同类别语义的检查点互用。

这不会自动破坏正 proposal 下的 `pi/q` 恒等式，但会破坏机制解释并使“诊断有效”结论不成立。

**修复要求**：检查点存 canonical mechanism catalogue 及 hash；推断严格检查类型、起点、持续时间、幅度和顺序；训练 demo 与主闭环使用同一声明目录，或拒绝不匹配的加载。新增“同类别数但不同语义必须报错”测试。

### R3 — 列表/计划版本必须包含机制目录（高优先级）

只冻结 M1 权重哈希不足以覆盖 M2 的机制解释空间改变。增加或改动合法机制会改变软码分布和兼容列表。

**修复要求**：构造推断语义版本 = generator hash + mechanism catalogue hash + corruption/readout definition；旧计划/排除证据在该版本改变时失效。若机制 prior 被用于证书，则 prior 也必须进入版本；当前 composite-null LP 对所有目录项约束，本身不依赖 prior。

### R4 — M2 的新颖性不能由 exact Bayes 后验等式充当（科学门槛）

有限机制完全枚举 + 相同规范化模型的标准 Bayes 会得到同一个后验。后缀减旧加新的算术、Bayes 归一化不构成独立原创定理。

**修复要求**：在论文贡献中把 M2 放在**源条件差分诊断分配有限回放预算 + 可追溯历史替换**；必须与 uniform/prior proposal、source-blind differential proposal、exact mechanism Bayes 比较。计入生成历史参考轨迹的成本；不能只报告减少的 likelihood 调用次数。当前 exact 参考实现会多次全历史重算，不得把它写成已经实现缓存加速。

### R5 — 受控闭环可能全部退回 EIG（科学门槛）

若码长 5、有限 MC 样本、半径大且机制最坏情况存在高度重叠，反证功效可能只有 alpha。此时退回 joint EIG 是正确行为，却不能报告“纠错反证带来提升”。

**修复要求**：逐轮报告理论功效下界、MC 半径、fallback 次数及实际反证次数。另保留确实有独立码区的解析码本测试，区分“算子可工作”与“生成器已产生可工作码本”。不要缩小风险半径或偷用真实响应来使 demo 出现反证。

### R6 — 列表覆盖与长期覆盖不是同一个保证（科学边界）

当前列表每块重置，不做跨块交集，避免把每块 eta 错当作永久置信集。其角色是调度，不能拿来把源后验置零。若未来要累积多个块的排除，须另设覆盖风险预算/可撤销证据规则。

### R7 — 反证决策不是新的测量（科学边界）

检验触发后 M2 使用同一原始块更新/回放即可。不能再乘以“reject”的概率，把相同观测同时计为原始 likelihood 和二值诊断 likelihood。当前代码遵守，须继续保留防重复测试。

## 原生 M1 教师的真实失败条件：不是简单“二维不够”

所需的精确可行条件是

$$\operatorname{range}(\partial_sX)\subseteq\operatorname{range}(J_XP_U),\qquad P_U=I-J_U^+J_U.$$

源位置只有二维，并不使该条件自动成立或自动失败。重要的是自然随机传播噪声在固定可观测局地风后，还能否沿源扰动所需的观测切向方向移动。

- 若唯一随机变量就是两维风，而 `J_U` 满列秩，则 `P_U=0`；只要源切向量非零，风保持 lift **数学上不存在**。
- 若原生粒子扩散/排放扰动含有独立自然噪声，可能存在非零风零空间，但响应切向量仍须落入其像空间；必须逐样本检验，不可以“噪声维度很大”代替证据。
- 不应直接对硬检出位求 `J_X`，其普通导数几乎处处为零。需要连续的读出前响应 X 和独立处理的硬阈值/碰撞/注入分支。受控一维门已演示边界项，但 GADEN 的多门覆盖尚未完成。
- 移动源跨过不可行障碍、离散注入体素或断开的合法候选区，可能没有所假设的光滑源路径。source-score 路径界必须限于合法连通分区，分区相对质量依赖 NLL。
- 没有自然随机噪声资格、JVP/VJP、分支 trace 的原生模拟器，当前状态应为 `BLOCKED_NATIVE_TEACHER`。这不妨碍训练 Aprime、运行 M2/M3 或验证受控 IBP 算子。
