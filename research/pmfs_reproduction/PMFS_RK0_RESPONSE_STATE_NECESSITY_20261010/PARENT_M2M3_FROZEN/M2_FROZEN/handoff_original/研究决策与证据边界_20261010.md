## 2. 决策

当前没有足够证据宣布已形成可投稿的主创新。优先研究对象不是“更精细的三维场”，而是“单一固定源产生的随机气体，经移动采样与传感器转换后，如何形成源位置证据”。

首选机制候选：**物理随机过程与观测生成过程不一致，导致源候选比较发生结构性偏移。**

保留的备选：观测过程对齐后仍存在、且能在独立样本中复现的源—传播条件补偿/前向失配。不能将它直接等同于三维缺失；更换2D/3D模拟器会同时改变多个近似。

不批准作为当前主创新：单纯概率降温、事后删格、普通贝叶斯模型平均、泛化的任务充分表示、仅把PMFS改成3D、普通风场/浓度/源位置多头网络。

## 4. 当前证据

E3：一次官方成功样本，不是30次统计复现。B4：一次合法候选支持中的错误高置信收敛。M0：指出净错误评分主要来自哪个空间带及传播格，不证明因果机制。M1：统一1×1候选面积后错误偏好依旧，不排除所有源表示、随机近似及物理失配。

原始受体观测能否稳定区分真/错源仍缺独立源条件参考。B4-M1的两个RNG起始状态不是两次独立物理实现。B4风始终为第10帧，不能用于证明动态湖陆风历史错配。

本次另读原始无表头`measurement_events.csv`确认：50块、50块超过固定0.1阈值、10处停留；块浓度范围0.1682239324—6.8793778419。不能把这50块称为50次独立物理实验，也不能因为全为正检出就断言没有空间定位信息。

## 5. 本次新增的公式级反例

对应源码位置：`PMFSLib.cpp`的`EstimateHitProbabilities`、`applyFalloffLogOdds`；`Simulations.cpp`的`probabilitySingleFrequency`、`simulateSourceInPosition`。

在同一测点、零空间偏移、固定先验0.3、每次逆观测模型命中0.6/未命中0.1的简化条件下，累计log-odds为：

`ell_n = logit(0.3) + n_hit*(logit(0.6)-logit(0.3)) + n_miss*(logit(0.1)-logit(0.3))`。

真实独立检出率为r时，线性漂移临界值约0.518666。高于它，测量图值趋向1；低于它，趋向0。这一般不等于检出率r。

示例：100次中60次检出，真候选的精确预测检出率0.6，错误候选0.9。测量图约0.9999999985；D=0.4、共同confidence=1时，单格相似度分别约0.84和0.96，错误候选获胜。原始Bernoulli似然反而支持真候选约3.29e13倍。

并非只选一条有利序列：随附程序对所有可能检出次数作精确二项加权。样本数50、100、200时，这一两候选玩具问题的相似度误选概率分别约84.38%、93.62%、98.69%；原始Bernoulli规则约0.5688%、0.01072%、0.00001215%。

### 不允许扩大结论

1. 这是公式级反例，不是原生C++逐位复现，也不是B4定位改进。
2. 它没有推翻二值滤波在适当静态二值隐变量上的正确性。
3. 在固定n、精确数值的一格情形，log-odds可反演检出次数；不能因此声称建图本身必然丢失信息。反例直接证明的是比较对象的概率含义可能不一致。
4. B4的50块全为正检出，反例中的60/40混合序列不能直接解释B4。
5. 将地图换成Beta-Bernoulli、做校准或采用普通原始事件似然，本身不满足主创新要求。

## 6. 方法草案与原创性边界

工作名称：**过程—观测分离的随机气源推断**。

让`mu_s`表示给定源位置、几何、风条件下的随机羽流过程分布；`O_A`表示沿实际轨迹和时刻采样；`S_theta`表示传感器响应；`B`表示实际测量块聚合/阈值转换。源条件观测分布为：

`nu_s^A = (B o S_theta o O_A)_# mu_s`。

推断比较`nu_s^A`与实际同类观测，而不是直接把原始模拟命中率与累计二值信念相减。最终仍对源坐标取边缘分布，输出二维源概率图。

这条生成链是结构定义，不是原创性证书，且项目9月23日已有相近定义。可发展的实质贡献需要包括：

- 特定观测压缩/非线性转换导致源比较偏移的条件分析与实际反事实证据；
- 面向移动受体、间歇羽流及有限随机预算的源条件联合证据构造，而非一个全局标量校准函数；
- 对共享原始观测的传播格保留依赖，不能重新当成大量独立传感器；
- 在未见源、风况和几何上纠正定位/排序，同时给出独立验证的短时预测。

底层可先用已有物理样本及低维统计原型，不必先训练世界模型。跨场景目标是共享条件化生成机制，不是要求不同风况下浓度曲线相同，也不是不加区分地删除所有随风变化的信号。

## 7. 湖岸和论文定位

优先采用“普遍机制 + 湖岸独立压力验证”，不把湖岸热力现象设成必须成立的主机制。真实地形、受控气象、模拟泄漏必须分开标注。

暂定题目方向：基于观测生成一致性的湖岸无人机气体源定位与动态监测研究。题目只能在机制准入后冻结。

研究内容一：过程—观测分离的概率气源定位与短时羽流预测。
研究内容二：定位歧义与羽流关键区域驱动的多无人机协同监测。
研究内容三：多设备观测一致性与分级闭环验证。

第一篇保留源位置概率、定位误差、预测检出区域及不确定性。输出绝对浓度还需要源强/传感器标定及相应可辨识性，不能由命中率自动得到。传播路径应是可定义的概率通道/到达统计，不把风流线直接称作气体真实轨迹。

合格论文证据还需要非oracle信息条件比较、留出物理实现、跨源/风/几何、独立预测和消融。相同模拟器不同seed只解决实现泄漏，不自动解决同模型验证偏乐观的问题。
