# M3 冻结二维图的受体代理与源偏好定位

本次新增实际工作为只读算术：复用M1统一1×1候选的T/W两组图、原B4的50块事件及最终原生belief/confidence，再与M2独立3D参考的相同受体事件比较。新增前向、ROS、GADEN、导航均0。合同在生成派生结果前保存。

## 1. 不经过累计测量图，二维占格频率代理仍有错误偏好

2D占格频率没有ppm，**不能自动视为合格PID块事件概率**。下面只把它放入固定评分算子，定位错误偏好是否已经存在于受体处。50块全部正，来自10处停留；坐标用原生float32原点、0.25m网格及float32坐标运算转换，实际得到10个合法直接受体格。

| 二维图 | 随机状态 | 原值Brier 真/错（越小越好） | 原值Bernoulli log 真/错 | 固定有限步平滑log 真/错 |
|---|---|---|---|---|
| 原生模糊图 | T | 0.834997 / 0.409450 | −∞ / −∞ | −212.589 / −123.222 |
| 原生模糊图 | W | 0.840575 / 0.408583 | −∞ / −∞ | −214.000 / −123.058 |
| 未模糊占格图 | T | 0.864925 / 0.435450 | −∞ / −∞ | −248.183 / −125.367 |
| 未模糊占格图 | W | 0.874000 / 0.428363 | −∞ / −∞ | −249.738 / −124.549 |

未平滑的log两候选都包含预测为0的正观测，故均−∞，不能宣布它选错源。模糊图中真/错分别有10/15个不可能正事件；未模糊图为40/20个。没有为救分数裁剪0/1。

固定敏感性`p=(200*h+0.5)/201`后log和Brier均偏错。200是原二维记录步数，不是50观测块数。对未模糊图`200*h`近整数（float32最大误差5.72e−6）；对模糊图这仅是加权pseudo-count变换，不能宣称它是实际Bernoulli样本的Beta后验。报告原值和敏感性，后者不代替原值，也不是新算法。

## 3. 真正PID参考与网格量化控制

M2两份独立参考/候选，在实际服务XYZ、实际物理时刻和固定PID阈值下：原B4 log 真/错=−9.1161/−30.9835，Brier=0.027778/0.21，两者偏真。

把3D查询移到**相同native受体格中心**、保持原传感器高度−0.2m与物理时刻，log 真/错=−9.1161/−32.1590，Brier=0.027778/0.218889，也偏真。因此本次受体平面坐标量化没有把3D PID参考的候选排序反转。此控制改变了空间采样，明确为诊断，不能替代实际传感器观测。

## 4. 能缩小什么，尚不能证明什么

可以限定地说：**在冻结二维占格频率代理中，绕过累计belief-map仍有错误Brier排序；累计地图不是该代理排序产生的必需步骤。** 这削弱“只有地图传播/累计才制造了错误偏好”的单一解释。

不能据此说累计地图与B4完整错误定位无关，或二维维度缺失已是物理根因。二维与3D仍同时不同：均匀1×1源/精确点源、记录窗口/真实时钟、5丝团/步的50丝团每秒记录尺度/7丝团每秒物理释放、中心占格/扩散体积浓度、水平风/三维路径，以及同信息PID算子资格。二维还使用0.375m量级的固定网格模糊，而3D丝团σ随年龄增长；这一差异不能靠改评分称为消除。

这两个M1随机初态不是两次独立物理realization，50块也不是50次物理实验。M2的四份留出仍是同一GADEN模型和同一选定B4任务，未形成新定位增益或独立物理模型验证。

## 5. 建议下一刀的冻结设计（方案，未执行）

优先利用**同一批M2点源bank的原生丝团状态**，不新增GADEN或CFD，隔离“中心占格”与“体积浓度/PID”的读取差异。双方仍是完全相同的点源、源强、扩散参数、物理时刻、轨迹和realization。预注册三种读取：原生PID；同0.25m水平受体格中至少一个丝团中心的xy投影占用；同受体格且中心z处于传感器高度±0.125m层内的占用。后两项是明确可审计的几何占用算子，不赋予ppm。两种几何定义都预先保留，不能按结果选一个；reference/heldout划分和Jeffreys平滑沿用M2。这样能直接检验同一物理过程的观察尺度/投影是否改变源排序，但仍不能证明原2D模型全体失效。

若必须消除M1与M2的源表示差异，另冻结最多4次低成本二维**精确点源**前向：真点(−3.2,−3.3)、错点(−1.675,1.495) × 两组已有RNG初态，仅使用已有`SimulationSource::Mode::Point`，无导航、无更新、无新seed。该试验仅排除均匀区域/点源混杂，**仍不能对齐原生50/s与7/s及PID读出**；不能做完点源就直接宣布二维/三维原因成立。

正式可比物理对照还须固定同类释放计数、相同目标时刻、相同受体体积/浓度读出，再只改变欲检验的物理状态。这意味着隔离的诊断输运核需明确改动，不能冒充未改官方PMFS。上述两种下一关方案均未在本子任务执行，没有自动授权新计算。
