# PMFS M2/M3 独立审查与主创新决策

日期：2026-10-10。锚点：`4d15d0d93b5d33b1d7d18b12b4cf8095f1cfe66c`，M2提交 `c7f06bfd2b180350f5fe7d03b772da5839945d8e`。

## 结论

已经找到有反事实支持的失效组成因素；尚未把B4原生错误收敛唯一归因，更没有完成新方法的定位验证。现在不应继续把整个项目笼统称为“物理机制未知”，也不能把“导航域改成气体域”直接包装成主创新。

本轮进一步以相同三维物理bank、同一观测时刻、同一447格、同一原生相似度，对比预测读出：三维羽丝中心的二维占用频率弱选错源，而真实传感器高度的PID阈值频率选真源；共同使用原生模糊时仍翻转。它明确定位了一个**读出压缩不保持源判别**的条件失效。它不同于上一轮“累计信念与频率语义不一致”E1假说，不得偷换成E1已经证明。

可收敛的主问题是：**如何在压缩随机气体状态时，同时保留物理可达性与源—受体检出关系，并以可控制的计算代价输出二维源概率与短时预测？**

这足以进入有限的机制导向原型筛选；没有必要等待把B4所有评分差唯一分解完。但主算法必须超过正确气体域、正确观测模型和普通概率反演，不能仅胜过未修正的原生PMFS。

## 一、实际核验范围

本地解压联合包；独立核对1510项SHA；独立M2 ZIP的877个文件成员与联合包内M2逐字节一致。调用M2只读核验完成原始快照到408个受体浓度的复算，并检查原生语义与建图锚点。M3的壁面/点源、风高度、运动域子核验、五种观测核、共同中心场、代理评分及392帧物理状态统计均作复算或按原核验入口检查。

没有运行新的GADEN、CFD、原生候选前向、导航或训练。复算不是重新积分全部1000秒气体，也不是独立验证CFD真实性。

### 原验证器的可移植性问题

原版`verify_combined.py`在本环境不能原样通过：其一，OpenCV版本字面值4.11.0与4.13.0不同；其二，最后对派生CSV要求字节相同。原始证据哈希全部不变。

对派生表逐值检查后：303个细XY高度统计、659个普通XY高度分布及7942条局地统计仅存在约1e-17量级差异；392帧计数表字节相同。1452行高度直方图中，`z_min/z_max`存在最大2.1606683731079102e-7米差异，原因可被两套明确标量表达式逐项精确解释：旧式`float(origin)+k*float(cell)`与本环境float32运算的类型提升不同。所有体素编号、计数和比例相同。主JSON在原数值容差内一致。

因此应写“核心数据与数值核验通过，原验证器存在版本/派生标签可移植性问题”，而不是“原版验证器全PASS”。没有扩大原数值容差或修改冻结文件。详见`new_diagnostics/PORTABLE_VERIFICATION_SCOPE.json`。

对照使用点源、相同柱均风及原壁面规则：

|随机初态|原导航运动域错/真评分比|柱自由并集运动域|真源评分增长|
|---|---:|---:|---:|
|T|21729.753388|467.105042|约50.51倍|
|W|25553.938085|334.671508|约49.11倍|

评分、候选支持和447格读出没有随运动域放宽。新增区域采用事先冻结的风延拓；两个禁用干预锚点检查了原分支保真。本对照各分支预热200步、记录200步，排除了该组中预热时长变化。T/W仍只是两个算法随机初态，运动变化会使随机消费分叉，不是独立物理释放。

392帧的457736条粒子—快照记录中，297006条投影在二维导航非自由格。64.89%不是质量比例、独立样本量或根因贡献率。

### 必须修正的“上界”逻辑

柱自由并集把1530格全部放开，可连接实际处于不同高度、并不连通的通道。它是几何支持的放宽，不是定位性能的上界。**支持集合变大不保证源排序单调变好。**

因此，该放宽仍错只能说明“这项已测试放宽不足”；不能证明“任何正确气体域修复都不可能单独修好”。仍需真实三维连通性或合格多层连通模型作比较，不能用全开放二维平面冒充真三维。

点源、滑动、固定风面的所有未改善结果保留。它们否证的是已测试的简单充分解释，而不是对应物理因素在所有条件下均无关。

## 四、本轮新增：同bank、同评分的读出反事实

复用C7/K2各两份reference，不更换随机物理实现、源坐标、实际50个时刻、传感器高度或冻结测量地图。

评分统一为

\[
\ell_s(q)=\sum_{i\in\Omega_{score}}\log\bigl(1-0.4c_i|p_i-q_{s,i}|\bigr),\qquad
\Delta=\ell_{C7}-\ell_{K2}.
\]

正值支持真源C7。该式只是原生相似度，不作为物理联合似然。

|预测读出|共同处理|Δ|选择|
|---|---|---:|---|
|全高度中心投影占用|不模糊|-0.2588620658|K2错误源|
|PID浓度>0.1ppm频率|不模糊|+4.0082067819|C7真源|
|全高度中心投影占用|相同导航mask归一化模糊|-0.5089087756|K2错误源|
|PID浓度>0.1ppm频率|相同导航mask归一化模糊|+3.3033548387|C7真源|

这次没有同时改变距离形式，不是M2中“原生相似度与地图MSE”的混合对照。

物理含义：同一XY里有中心，不代表在受体高度有足够气体；XY里没有中心，也可能有邻近扩散核贡献超过阈值。中心占用还丢弃了粒子数、羽团尺度、质量加和及遮挡影响。当前证据不能把这些读出因素进一步唯一分成“只有高度”或“只有尺度”。

**已支持的最窄机制结论：** 在固定三维bank与冻结原生评分下，所测中心占用读出会改变当前两源的相对判别，换成匹配物理传感器的读出可反转其排序。这不直接解释原生二维前向的上万倍评分差。

全场447格查询只用于反事实诊断，不是部署中额外获得447个真实传感器。相同bank在M3已被检查，因此本轮是探索性、确定性复算，不是新独立实验。

## 六、应该研究的对象与数学条件

不是把所有二维方法升级三维；更不是换Bayes为神经网络。

研究对象是源条件随机气体状态及其有限移动受体响应。完整状态可含三维位置、羽团尺度/年龄及粒子数量；部署只读取实际气体、风和位姿。输出仍是二维源概率图。

若以R压缩状态，好的压缩至少要近似满足：

\[
P(RX_{t+1}\in A\mid X_t=x,s)=\bar K_s(A\mid Rx),\quad
P(Y_t\in B\mid X_t=x,a_t)=\bar O(B\mid Rx,a_t).
\]

第一式要求同一粗状态具有可表达的后续转移，第二式要求同一粗状态具有可表达的受体响应。源注入、初始分布与边界也必须一致。满足上述条件的Markov模型可在粗状态中保持观测序列分布；仅保持XY访问频率不满足该结论。这是经典状态聚合的理论要求，不是本轮发明的新定理。

在线概率图应由整个隐状态边缘化得到：

\[
\pi_t(s)=\int p(s,X_t\mid y_{1:t},a_{1:t},u,\mathcal G)\,dX_t.
\]

输出二维并不要求内部状态二维。反过来，内部三维也不能补救错误读出或不合格的概率比较。

## 七、三条真实跨领域计算候选

### A. 海马正交化状态机：克隆状态解除混叠

文献[P1]：Weinan Sun、Johan Winnubst、Maanasa Natrajan等，*Learning produces an orthogonalized state machine in the hippocampus*，Nature 640,165–175 (2025)，12 February 2025，DOI `10.1038/s41586-024-08548-w`。DOI中的024不等于出版于2024。CSCG的基础早于2025；该文贡献包括神经记录与学习过程比较，不能声称CSCG本身于2025首次发明。

**原领域输入→计算→输出：** 模糊/重复视觉线索与事件序列 → 一个观测符号对应多个隐藏克隆，固定结构化发射关系、用Baum–Welch学习转移 → 随历史改变的克隆占用概率和任务状态图。

示例：`A→G→B`与`C→G→D`中，同一个G分成G1/G2；不是增加一个任意记忆向量，而是禁止把两条不同历史串接成错误未来。若后续同为B，分裂并不必然有益。

其原型滤波式可写为

\[
b_t(j)\propto \mathbf1[j\in C(o_t)]\sum_iT_{ij}b_{t-1}(i).
\]

**映射链：** 感官符号混叠 → 隐状态克隆与转移学习 → 任务状态概率 → PMFS把不同高度/尺度及来历压到一个XY中心占用状态 → 重定义物理克隆、运动与受体发射，而非照搬视觉HMM → 真实几何/风、源候选注入、实际PID事件/浓度/位姿 → 边缘化隐状态输出二维源概率。

**本领域重新设计：**
- 一个XY格可具有少量响应不同的隐类，而不是密集3D重建；划分不接收真假源标签。
- 气体转移由气体物理连通性约束；导航动作只改变受体采样算子。未建模旋翼扰动时，不把无人机动作当作能控制羽流的动作。
- 气体同时包含很多羽团，必须使用占用数量/质量状态或其随机集合，不能拿“单个隐藏位置HMM”冒充整个羽流。
- 用已有物理参考学习/校准状态；不能仅从B4的50个全正块无监督学出高度状态。

**必要性检验：** 正确气体域与统一响应核已修复后，响应保持的状态分裂是否仍提升独立源判别或概率质量？必须比较普通HMM、固定高度/尺度分箱、无克隆折叠及相同状态数的非物理划分。

状态：保留为**有条件的计算母机制**，尚未批准“CSCG适合本项目”的结论。若普通固定核/分箱已足够，停止将克隆当主创新。不得把旧MZ/Blackwell/世界模型STOP重新换名。

### B. 内嗅皮层的可组合预测地图

文献[P2]：Payam Piray、Nathaniel D. Daw，*Reconciling flexibility and efficiency: medial entorhinal cortex represents a compositional cognitive map*，Nature Communications 16,7444 (2025)，DOI `10.1038/s41467-025-62733-7`。

**原领域输入→计算→输出：** 基础空间转移与物体变化 → 默认预测表示及对象局部改变的组合 → 可重组的预期占据地图与规划价值。原文默认表示为

\[
D=[\operatorname{diag}(e^{-r/\lambda})-T]^{-1}.
\]

**映射链：** 局部环境变化 → 对基础预测地图作可组合更新 → 全局预测关系 → PMFS用一张导航占据图硬性决定气体路径 → 将物理结构对气体传播的作用作为有向转移算子的改变，并独立保留导航图 → 气体几何、风、源注入和受体 → 源条件检出预测及二维源后验。

可以研究的GSL代数骨架（本报告的改写，不是原论文GSL公式）为

\[
G=(A_0+UV^\top)^{-1}
=G_0-G_0U(I+V^\top G_0U)^{-1}V^\top G_0.
\]

它保留对象间相互作用，不等于把几张羽流线性相加。必须用气体图而非机器人图，保持非负/稳定性；风存在时不自动拥有平移旋转不变性，风与边界必须相应变换。

**局限与查重：** 该计算可以提高结构更新效率，但不会自动修复高度混叠、PID读出和概率校准。与仓库M4类组合算子邻近；需要在正确读出下与整体求解和旧组合方式同信息比较，不能以“认知地图”名称重新开旧失败分支。

状态：作为跨几何表达/效率的备选，不把它当作目前最强的定位主机制。

### C. 天文学HIBI：在仪器响应空间联合反演隐场与物理结构

文献[P3]：Paul Tiede、William Moses、Valentin Churavy、Michael D. Johnson、Dominic W. Pesce、Lindy Blackburn、Peter Galison，*Hierarchical Interferometric Bayesian Imaging*，The Astrophysical Journal 997(2),262 (2026)，DOI `10.3847/1538-4357/ae2749`；初始预印本2025年11月。作者出版目录确认期刊信息，算法细节读取作者arXiv全文。

**原领域输入→计算→输出：** 稀疏、受仪器影响的干涉观测 → 天体场、仪器增益及相关先验超参数的层次联合反演 → 天体图像、形态参数与不确定性，而非先得到一张确定图再忽视重建误差。

简化观测方程与关键归一化项为

\[
V_{ij}=g_i g_j^*\mathcal F[I](u_{ij},v_{ij})+\epsilon_{ij},
\]
\[
\log p=\log L-\tfrac12r^\top Q(\eta)r+\tfrac12\log\det Q(\eta)+\log p(\eta,g)+\text{const}.
\]

`log det Q`使先验尺度变化的体积代价进入推断；不能任意扩大误差解释任何数据。上述是原框架的简写，不是本文原创。

**映射链：** 稀疏间接观测 → 显式响应算子和隐场/仪器/超参数联合推断 → 源结构后验 → PMFS将中心占用代理当作实际检出证据 → 用受约束的源条件随机羽流和已标定PID响应替换代理，不把插值图再当新观测 → 原始气体/风/位姿与物理先验 → 对羽流与参数积分得到二维源概率。

**淘汰理由：** 与已知源项反演、联合状态估计高度相邻；B4的PID链已经核验，并没有仪器增益未知的现成证据。若只是层次Bayes+MRF+新名字，不满足主创新要求。源位置与任意残差场也可能互相补偿；更大的隐模型不会自动解决不可辨识性。保留为响应建模和不确定性基准，不作为本轮主算法。

## 八、可以形成的一个主思想、两个辅助机制（条件草案）

主思想：**为源—受体预测解除状态混叠，而不是为全场重建盲目增加状态。**

辅助机制一：**物理支撑约束的转移结构。** 分别定义气体可达域、平台可达域和观测支持；真实边界决定气体边，平台限制不能删除气体状态，柱并集也不能创造跨层通道。

辅助机制二：**响应保持的原始事件更新。** 保持羽团尺度、质量加和、受体位置和实际阈值；每个原始观测进入条件更新一次，地图是输出或预测摘要，不重新冒充独立证据。概率可靠性需独立任务检验，不能靠把相似度归一化就宣称成立。

对占用数量/质量状态N_t，设计骨架为

\[
N_{t+1}\sim\mathcal K(N_t;b_s,u,\mathcal G_g),\qquad
C_t=h_{a_t,\theta}^{\top}N_t,\qquad
Y_t\sim p(y\mid C_t),
\]

再递归推断源与N的联合分布并边缘化源概率。若只传播E[N]，一般不足以推导超阈值概率；必须保留相应随机波动、协方差或集合，不能把均值当完整概率分布。

这些方程本身仍是一般状态空间结构；潜在原创部分应当在**少量物理克隆的构造/更新规则、读出保持性质和源判别收益**，而不是式子中出现了Bayes或隐状态。

## 九、下一步只检验一个缺口

检验命题：**改正支撑与观测定义以后，一个所有源共享的固定响应核是否足够，还是需要保留源条件的高度/尺度混合状态？**

先用已有bank作受限读出压缩诊断，不新建CFD、不航迹挑选、不训练通用网络。比较同一物理bank上的：
- U：保留中心数目而非“至少一个中心”，所有源共用一个固定响应核。
- S：同一计算流程，仅将同XY分成事先限定的小数量高度/尺度状态，响应核仍不接收真假源标签。
- F：原生完整3D-PID，作为参考。

共同使用实际受体事件与相同评分；不得把heldout真实z/尺度当在线输入。若为诊断读取这些隐状态，明确写成oracle压缩可行性，不计作定位方法表现。内部分箱及核只用reference，已看过的四个heldout仅作为探索，不能称全新验证。

U已接近F：不以此批准复杂状态克隆；优先正确基线与新任务。S在预测和源判别上有附加收益：允许克隆类有限原型。S仅改善场拟合不改善任务：不升主线。F与两者皆无可重复优势：不继续加隐类补救。

后续新任务最多先做6个按几何预选候选×每候选2 reference+2 heldout=24份气体，分批运行；并保留B4开发与E3非劣案例，不把旧四个留出当新独立验证。它仍不是发表级统计验证。必须新增未见源/风况/几何后再论泛化，不能要求在已错的旧复现上追求通用胜利。

若学习转移需要粒子身份，不能用392快照中的行号当稳定ID；必须使用合格转移记录，或单独建立并检验明确物理转移。禁止重犯旧source-lineage失败。

## 十、研究内容一及湖岸联系

内容一可暂写为“复杂传播环境下保持受体响应的概率气源定位与短时预测”。若克隆必要性与新任务成立，再用“基于响应保持状态分解/克隆”的具体标题，而不是现在就锁定网络名称。

输出包括二维源概率、坐标、检出区域及有数据条件下的浓度预测。仅二值观测不能无条件推出绝对浓度；源强与传感器应标定或作为受约束变量处理。

湖岸意义在于机器人/无人机许可或安全域与气体传播域可不同，以及受体高度和地形通道对信息的作用。上述属于待验证的迁移场景；当前B4不是湖岸实测，也不证明动态湖陆风。内容二接关键区域监测与任务分配，内容三接设备/闭环与实飞，不把所有任务塞进主算法。
