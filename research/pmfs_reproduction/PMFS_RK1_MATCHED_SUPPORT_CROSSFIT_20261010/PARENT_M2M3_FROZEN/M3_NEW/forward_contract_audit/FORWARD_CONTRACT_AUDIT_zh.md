# B4/M2 原生前向合同与三维状态投影审计

本审计只读取锁定源码、M1 原生前向记录、M2 的 392 个已保存三维快照、原 CFD 第10帧和 B4 配置。没有生成气体，没有运行 ROS、导航、候选前向或输运再积分。源码正文、哈希、定量表和只读脚本随包保存。

结论已经比“二维与三维不同”具体：原生 PMFS 在固定传感器高度的二维风、二维自由支持、点中心占用频率上建模；GADEN 的中心在三维空间移动，实际高度改变其水平风，边界处理、释放密度和驻留历史也不同。已有三维状态证实这些高度和几何投影差异真实存在。然而，它们是否单独导致 B4 的错误源偏好，仍必须由同观测、同候选、同随机初态的单项干预判断。本文件不把状态差异升格为已确认因果。

## 先排除两种不正确的工程解释

1. **不是风服务错误地强制 z=0。** `PMFSLib::InitializeWindPredictions()` 从 TF 取得 `anemometer_Z`，B4 实际为 -0.2m。冻结二维图中全部447个自由格的 u/v，与 M2 原生 CFD 查询同格、同高度数值完全相同（最大差0）。需要研究的是这一合法水平切片是否足以表示整个羽流运动，而不是将它误写成错误接线。
2. **不是水平随机位移标准差大十倍。** GADEN 配置 `filament_noise_std=0.02`，但构造函数为兼容旧配置明确乘10，再乘 dt=0.1s，水平单步位移标准差为0.02m。PMFS 为0.2m/s×0.1s=0.02m，记录阶段尺度相同。GADEN 另有 z 随机位移；PMFS 预热 dt 翻倍后为0.04m。这些差异须分开记录。

## 真正不相同的程序原语

| 环节 | 本次 PMFS 实际行为 | 本次 GADEN 实际行为 | 可影响的链条 |
|---|---|---|---|
| 释放 | 每步固定5个中心；记录50/s、预热25/s | 7/s，累计小数后取floor；固定点释放 | 中心占用饱和、存量与驻留时间；不是已标定的质量率 |
| 源表示 | 每个中心在候选叶内重新均匀取点；真源叶5×1格、错误峰1×1格 | 两个 M2 源均为精确XYZ点，z=-0.5m | 候选区域混合与随机释放位置；精确点是oracle诊断 |
| 状态 | 仅XY中心，没有 sigma、质量、气体类型或高度 | XYZ中心、sigma；固定总摩尔数、sigma随时间长大 | 不能从 PMFS 中心数自行制造ppm |
| 风 | 原生0.25m格中心、z=-0.2m的u/v，单次源更新冻结 | 0.1m体素风u/v/w，按每个中心当前XYZ取样 | 隐藏高度改变水平漂移与可达路径 |
| 浮力 | 无 | gas13=smoke，比重0.89；初始10ppm时约+0.03798m/s，随sigma长大衰减 | 改变高度，进而改变后续水平风，不是恒定上升速度 |
| 壁面/出口 | 同格或可见自由终点走到终点；其余按≤0.125m步长截断，遇壁退回，无切向滑动；出二维边界删除 | 步数ceil(距离/0.1m)，遇障碍/OutOfBounds退回并递归处理切向剩余；仅Outlet删除 | 墙边驻留、绕行、存量和出口条件不同 |
| 时间 | 空羽流重新预热；本次6份M1记录均为40模型秒预热+20秒统计 | 连续释放自物理0秒开始，本次受体时间322.92–534.09秒 | 当前静态风不意味着羽流历史或年龄一致 |
| 读取 | 每格每步最多一次中心占用，200步平均，再用σ=1.5格=0.375m的全场Gaussian blur及自由掩码边界校正 | 三维有限Gaussian、3σ截止、LOS、摩尔数换ppm累加；原生传感器阈值0.1ppm | 两种hit的样本空间与浓度语义不同 |

上述 PMFS 碰撞路径是实际生效的 `USE_DDA=0` 分支，不能把未编译的0.7壁面比例解释成本次行为。GADEN 切向残量使用锁定 `vmath::project()` 原实现；其整数跨格法向投影不能被报告者换成理想化法向公式。PMFS 的 `warmup` 形参不控制预热代码块，本次执行本来就开启预热，因此这不构成新发现的运行错配。

保存快照中的 sigma 范围10.075–90.065cm，中位40.608cm；对应3σ半径0.302–2.702m。统计汇总457,736条颗粒状态记录，多帧中的同一颗粒可以重复出现，这不是457,736个独立物理样本。PMFS 有全场 blur，因此不能说它“完全没有Gaussian”；该固定二维后处理与逐颗粒质量守恒的三维浓度核不同。

## 用现有状态量化二维状态不闭合

`audit_3d_state_aliasing.py` 重读并核验全部392个快照哈希。每个中心在原0.1m CFD XY体素上分别取其实际Z和固定传感器Z=-0.2m的风。这样高度风差不包含0.25m二维水平网格粗化；另表同时给出实际风与原生二维格风的总差。

全体457,736条相关状态中，297,006条（64.89%）中心投影落在原生二维图内非自由格，3,552条（0.78%）超出原生二维索引范围；按 GADEN 实际索引占据谓词，中心均处于3D自由体素。三维可达空间与二维导航/候选支持并不相等。这不是允许改地图、添加真源候选或删除状态的依据，也不能把上述比例当成评分失真的百分比。

另外，原生浮点坐标转整数使用trunc，体素范围向上取整；原生自由索引与声明的严格world min/max AABB存在边缘区别。本次1,172条状态超出严格声明AABB，其中360条低于某轴最小值，却仍在原生自由体素索引内。随表单独记录，未悄悄替换占据谓词。它们占0.26%，不足以仅凭数量归因主现象。

为避免非自由二维区域的零风扩大统计，重点使用预设y=1.7–2.7m且原生二维自由支持内的50,997条状态：

| 描述量 | 数值 |
|---|---:|
| 实际中心z中位 | 0.6277m |
| 与传感器高度绝对差中位 | 0.8317m |
| 同细CFD XY的实际Z风与传感器平面风水平差中位 | 0.10254m/s |
| 实际水平风速度中位 | 0.04665m/s |
| 可比较风向中反半平面 | 18,656/50,819=36.71% |
| 两风向夹角中位 | 38.95° |

这些数值描述已实现的三维颗粒状态，不是受体ppm权重。不能用“风误差/近零真速度”的巨大均值证明强失配；JSON保留该原始相对量，但本报告主要使用绝对差、中位和有非零速度条件的方向统计。

进一步固定同一个0.1m CFD XY体素，而不是只固定0.25m候选格。在关键带且二维自由支持内，对两源各至少20条状态的全部303个共有XY体素，无按定位效果选格：

| 源条件高度/风描述量（303体素） | 中位 | P95 |
|---|---:|---:|
| C7/K2 高度分布JS距离（bit） | 0.38990 | 0.58759 |
| 两源条件平均z绝对差 | 0.25914m | 0.86676m |
| 两源条件平均水平风向量差 | 0.02371m/s | 0.10675m/s |

其直接含义是：即使当前CFD是静态第10帧，同一个XY处的颗粒高度分布也依赖源与已有输运历史；源条件平均水平漂移不必等于一个共享的固定平面风。二维XY状态没有保存这种条件信息。JS和计数只作描述，没有把颗粒或空间体素当独立实验进行显著性检验，也没有证明这些差异正是错误源评分的必要/充分原因。

## 可执行的最小鉴别边界

1. 源表示：同一保存Gaussian初态、冻结地图和风，精确真源点与错误候选精确点同预算。只隔离uniform叶释放混合；不能同时宣称隔离三维动力学。
2. 已有三维路径读出：保持全部三维颗粒状态，比较原生PID核与中心柱占用等明确定义的读出。投影XY中心柱占用会丢弃Z，必须如此标记；不创建没有摩尔数/sigma的“2D ppm”。此项无需新气体。
3. 水平高度风：在精确点、原壁面规则、同两个原生Gaussian初态下，仅换全候选共享的风表。`COMMON_SOURCE_HEIGHT_WIND_SLICE_PROPOSAL.csv` 已从已有CFD取统一z=-0.5m表，447个二维合法格在该高度全为3D自由；另一预先固定全free高度柱平均可另行诊断。所有候选用同表，不按真源给专属高度，不选择效果最好的高度。该干预只能检验水平高度条件，不能补回w、浮力、三维壁面和长期驻留。

以上第1–3项的父任务运行结果以父任务正式原始输出为准。本子审计自身新增前向数为0。若某单项干预未恢复真源优势，就排除该单项足够解释的说法，不再靠同一状态反复挑层、挑seed、挑阈值。未来释放率或壁面单项控制均须独立固定，不自动启动。

## 复核方法和文件

- `FORWARD_CONTRACT_DIFFERENCE_TABLE.csv`：每项实际值、源码行与解释边界。
- `FORWARD_CONTRACT_FACTS.json`：释放、噪声、浮力、sigma、时间及原生预算事实。
- `THREED_STATE_ALIASING_AUDIT.json`：全部源/银行/区域分层统计与限制。
- `THREED_SNAPSHOT_PROJECTION_COUNTS.csv`：392帧数量、投影、严格边界和SHA。
- `CELL_CONDITIONAL_HEIGHT_AND_WIND.csv`、`SAME_FINE_CFD_XY_SOURCE_CONDITIONAL_HEIGHT.csv`：完整逐格条件统计。
- `FILAMENT_HEIGHT_HISTOGRAM.csv`：完整高度体素分布。
- `SOURCE_PROVENANCE.json` 与 `source/`：只读源正文和原始路径/hash。

```powershell
python audit_3d_state_aliasing.py --m1 <M1审核包解压目录> --m2 <M2审核包解压目录> --out <新复核输出目录>
```
