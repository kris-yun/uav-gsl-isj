# RK1 两折共同支持诊断：独立科学审查

本文件的事前部分在读取本轮拟合或测试结果前写定。审查依据是 `PMFS_TARGETED_MECHANISM_PLAN_20261010.md`；本审查不修改冻结合同、源代码、旧缓存或历史判决。结果出来后只能在后文追加实际方向、反例及算术复核，不能据此改变本节判据。

## 事前审查：问题与可识别范围

本轮回答的最窄问题是：在两个候选源的训练细状态都覆盖的同一个 Q 组件内，跨整个气体实现测试时，共享 XY 条件均值是否发生可重复的响应压缩损失；高度×尺度分箱能否补回；分箱之后是否还存在源条件响应残差。

每折 Q 只来自该折双方训练库细 key 的交集。U、S、C 的训练粒子、测试粒子和原生尾项必须完全一致，零贡献必须进入分母。这些身份约束先于任何成绩判定。若不满足，判为实现不可比，不解释科学方向。这里的尾项是隐藏物理真值，并非可部署的缺项修复。

同一精确尾项对连续误差应有逐块恒等式：`预测总响应−原生总响应 = 预测Q响应−原生Q响应`。因此本轮完整浓度 MSE、bias 实际严格衡量 Q 组件的压缩误差，尾项不会掩盖这个连续误差；尾项会掩盖二值阈值效应，并限制结果可外推的空间及状态范围。独立复核应检查这项恒等式。

两折 T0_E1 与 T1_E0 交换整份 realization，降低参考自拟合造成的乐观偏差；但每个源每折只有一个训练 realization，核估计的不确定性会更大。两个折反复使用同四份已查看材料，不是四个全新的独立确认样本，更不能把 200 个相关测量曝光视为 200 次独立实验。

## 事前端点与方向规则

主端点是每个完整测试 bank 的 50 时刻浓度 MSE，两项固定配对为 U→S、S→C。四库等权汇总只作描述，必须同时交付四个方向与原始数值，不能用汇总增益掩盖一源退化。平均有符号误差、平均绝对误差和逐站误差为规定的辅助端点，不替换 MSE 主端点。

“改善”是配对误差在数值精度之外减小。本轮计划没有预注册效应量最小值，因此只可称方向性诊断证据，不能事后新增阈值来升级为统计显著或科学足够。必须报告绝对差及相对差，避免接近零的比例制造夸大。

固定决定表如下：

| 逐 bank 结果 | 科学解释与行动 |
|---|---|
| S 相对 U 在同源两折 MSE 同向改善，C 相对 S 没有跨折稳定附加改善 | 该源 Q 组件支持普通物理分箱的诊断价值；优先检验普通正确响应模型及固定分箱，不证明全域四类充分 |
| C 相对 S 在同源两折 MSE 同向改善，训练与测试的类内源条件响应差方向重现 | 当前四类仍遗漏可重复的条件响应组成；保留响应驱动状态表示候选，仍不证明 CSCG 必要 |
| 某配对一源改善、一源退化，或同源两折方向反转 | 必须报告条件与反例；不宣布统一可靠的机制，也不挑有利一折追加模型或 seed |
| 训练内守恒/改善，但整库测试消失或逆转 | 将旧正结果限定为参考库拟合现象，审查有限样本及状态内波动 |
| U/S/C 的 Q 响应接近 | 当前共同组件未显示额外状态价值；不能据此排除 Q 外或被尾项遮蔽的机制 |

仅当四个 bank 的某项配对主端点均改善，才可称“在本次共同组件上统一改善”。同源两折一致最多构成两源中某一源的稳定方向信号。分类率不是本轮端点，不计算未知源选择 C 的正确率，也不产生新的 PMFS 后验或定位成绩。

## 事前关键盲区

1. C 通过源标签增加条件及核参数。真实生成源在冻结两个 C 输出后才用于选核评价，这仍然是 source-aware oracle。C 的条件均值预测更好，只说明 U/S 的压缩可能残留源条件组成，并不提供未知源时选择正确核的方法。
2. 普通四类是固定高度×尺度离散化，未学习状态转移、克隆状态或历史。即使 S 优于 U，也不能直接推荐 CSCG；即使 C 优于 S，也未唯一分离高度、尺度、格内位置、遮挡与历史。
3. Q 外贡献原样加回，会共同改善所有模型，并可能单独跨过检出阈值。C7 的局部站点 Q 响应很少，事件不变不能否定连续响应压缩，但总检出指标也可能被尾项遮蔽。必须保留每站 Q/尾项响应份额和尾项独立触发数。
4. 每折只用一个源条件 realization 拟合 C，更多参数与较小分母可能增加方差。没有多实现不确定性估计，不能把单次 C 优势或劣势解释为无限数据的核性质。
5. 全部模型使用同一空间框架、已保存受体位置和隐藏粒子状态。结果是响应映射诊断，不是实际稀疏无人机传感输入，也不证明原生闭环采用这些状态后定位会改善。
6. 缓存原生 per-particle φ 与 float64 求和、原生 float32 累加应单列。舍入或阈值近界差不能包装为物理状态效应。
7. C 的源条件 XY 核与 S 的共享 XY×高度×尺度核并非嵌套模型。C 不是在 S 上再增加一个标签的单变量干预。C 的整体 MSE 更低须结合固定细类的训练/测试源条件响应差重现来解释；仅凭这一排序不能证明四类内源条件残差，或排除参数估计方差与跨类组成的影响。
8. 当前核对整库所有曝光粒子在十个受体位姿计算跨时刻平均，而评分是在实际访问时刻的相应位姿。逐位姿、全拟合粒子上的守恒不保证实际 50 条训练事件的平均偏差为零。残差可能还包含时间与位姿联合分布，不能把固定风误解为响应过程没有时间变化。

## 结果后追加：独立算术复核与机制决策

结果输出为 `outputs/PMFS_RK1_MATCHED_SUPPORT_CROSSFIT_20261010`。独立脚本 `science_recalculate_rk1.py` 只读取已保存的预测、指标及冻结后生成源映射，未调用生产器、拟合新核或查询 φ。40 行训练/测试 bank 指标重新计算后均与保存结果一致；同尾项连续误差恒等式的最大差为 `4.4149×10⁻¹⁶ ppm`。本节是结果后追加，以上事前判据不变。

本轮可以给出积极而具体的判决：**共同支持内，跨整个实现测试的源条件响应压缩损失得到进一步支持；它不能完全归于未知状态缺项或核在自身参考库上的自拟合。普通四类补回部分信息，但没有统一消除误差。**尚不能将该损失唯一归因于高度、尺度、格内位置、遮挡、时间关联中的某一个，也不能确定它对原生 B4 错误收敛的贡献比例。

### 主端点：所有四个测试 bank 均保留

| 测试 bank | U MSE (ppm²) | S MSE | C oracle MSE | U→S 相对下降 | S→C 相对下降 |
|---|---:|---:|---:|---:|---:|
| C7_1，T0_E1 | 1.105202 | 0.854989 | 0.760596 | 22.64% | 11.04% |
| K2_1，T0_E1 | 0.655702 | 0.672869 | 0.283668 | **−2.62%，退化** | 57.84% |
| C7_0，T1_E0 | 1.385552 | 1.230607 | 0.735548 | 11.18% | 40.23% |
| K2_0，T1_E0 | 0.418049 | 0.382582 | 0.214615 | 8.48% | 43.90% |
| 四库等权均值 | 0.891126 | 0.785262 | 0.498607 | 11.88% | 36.50% |

S 相对 U 的主 MSE 改善为 3/4：C7 在两折重现，K2 两折方向不一致，故不符合本审查的四库统一改善口径。C oracle 相对 S 主 MSE 为 4/4 改善，且两源都在交换实现后重现；这是可保留的源条件响应组成信号。这里的 4/4 是四个 bank 方向，不能解释为独立确认试验成功率或具有显著性。

参数容量须精确限定事前“C 增加参数”的比较对象：**C 相对 U 增加源条件与合计参数；C 的合计系数反而少于 S**。T0_E1 的 U 为 6850 个受体系数、S 为 20980、两份 C 各 6850（共 13700）；T1_E0 对应 U 6940、S 21510、两份 C 共 13880。因此 C 的改善不能笼统归结为“比 S 参数更多”。但 C/S 所用条件信息不同且非嵌套，也不是容量完全匹配的充分性检验。

### 不能隐去的辅助端点反例

1. C7_0 中，C 比 S 的 MSE 改善 40.23%，但 MAE 从 `0.478849` 略升至 `0.485279 ppm`。平方误差更低不等于所有误差指标更低。
2. C7_1 中，C 比 S 的 MSE 改善 11.04%，但平均有符号误差由 `−0.047583` 变为 `+0.064810 ppm`，绝对均值偏差略升。C 并没有全端点支配 S。
3. K2_1 中，S 的主 MSE 比 U 退化 2.62%，但 MAE、绝对 bias 和检出误差均改善。不能用这些辅助正结果替代已经冻结的 MSE 反例。
4. K2_0 中，S 主 MSE 改善 8.48%，但检出误差从 `7/50` 增到 `9/50`。检出和连续浓度是不同端点。

原生 F32 与 φ64 的检出错误数在本次各 bank 中一致，未出现舍入跨阈值的解释。C7 两 bank 三模型检出错误均为 0，但其尾项独自触发分别为 `9/50` 与 `7/50`；K2 对应尾项独自触发为 `2/50` 与 `0/50`。因此全正检出或事件不变不能反证 Q 内连续响应压缩的损失。

### 源条件偏差链条

U 在两折 C7 测试 bank 的平均偏差都为负：`−0.165350`、`−0.337708 ppm`；在两折 K2 测试 bank 都为正：`+0.187783`、`+0.282407 ppm`。这与“源条件组成不同被同一个共享条件均值混合”相符。S 四类减少四个 bank 的绝对 bias，但 K2_1 的平方误差反例仍存在。

C oracle 的对应测试平均偏差为 `+0.064810`、`−0.023729`、`−0.128992`、`+0.047932 ppm`，方向不再固定为一源低估、另一源高估，主 MSE 也在四库下降。这个结果更具体地缩小了问题：**相同二维 XY 计数及同一粗高度×尺度类，不能保证来自不同候选源的连续三维状态具有相同的受体响应条件均值。**把这些条件均值合成共享核，会在本次冻结状态分布上产生源条件偏差；“只要修正缺项覆盖，共享核就已充分”并未得到支持。

但此论断是对共同 Q 与两份 B4 源条件的诊断，并非一个关于所有源、所有风或部署输入的定理。C 与 S 非嵌套且 C source-aware，仍不能直接断言其胜出只由四类内残差而不是额外条件、参数及不同聚合构成。主结果必须和下述保存的类内差共同读取。

### 固定细类差：重现与反例同时存在

原保存汇总中，T0_E1 的 1301 个非零训练差行有 625 同号、460 反号、216 测试近零；T1_E0 对应 1344 行有 623 同号、460 反号、261 测试近零。很多小响应差不稳定，不能宣称每一个细类都具稳定源条件效应。

作为结果后的描述性补充，独立脚本将全部双方测试有支持的细类×位姿行纳入，按双方测试粒子计数的较小值加权，不筛选有利差值：训练/测试源条件差向量余弦为 `0.7577`、`0.7450`；训练差与测试差的加权平方差相对“测试差为零”的平方基准为 `0.4576`、`0.5619`。大幅响应组成的差异能部分跨实现重现，但约有 `22.19%`、`3.51%` 的测试差能量落在反号行。本项汇总是事后描述，不是新增模型、主端点、显著性检验或物理根因唯一性判据。

### 对 PRO 的单一研究决策

目前不建议进入 CSCG 训练或新增 24 份气体。建议将审核问题集中为：**如何构造能保留源条件受体响应的有限状态，并先与正确普通响应核、固定物理分箱比较？**当前证据支持继续研究“响应映射/状态压缩”这一具体组成因素；不支持把克隆模型视为必选答案。

如果 PRO 认可进一步验证，下一项前瞻实验应预先固定新源/受体几何、支持和预算，且同时包含 U、固定 S 与拟议表示；评分从候选源预测到真实观测，避免用真实来源选核或精确尾项制造部署收益。C oracle 只能留作机制参照。新状态至少应在未知生成源下保留真实候选相对排序，并通过固定 S 的反例，而不是仅降低全局浓度 MSE。新增计算及气体样本仍需另行有界授权，本轮不执行。

阶段判决为：`MATCHED_SUPPORT_CROSSFIT_ARITHMETIC_PASS / SOURCE_CONDITIONAL_RESPONSE_COMPRESSION_SIGNAL_SUPPORTED / FOUR_BIN_UNIFORM_SUFFICIENCY_NOT_ESTABLISHED / CSCG_AND_CLOSED_LOOP_CAUSE_UNPROVEN`。这里最后两项是证据边界，不撤销已经取得的积极机制信号。本轮无需继续寻找旧缺项或重跑定位。
