# 获批后的依赖对齐补充

用户于本轮明确批准“只生成并核验一个C1”。气体生成之前发现旧 underlay 的 core 位于 `9e93c36ae1af74f6a62c42f1c9d7b813153222ed`，且 MathUtils 中有历史盐化种子工程修改；这与当前固定官方 GADEN 声明的 submodule `1a20e35cd5f174ae9675a2ae3c796137a05c4ee5` 不一致。

因此本轮不再用旧 underlay 生成新 C1。隔离 workspace 中导出固定 GADEN 的 gaden_common 包、其声明的 gaden_core 及递归 submodule 原始 Git 版本，包括 DDA、GLM、compute、yaml-cpp；不影响旧库或另一任务环境。GUI构建是唯一非算法构建删选。官方core随机函数使用默认 `std::mt19937`，两个引擎初始seed均5489，不设 `GADEN_RNG_SEED`，不挑种子。保存默认引擎序列化初始状态与代码血统；高斯缓存由原程序初始化，不额外调用随机函数。

生成包装保留前述温度/压力参数绑定修正。另加一个被动记录钩子，在原 `AdvanceTimestep()` 前读取当前物理时间及风索引，在调用后检查新写出的帧文件，将该帧对应的真实保存时刻写入CSV。它不改变释放、随机调用、输运、保存判断或风推进。

第一次预处理使用旧依赖完成，只作为工程阶段记录；生成前必须在新官方依赖构建后再次执行官方预处理并验收。所有派生输出位于隔离目录，官方二维地图仍直接取作者固定原件。一次气体生成是唯一获批的 realization，不包括新的PMFS导航。

这闭合的是固定公开源码版本下的依赖合同；作者当年的完整依赖与历史二进制仍未知，不据此宣称完全复现作者的历史随机轨迹。
