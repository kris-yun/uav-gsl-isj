# RK2 有限原型的独立数值审核

判决：**PASS_INDEPENDENT_RK2_MATRIX_SCORE_METRIC_RECOMPUTATION**，冻结的 A 开发门结论复算为 `A_DEVELOPMENT_GATE_PASS_REQUEST_B_ONLY`。这允许提出 B 任务申请，不是执行 B 的授权，也不构成独立新物理验证或主创新成立。

本审核不导入 producer、rk2_models 或 rk2_infer。独立验证器只读冻结文件、计算矩阵目标与评分、在新的外部目录写 QA；优化调用和 φ/LOS 调用均为 0。

## 校验范围

- 7 项冻结源码、642 项父输入、18 项准备输入、12 项预测冻结 SHA 全部通过。
- 从 196 份旧参考缓存独立重算物理特征和路由，3 个训练计数矩阵 X 逐元素完全一致；3 个共同粒子均值先验最大绝对差 `2.303712776097e−15`。训练零响应保留、每份完整实现总权重为 1。
- S 的训练加权 z、sigma 中位分割一致。最终 L 为最多 4 叶、3 节点；没有真源编号路由。
- 3 个方法×10 受体共 30 个非负 query-ridge 目标、RMS 列缩放、梯度与 KKT 校验通过，λ 固定为 0.01。原始优化器状态并不自动代表最优；最终保存解满足冻结 KKT。最多 32 步 dual polish 仍解相同目标，没有修改 λ、训练样本或任务分数。
- 72 个训练 proposal 的日志选择和容量排除可复算。审核依据保存的训练损失确认择优，未重新求解 proposal 或提出另一套 L。
- 200 行候选参考读出与各候选 (2 参考×50 块) NPZ 对应。200 个压缩查询×3 方法、1600 个成本记录全部纳入，无困难查询删除。
- 16 个源任务结果由独立 mean Bernoulli log score、M=2 Jeffreys 平滑和共同温度 1 softmax 重新计算，全部一致。观察与候选先转 float32、每份候选实现独立阈值化后统计频率，未把平均浓度越阈值当作检出概率。
- 候选预测和源概率冻结先于测试压缩隐藏状态读取；真源映射只在评分复算后用于评价。审核前后 61 个运行文件字节不变。

## 源任务结果和必须保留的反例

| 方法 | 四任务等权源 NLL/nat | Top1 错误数 |
|---|---:|---:|
| F | 0.533544918630 | 0/4 |
| U_query | 0.539477111962 | 0/4 |
| S_query | 0.540125250520 | 0/4 |
| L | 0.533544918630 | 0/4 |

L 相对 U_query/S_query 的平均 NLL 增益约 **1.10%/1.22%**，Top1 全部已饱和。因此可以说通过预先冻结的有限开发门；不能说取得大的定位改善，更不能将源 NLL 改善换写为距离误差下降。

L 相对 S_query 的 4 个任务 NLL 均改善；相对 U_query 只有 3/4 改善。O03 的 L NLL=`0.624642344082`，U_query=`0.609817909716`，L 退化 `0.014824434366 nat`。平均收益不掩盖这项反例。

L 与 F 的全部候选参考事件频率相同，所以源概率和 NLL 相同。这是有限参考二值接口的保真，不能推导连续预测等于 F、对新参考实现必然同样保真或 L 超过 F。任务图是复合评分规范化，不是经独立校准的完整物理后验。

## 容量和成本

| 方法 | 活动状态 | 解码标量 | canonical 总字节 | 最小 Python runtime 字节 | runtime NPZ 字节 |
|---|---:|---:|---:|---:|---:|
| U_query | 789 | 7890 | 72588 | 73431 | 73404 |
| S_query | 2795 | 27950 | 257172 | 258127 | 258204 |
| L | 2328 | 23280 | 214272 | 215983 | 215796 |

L 的路由开销已计入，与 S_query 的共同容量限制通过；它仍比 U_query 大，不能称为相对所有普通模型更省存储。

200 个候选参考查询的本机 Python 原生物理读出 F 为 `1.636737900 s`，L 路由加解码为 `0.942500400 s`，局部读出时间减少约 42.4%。同一输入解析成本共同记录；这些墙钟数只可从原始成本记录汇总，独立审核没有重新计时。

候选参考训练支持无回退；200 个旧测试压缩查询 L 对 885 个缺核粒子调用合法预测侧物理回退，132 次 LOS。U_query 和 S_query 也使用同一回退政策。L 不读取观察侧真实尾项形成源预测。

共同传播成本没有降低。本机 Python 读出速度不是 C++/ROS、闭环或总物理仿真速度。离线训练、72 次划分 proposal、原始 KKT 早停以及唯一数值修复运行成本必须合并报告，不能只展示微秒级解码。

## 结论边界

结果表明一个受限、无观察隐藏状态输入的四叶响应树，在已查看旧材料上保留了二值候选预测，并以小幅源 NLL 增益通过冻结开发门。查询级普通基线没有完全消除本次有限表示增量，足以提交一项前瞻任务方案。

它尚未证明未知场景泛化、持续气体状态转移、CSCG 必要性、B4 唯一物理根因或正式原创主方法。有限树由旧参考数据构建，四份旧测试库也已被查看；后续 B 必须单独批准、事前冻结、包含普通基线且保留所有结果。
