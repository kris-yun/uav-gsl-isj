# RK2-A 最小合同独立审查

本文件只审查交付任务书与实现合同，不运行实验、不生成物理数据。依据是用户交接的《RK2_有限原型与单任务否证_待执行.md》及本轮粘贴说明。原 RK1、B4 和历史 STOP 判决均保持冻结。

## 1. 本轮可以回答什么

RK2-A 是旧材料上的一次有限方法开发比较：不让测试真实粒子组成、真实源标签或真实尾项进入候选预测，比较一个共享响应有限划分 L 能否超过按同一查询目标正确拟合的 U_query 与 S_query。它不再重复证明 RK1 的条件残差，也不验证长期状态转移、CSCG 或湖岸外推。

训练集固定为 C7_0/1 与 K2_0/1，旧留出为 C7_2/3 与 K2_2/3。后者已被历史研究查看，必须称“旧留出开发比较”，不能称新的独立确认。以完整 realization 等权；每份 50 个相关时间块不是 50 次独立释放。

## 2. 推荐并已沟通的单一 L 构造

采用一棵作用于全部粗 XY 格的全局共享轴对齐物理特征树：最多 4 个叶、3 个内部节点。特征固定为格内 x、格内 y、连续 z、sigma_cm。所有特征来自各候选自己的预测状态。这个全局树是任务书允许的有限树构造的一个受限子集；本轮不再尝试每格一棵树或其他聚类器。

每次只在训练数据上，从每个可分叶的四项特征的等 realization 权重 25%、50%、75% 分位切点产生候选。切点、分位数约定、等值归属、叶顺序、特征顺序、同分规则应在运行前写入合同。重复、常数或空子叶切点按冻结规则排除，不补随机切点。最多 12+24+36=72 次分区候选评估；最多三次接受切分。

每个候选都重建计数设计矩阵，使用与 U_query、S_query 完全相同的查询级非负 ridge 拟合。择优以全部训练实际访问查询的共同损失为依据。不能用逐粒子 phi 方差、单个 cell 的独立误差、测试浓度或测试源标签代替该目标。停止条件为容量上限、没有超过预定数值容差的训练损失下降或资源截止。无收益允许树停留在一叶，不强制四叶。

## 3. 查询目标、求解与数值资格

实际访问计划提供每份 realization 的 50 条主分支查询。四份训练总计 200 行；十个受体位置分块求解时每个位置为 20 行。其它受体/时刻的缓存可以提供同一先验字典统计，但不得偷偷增加某一模型的主拟合查询权重。第 40 块的另一时间分支只作为独立敏感性输出，不重复算入主训练/主端点。

对某一受体，把候选状态计数矩阵记作 X，原生总响应记作 y。列 RMS 缩放 D 和非负变量 beta 应对所有模型采用相同定义；beta 对应 h 的缩放表示。推荐合同已选固定 lambda=0.01，先验为等 realization 权重的逐粒子共享均值，并使用同一非负求解器最小化：

`weighted_mean((X_scaled @ beta - y)^2) + lambda * sum((beta - beta_prior)^2)`。

需要明示目标里的均值/求和、权重是否归一为 1，及梯度是否含系数 2；否则 lambda 的实际含义不一致。列 RMS 为零的列必须按共同冻结规则去除或只保留先验，不允许除零。这个固定正则化与缩放是共同实现规则，不是物理定律或经过独立验证的最佳值。

可用同一 SciPy L-BFGS-B，非负下界、maxiter=600、gtol=1e-8、ftol=1e-12。求解器返回 success 不足以证明非负最优性，建议每次最终解额外核查 projected gradient：

- beta_j > 1e-10：违约量为 abs(g_j)。
- beta_j <= 1e-10：违约量为 max(0, -g_j)。
- 统一容差：`1e-6 * (1 + norm_inf(Xw.T @ yw) + lambda * norm_inf(beta_prior))`。

保存绝对/相对 KKT 违约、迭代次数、停止原因和最终目标。最终臂不通过 KKT，应将方法比较资格 HOLD，不能凭较好测试指标宣称胜出。候选拟合未收敛也不能静默删除后宣称树是候选集合中的最优分区；应完整留档并把搜索资格标作不完整。

## 4. 容量与总成本

“最多四叶”不代表模型容量相同。活动 cell×叶状态数、受体解码系数数、非零系数数、路由节点/阈值/索引、计数/键索引、实际数组存储、运行峰值都必须分别保存。不要把 ZIP/NPZ 压缩后的大小当作常驻内存或有效自由度。

表达消融要求 L 活动状态及解码系数不超过 S_query 上限。实用比较另外把三个路由节点及相关索引的字节从共同 S_query 总存储预算扣除；若对应最少一个状态槽，应明确预留，不以“只有几十字节”免计成本。U_query 可以容量更小，实际较快/较省必须如实记入，不能为 L 强行填充 U 到同样大小。

本轮缓存只避免重复原生读出。缓存数组求和耗时并不等于真实在线 PID/LOS 求值耗时，因此不能据缓存计时宣布加速完整物理读出。应同时报告逻辑粒子/phi/LOS 数量、真实执行或复用次数、候选状态路由、编码计数、解码、回退、离线拟合和 L 的全部候选搜索成本。共用气体传播成本相同，不声称 L 已降低三维传播求解成本。

单轮方法构造与主预测总墙钟不超过 600 秒、峰值不超过 1 GiB，最多一版 L，不启动任何新 GADEN/CFD/ROS/VM/导航/网络。验证、画图、打包的成本可单列，但不能把 L 搜索/拟合拆到限额外。非有限、负响应、源血统错误或连续两次进度周期无进展应保存故障并停止。

## 5. 信息接口必须可检查

compression 允许显式读入评估物理快照，输出只是 oracle 压缩诊断。infer 是另一数据类/目录，候选端只读四份训练参考实现及许可受体计划；观测端只读真实气体读数、受体 XYZ/时间和许可环境。二者不能靠布尔选项混用。

infer 中每个假设使用自己的两份参考；共享字典可学习全部四份训练。候选名称是可置换的符号，不应硬编码 C7/K2 分支。预测侧缺项回退可以使用该候选预测自身的原生 phi，全部臂采用同一公开规则并计入成本；不可加测试真实尾项。

三项必须完成的测试：隐藏测试状态被替换/删除时 infer 输出不变；候选编号置换时预测及概率只按相同置换重排；没有测试真源映射也能先完成全部预测及规范化，标签只在预测 SHA 冻结后接回评价。这三项是候选推断资格，不是物理机制证明。

## 6. 主源任务与分流

各候选先分别对自己的 M=2 份参考读出并阈值化，再用 `p=(hit_count+0.5)/(M+1)` 构造边缘事件频率。禁止平均浓度先越阈值后冒充检出概率。所有臂使用相同阈值、先验、评分规范化和温度。推荐共同复合评分是 50 块 Bernoulli logscore 的均值，再以温度 1 的 softmax 转成二候选规范化概率；不要把它叫作已校准物理后验。

主开发端点为四份旧留出等权的真源 NLL，并同时报告逐 realization NLL、Top1 错误数、真假源相对 logscore、最差 realization。相关块不作独立样本显著性检验。若采用总 logscore 而非均值，必须在运行前冻结，并承认温度/证据聚合含义改变，不能测试后择优。

有限开发比较只有在 L 以相同信息、同一总资源约束超过 U_query 与 S_query，且源主端点有明确增量、Top1 错误数不增加时，才可以推荐提交下一新任务申请。10% NLL 降幅、每任务不恶化超过 0.2 nat 是交接任务书对未来 B 的候选实用门；如果本轮 A 借用，应另写为本轮新冻结决策规则，而不是称历史预注册事实。

L 仅超过旧 U，或仅改善 compression MSE，不足以进入定位主创新。U_query 追平/优于 L 且 L 没有资源优势，应停止当前有限划分构造。全臂 Top1 饱和但 NLL 无增量，应报告天花板/无新增价值，不能换评分、换时间子集或补 seed。无论本轮结果如何，B 仅设计、不得自动生成新的 12 份实现。

## 审查判决

`RK2_A_CONTRACT_ACCEPTABLE_WITH_EXPLICIT_INFORMATION_AND_BUDGET_ACCOUNTING`。

这个判决只放行上述受限旧材料原型的可执行合同，不证明 L 有效、树是主创新或低维状态已经封闭。输出须保留负结果，并把核心研究问题门、信息资格门、数值资格门、方法价值门及未来独立验证门分别列出。
