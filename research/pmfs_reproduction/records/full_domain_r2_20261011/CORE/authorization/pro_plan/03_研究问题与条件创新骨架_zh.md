# 研究问题与条件创新骨架——不是已验证的主创新

## 1. 可稳定写进研究对象的内容

研究对象：已知或明确受限释放条件下，复杂气体传播产生的源条件随机状态，以及无人机沿有限轨迹得到的局部气体/风/位姿观测。

科学问题候选：在有限计算与风场信息条件下，如何保留影响受体响应和候选源判别的传播状态，避免空间压缩与观测近似改变源位置证据，同时保持可验证的概率输出与短时预测？

这比“使用3D/神经网络改进PMFS”更具体，但仍需正确普通物理模型作对照。气体活动域、观测域和源候选域是不同对象，不能借导航mask绑定；二维源概率输出不要求内部状态二维。

## 2. 原论文边界

Ojeda、Monroy、Gonzalez-Jimenez，Robotic Gas Source Localization with Probabilistic Mapping and Online Dispersion Simulation，IEEE T-RO 2024，DOI 10.1109/TRO.2024.3426368。
公开作者版：https://arxiv.org/html/2304.08879v3

原论文已经讨论高保真前向的计算/边界条件代价、二维风场限制及检出抽象的作用。因此不能把“从二维到三维”“地图加网络”“模拟器换成GADEN”当作本研究首创。

## 3. 条件性主计算思想：响应保持的随机粗粒动力学

近期母理论候选：Christians、Wojnar、Pak，Probabilistic Forecasting for Coarse-Grained Molecular Dynamics，JCTC 22(9):4231–4246，2026，DOI 10.1021/acs.jctc.5c02131。
出版社：https://pubs.acs.org/doi/10.1021/acs.jctc.5c02131
预印本2025-12-30，期刊2026-04-21在线发表。不能把预印本年份/接受状态混写。

原领域链：细粒度分子轨迹 → 粗粒状态及有限历史 → 随机状态演化预测 → 长时构型与动力学统计。其价值在于建模演化，不只是读取完整原子状态后拟合最后一步输出。

对应GSL的拟议链：候选源、几何、风与已有观测 → 保留物理通路和受体响应的随机低维传播状态 → 候选观测分布 → 二维源概率及未来观测/羽流预测。

### 主机制

学习/构造可直接向前推进的随机状态，而非先完整生成3D银行再用静态树解码：

z[t+1] ~ K_theta(z[t], source, wind[t], geometry, history)

history项只是候选，不能因为垂向作用已证就认定必须有记忆。先与同参数量的无历史模型比较。不同源的状态组成不同，但受体响应定律共享。

### 两个辅助机制

A. 合法支撑与源注入：气体转移仅沿真实可达关系；质量/数量的非负性、注入和出界分别记账；导航安全域不替代气体域。

B. 实际受体生成：在受体位置/高度及设备条件下输出随机观测分布；保留间歇性，不把平均浓度过阈值当检出概率。不允许依据测试真实粒子或真源选择解码器。

输出：pi_t(s) = integral p(s,z_t | observed_gas[1:t], poses[1:t], permitted_wind, geometry) dz_t。Bayes/边缘化本身不是新颖性。

### 必须满足的进入条件

- R2表明正确普通物理模型在全域候选上有源概率/预测价值；
- 实际运算而非HGFS重复读写构成瓶颈；
- 具有足够的合法动态训练参考，且不同realization/源角色划分清楚；
- 普通固定层/Markov低维模型、全物理模型和目标模型可以同信息比较；
- 新方法减少的是主要传播成本，不是一个本已廉价、只调用一次的读出末端。

若这些不成立，本方向不启动，不能靠母论文级别来证明适合。现有R1不证明记忆必要，也没有跨环境训练效果。

## 4. 不再给海马机制强行匹配静态树

Sun等，Learning produces an orthogonalized state machine in the hippocampus，Nature 640:165–175，2025，DOI 10.1038/s41586-024-08548-w。
https://www.nature.com/articles/s41586-024-08548-w

该研究涉及序列语境下的隐藏状态推断。RK2静态四叶树不是其实现。只有将来发现“当前可用状态相同而历史能稳定改善未来响应/源判断”，才可讨论与序列隐状态的实质映射。当前不重启CSCG。

## 5. 在R2结束时应给出的决策

普通正确模型足够：整理机制与强基线，不编造算法必要性。
普通模型有用但动态计算过贵：把主要创新转向随机传播状态演化，进一步由Pro定下具体结构和可检验的二次创新。
正确物理预测也不能分源：研究信息条件或有限参考，不继续静态解码器拟合。
前向有用但地图比较不稳：以相同观测生成分布和普通事件反演为基线查证证据构造，不把任意校准称创新。

本轮交付评分/审查代码，而不是未经验证的神经网络。具体原型代码要服从R2真正暴露的剩余问题；不会把原假设先写成大模型再让数据迎合它。
