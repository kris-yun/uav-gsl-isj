判决：**LOCAL_HISTORY_PROJECTION_PASS / COMPLETE_RELEASE_HISTORY_ABSENT / NEW_3D_INITIAL_LAW_NOT_REGISTERED**。

这次实际解码了冻结过去前缀中的风、TF和clock，完成了独立哈希、时间绑定及非法输入拒绝检查。没有执行新羽流预测、CFD、GADEN生成或定位goal；没有读取真实源坐标、测试羽流状态或完整CFD来构造初态。本报告定位的是新LOCAL基线的输入/模型缺口，不是B4错误收敛的物理根因结论。

## 1. 纠正上一轮的时间估计

此前C1A报告将frame500前的释放历史粗估为约50秒，此说法不成立。原文件保持冻结，本报告另作纠正：

| 事件 | 实际证据 |
|---|---|
| 释放物理时间原点 | RunningSimulation的currentTime=0；保存frame0物理时间0 |
| 第500帧实际物理时间 | **267.307098389 s** |
| 本次播放器ROS锚点 | 11.095207360 s |
| 发送goal的ROS时间 | 60.404529720 s |
| 对应物理时间 | **316.616420749 s** |
| 捕获程序看见初始化完成标记的ROS时间 | 65.904652855 s |
| 对应物理时间上界 | **322.116543884 s** |

本次归档epoch、播放器锚点之后的时钟绑定为：

`t_phys = 267.307098389 + (t_ROS - 11.095207360)`。

315条初始化前查询时钟记录与该式一致。禁止向锚点之前外推该式，也不能用文件名乘0.1或0.5替代保存时钟。

**准确的原生startTime没有单独写入事件。** Algorithm.cpp第53行在等待定位后设置startTime，第55行打印完成标记；driver第175行记录的是稍后看到日志的时刻。日志里的1791623707.919…是logger epoch，不能当作节点ROS时间。因此只给出goal发送至标记捕获之间的初始化区间，下一次插桩应直接记录startTime和当时播放器绑定。这一缺口不要求恢复旧文件，也不妨碍本轮保守前缀审计。

## 2. 过去前缀实际包含什么

本轮在任何解码前固定截止点为goal发送时刻60.404529720 ROS秒，早于原生初始化。只允许原始局部测风、/tf、/tf_static及/clock；不用源结果、候选评分、真实气体场、/wind_value回答或未来风。风适配话题是同一原始消息的转换，不当第二次独立观测。

- 截止前原始风230条；拒绝超前时间戳等不合格消息后，保留215条。
- 其中186条可绑定本次物理epoch，184条在截止前收到的TF中能查询其**原始测量时刻**的传感器变换。
- 这184条覆盖物理时间267.407159464–316.116526369 s，最大内部间隔3.212973210 s。
- 全部来自同一静止测量位置，约(-0.9,0.15,-0.2)m；没有形成三维空间风场采样。
- 原始传感器是**二维风速计**，未观测垂向w。先前看过B4真值的审查者不能据此把垂向风/过去CFD传给新的LOCAL消费者。
- 0–267.407秒没有在本次物理epoch中绑定的局部测风。还存在截止到真实初始化之间的保守缓冲区，不能自行补为已观测。
- 原生PMFS在该截止前实际消费风0条；其第一条消费发生在初始化之后。若B1使用这些启动历史，须将它们作为共同公开输入，明确普通PMFS/GMRF如何接收；不能称为原作者N0原样信息合同。

TF即时到达与初始化时可用要分开：186条物理绑定风中，仅63条在原消息接收当时已经有足够TF；184条在冻结初始化前缀结束时可查询过去测量时刻TF。这种延迟TF是当时已经收到的过去信息，允许用于该截止点的初始化，不允许用于更早的在线预测。未返回TF的2条保留为未资格化输入，不以最新TF代替。全部过滤拒绝计数342是风/TF记录的合计，不代表342条风。

## 3. 单位和噪声不是原R4模型

原B4归档fake_anemometer.cpp第179–181行直接证明：

- `noise_std=0.3`给风向增加N(0,0.3²)弧度噪声；
- 风速噪声是该Gaussian抽样再乘0.1，即标准差约0.03m/s，之后`max(0,...)`；零风速是删失结果，不能直接当普通高斯点密度；
- 正常传感器局部帧采用FROM，TO世界方向通过原始stamp的TF和π转换；固定地图参考模式另有不同方向定义，不能混用。

本轮同时读取了当前源与归档源。两者SHA不同，资格判断以归档B4源码及归档生效参数为依据，不能将当前混合工作区自动冒充当时的二进制。这里只确认公开仪器公式及单位，不声称风场先验或整个概率模型已经通过校准。

PID仍为ppm、model30、correction=false。没有解码气体CDR或使用实测浓度校准本次初态。R4的mg/m³、二维周期域、零初态和Gaussian sd0.02不能直接搬入。

## 4. 哪些已被合同覆盖，哪些没有

原执行合同R4-1第54、58–62行覆盖同物理时间及公平本地风权限，真风只能单列oracle；R4-2第68–72行覆盖保留旧传播状态、普通风不确定性过滤和合法序贯/事前声明proper-composite预测；第153–156行覆盖共同源支持、独立评价及冻结端点。这些足以支持本轮只读输入/工程资格化。

但R4已经执行、冻结的是二维周期有限体积、从物理释放起点开始的零气体初态和25点候选。**没有预注册B4的三维未观测过去风分布、搜索初态分布、垂向/空间风先验及ppm预测概率读出。** C1A工程fixture也没有补齐这些科学决定。

因此：可以现在完成过去输入投影、单位/时钟/角色隔离及拒绝规则；不能把某个临时选择的三维先验、sigma、历史长度、参考数或候选高度说成已经得到R4预注册授权，更不能先在已见B4上比较几种先验后择优。

## 5. 最小科学对象与否证门

从公开释放起点`t_release=0`构造零状态是合法的生成初态；**在搜索开始重置为零羽流是不合法替代**。对每一个共同候选s，搜索初态应是：

`π(X_search,U_unseen,q | s, public geometry, W_local_received≤cutoff)`。

这是未知早期风、空间/垂向风、释放及随机传播状态的分布；先通过候选条件三维输运推进到真实搜索时刻，再边缘化预测受体响应。用截止前的观测条件化更早潜变量可以是合法的初始化推断，但不能用未来风、真CFD或真源标签消除其不确定性。

输出须包括447格共同源质量、候选条件受体响应概率、候选间命中方差、可回放状态和参考充分性证据；不是把局地点风速直接推广为确定的全域3D场。一次SampleConcentration的ppm不是完整预测概率。

事前冻结并检验：无未来/禁用字段访问；初态非负与质量/出口边界；公开释放/年龄一致；源与高度支持一致；参考RNG独立且状态可回放；源盲参考预算；序贯似然不重复传播格或二值信息；MC误差与计算成本；不能以B4最终误差决定先验或参考数。有效校准必须来自独立、允许使用的物理数据或事前物理约束；这184条同位置测风不提供未观测267秒或全域垂向风的独立校准。
