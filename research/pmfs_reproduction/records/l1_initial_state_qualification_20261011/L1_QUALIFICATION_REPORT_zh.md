## 3. 确认的实现错误：把气体阻挡的域外面设成开放风边界

冻结L1合同和风构造代码把几何Outlet及OOB面一并设为开放。原锁定GADEN `RunningSimulation.cpp` 第256–267行却将`OutOfBounds`与`Obstacle`同支处理：退回previous，将剩余移动投影为沿边界的分量，再递归移动。第269–270行仅对`Outlet`返回出口，随后移除丝团。`Environment::at(indices)`对越界索引返回OutOfBounds。新SampleWindAtPosition没有改变这条气体规则。

因此，当前风先验的开放域外通量与气体算子的阻挡/滑移边界不一致。**这是我构造L1风场时的实现错误，不能归咎于原PMFS。**审核反馈提出后，已用原源码和存储数组独立核验，停止了依赖该场的气体计算。

| 外界面 | 接触该面的自由格面数 |
|---|---:|
| x低 / x高 | 703 / 3688 |
| y低 / y高 | 533 / 2208 |
| z低 / z高 | 9910 / 1335 |
| 合计 | **18377** |

这些应与气体规则一致的面上，当前单位基底最大法向速度绝对值为**5.88588953m/s**。这是单位模态值，不是实际B4真风，也不是合成随机实现的最大速度。独立包保存全部18377面所属格/方向和24模态值，可离线重算；没有修改气体OOB为出口来掩盖问题。

本次几何统计使用索引数组边界。原环境坐标转索引还采用GLM浮点到整型转换，连续坐标最小边界附近的行为须在未来实际原生接口资格中核验；没有把本次索引级检查升级为连续NS边界或原B4定位根因证明。

## 7. 对原PMFS与论文主创新的结论

原B4错误收敛证据保持；本轮没有新源后验、MAP或定位成绩。L1无资格作为强普通3D基线参与方法比较，也没有反证其总体理论。R4中普通动态模型足够的受控数学结论仍在，不能借当前实现错误重启R5网络。

下一科学判断需要有效物理边界、可靠有限参考和原生消费链共同成立。当前成果是明确并量化了新基线的两个阻塞：**边界不一致、有限参考退化**；还没有把它们证明为旧B4的物理失效机制。
