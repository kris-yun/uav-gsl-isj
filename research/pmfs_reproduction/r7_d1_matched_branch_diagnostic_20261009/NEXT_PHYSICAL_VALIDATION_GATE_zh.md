# 下一关：独立物理验证样本的冻结要求

本文件记录用户审核合同中的下一阶段资格要求。本轮未生成新样本，也未选择新的源位置、路线或种子。

1. **源支持合法。** 运行前冻结源XYZ及其三维释放几何；源点应在允许的物理释放域与方法候选支持域的交集中。二维投影、边界约定和传感器高度可审计。若研究障碍/墙面源，事先声明扩展的源支持模型，不能为单个真源事后开孔或增加候选。
2. **时间与输运合同可追踪。** 保存实际气体帧时间、风帧时间、循环/保持规则、单位、释放及扩散参数、原始传感器时间戳和TF。若检验时变风历史失配，样本观察时段必须实际包含已核验的风条件变化；R7恒定第10帧不能承担该验证。
3. **对照与预算预先冻结。** 同一数据、合法候选支持、源盲输入、采样距离和观测预算；事先区分固定候选预测库的配对评分、相同随机初态的算法分支、完整系统闭环。保存每层实际状态，禁止事后选路线、阈值或种子。
4. **独立验证数量可说明。** 冻结多个独立源/风/生成种子条件以及时间隔离规则。连续帧和同一停留点的相邻强检出不自动算独立实验。先检查可辨识性、相关性及原生基线，再评价物理证据方法。

物理主张的准入门：源表示、物理时间和参数血统合格后，仍出现可重复、能与工程配置及观测不可辨识区分的源—受体预测冲突。合格前维持 `PHYSICAL_MECHANISM_HOLD`。既有R7、D0、D1作为冻结诊断证据保存，现有STOP判决与开题报告保留。
