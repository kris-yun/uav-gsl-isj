# 应该改PMFS的哪一步：观测一致的整羽流鲁棒源证据

日期：2026-09-26。性质：一个具体的开发建议及有限字母表数值原型，不是新主线的科学PASS，不是历史路线的恢复。

## 直接决定

改“观测→候选源证据”这一层，保留PMFS的候选源、源先验、模拟器接口和概率图输出。不要继续从独立filament生成函数入手，也不恢复FULL协方差路线。

唯一母理论入口：分布鲁棒自由能思想——分开处理系统本身随机与我们不知道其分布这两件事。具体数值求解采用成熟的minimax log-loss/最大条件熵工具，不能把这些普通工具认领为原创。

候选二次创新：对一个source，每条完整plume realization只能有一套权重；不同probe/观测协议都是同一套整场样本的投影。构造“共享整场歧义→各观测通道”的鲁棒源推断，而非每个probe单独拟合或独立选择最坏模型。
