## 1. 本期真正的增量——不是增加一个神经网络

**最有价值的跨领域启发（P0）**：天文学FARSim(2026)明确区分原始电场信号与探测器最终trigger，把信号波形依次通过传感器电子响应、滤波和阈值逻辑。同理，PMFS的「某时刻候选气团占据频率」不等于真实「带延迟/时间常数/阈值的传感器hit概率」。这为**可否证的语义失配机制**提供独立原领域实例，但**一般传感器响应建模本身不是创新**。论文需要的预计算全场射电模板不能照搬到无逐源参考库的湖岸环境。

**最强普通采样对照（P0）**：Lorek等2026预印本CFI约束GMM将「先找到事件区域」与「控制有限权重方差」分开；定理要求高斯名义随机驱动且严格协方差条件，不能自动应用到PMFS循环高斯表或多气团联合路径。它构成AIMMD新机制的强普通竞争者，而不是证明AIMMD已经晋级。

**三篇ICML 2026强对照（P1）**：DAISI的逆向采样+预训练流同化、SURGE的扩散路径SMC校正、Savary等的GenCast基础上fully-adapted APF，都说明「观测引导≠正确后验」以及「高维PF提议机制已有优秀普通方法」。注意它们需要外部预训练的物理场分布；不能把无测试场的在线UAV方法与使用测试环境密集全场训练的方案直接公平对比。

**直接GSL原创性警示（P0）**：Marcolli等(2026)已经研究湍流气味源定位中加入自身位置感知噪声改善贝叶斯推断的条件性现象；若今后生物分支声称通过「加噪打破气味相关」首次解决气源定位，属于已有技术，必须改写贡献边界。

### 1. FARSim: a fast RF-chain-aware trigger-screening surrogate for radio detection of ultra-high-energy cosmic rays（P0_观测算子跨领域类比）
**身份**：arXiv预印本；2026-05-27首次提交；检索记录显示2026-10-29修订v4，修订时间需以arXiv版本页再核。作者：Xin Xu, Pengfei Zhang, Fufu Yang, Pengxiong Ma, Ramesh Koirala, Chao Zhang；领域：天文学/宇宙线探测。

**原问题**：用连续电场峰值是否越阈值代替经过天线、电子链、噪声和触发逻辑的真实探测，会造成探测率失配；单有高场重构精度不能保证触发准确。

**输入→状态→运算→输出**：粒子簇射参数、空间射电场足迹、时间波形模板、阵列/电子链设置与噪声。 → 三分量电场时间轨迹；滤波和数字化后的探测器电压状态；阈值/触发窗口。 → E(t,r)经天线/RF响应、滤波与噪声变成V_ADC(t,r)，触发指示为1{max_{t,c}|V_ADC,c(t,r)|>T}；真实触发还可使用窗口和多站门限。 → 站点trigger/no-trigger与阵列探测效率/触发区域。

**具体改造**：仅借鉴『物理场→时间响应→传感器事件』运算链：对PMFS候选源模拟因果浓度时间序列c_s(t)，经过已知一阶响应z_{t+1}=a z_t+(1-a)c_s(t-d)，再按窗口和阈值得到预测hit。对每条完整随机气团联合轨迹执行该操作，不能由逐时刻边缘占据率代替联合检测概率。

**GSL创新边界**：GSL已有传感器动力学、阈值检测与传感器校准文献；创新只能是针对原生PMFS源间判别的任务充足联合事件表征，在普通一阶模型/HMM上取得独立源排名收益。

**可否证实验**：构造两组等逐时刻占据边缘、不同接触持续时间的轨迹；比较原生occupancy、窗口Bernoulli、一阶响应、HMM与候选新机制的hit概率校准、MAP rank、Top-5%、Brier、同CPU成本；若普通响应模型已足够则不立新模块。

**部署信息与算力**：UAV实际局地浓度或hit、采样时间戳、传感器标定得到的阈值/延时/时间常数、位姿、局地风；无逐源全场真值。；原生轨迹上做线性时间滤波O(T)每源每轨迹；全场代理或射电参考库不可直接迁入。

**局限与证据**：文章依赖预计算ZHAireS足迹库，违反本课题在线无逐源全场参考库；气体检测机理不同。文中软件与数据按合理请求获取，未发现公开完整作者GitHub。论文作者报告的波形R²不等同本研究hit校准。；arXiv全文§4时间波形/RF触发与Data, Software and Code Availability；未本地复现。

**论文**：https://arxiv.org/abs/2605.28373；**代码**：作者声明按请求提供，未核验到公开作者仓库。
### 2. Robust Importance Sampling for Rare Events via Constrained Gaussian Mixtures（P0_AIMMD最强普通竞争者）
**身份**：2026-10-05 arXiv预印本；作者代码README称NeurIPS 2026，未由官方程序独立核实正式论文身份。作者：Paweł Lorek, Rafał Nowak, Rafał Topolnicki, Tomasz Trzciński, Maciej Zięba；领域：统计学/NeurIPS候选稀有事件。

**原问题**：普通蒙特卡洛极罕见事件无命中导致冷启动；直接最小化KL可能形成过窄提议分布，导致权重方差无限。

**输入→状态→运算→输出**：名义高斯随机向量X~N(mu,Sigma)、事件g(X)>gamma、抽样预算。 → 覆盖阶段中间阈值、GMM混合均值/协方差/权重、IS重要权重。 → 先用渐进level覆盖事件集，再约束GMM提议分布p(X)并做KL拟合；估计E_p[1_{g(X)>gamma}f(X)/p(X)]；若所有协方差Sigma_k ≻ 0.5 Sigma，则最终受约束GMM重要采样估计方差有限（不保证有限预算精度）。 → 概率估计、权重ESS和方差估计。

**具体改造**：只有在完成PMFS联合随机过程与高斯随机驱动的可重放定义之后，才能将『联合hit事件或源评分差阈值』构造为g；采样后必须以合法联合路径权重纠偏。优先作为AIMMD关键路径采样的普通强对照。

**GSL创新边界**：并非气体源定位特有方法；也不修正真源前向模型系统偏差。PMFS循环高斯表使独立Gaussian输入建模需重新证明，不能生搬作者定理。

**可否证实验**：同CPU比较原生MC、普通IS/WE、OCBA、CFI约束GMM与AIMMD；独立pilot和评估分离；分别统计真源近零响应是否恢复、源评分差RMSE、rank和校准，不仅比较事件命中率。

**部署信息与算力**：不需要在线全场真值；需要已核实随机驱动、候选传播模拟器和合法权重。；CFI训练+GMM拟合额外成本；CPU/GPU实现可用，pilot计算必须计总预算。

**局限与证据**：定理仅适用于所定义高斯名义分布与符合严格协方差条件的最终GMM，不自动覆盖flow refinement、相关伪随机PMFS和源排序。作者称NeurIPS收录但官方记录尚未独立核实。；arXiv全文定理1，GitHub官方仓库README。

**论文**：https://arxiv.org/abs/2610.07485；**代码**：https://github.com/lorek/robust-cfi-is。
### 3. DAISI: Data Assimilation with Inverse Sampling using Stochastic Interpolants（P1_条件成立时的强深度同化基线）
**身份**：ICML 2026正式收录，PMLR 306:2787-2830；2026-07会议。作者：Martin Andrae, Erik Wikingsson, So Takao, Tomas Landelius, Fredrik Lindsten；领域：气象/高维数据同化/ICML。

**原问题**：EnKF高斯近似在复杂非线性动力和观测算子下失准；每次同化重新训练模型成本过高。

**输入→状态→运算→输出**：预训练生成先验、任意可用预测模型、稀疏带噪观测与观测算子。 → 随机流生成的高维场状态与预测条件。 → 先逆向采样引入预测先验，再用观测条件guidance采样；同化时不用为每个预测模型重新训练生成先验。 → 隐藏系统状态的非高斯同化样本及不确定性。

**具体改造**：只能在FSR/GADEN离线生成可核验训练场时尝试训练流先验，把二值传感器事件似然作为观测算子，源后验需另行推断；不许使用未来场或逐源真值作为在线输入。

**GSL创新边界**：属于普通数据同化强方法而非气体源定位新颖性；无法单靠它证明来源可辨识。

**可否证实验**：与PMFS、PF/HMM、EnKF、作者同化模型在同数据/同先验/同CPU和同源概率评分协议比较；先测试状态同化再评估源MAP rank与Brier。

**部署信息与算力**：沿途浓度/风/位姿/地图可用；预训练场分布只能来自公开或自建离线数据，不可偷看测试真值。；需要离线生成场数据、预训练flow、推断多步采样；显著高于轻量HMM，须实测GPU时间。

**局限与证据**：作者仓库SQG数据生成/预训练checkpoint依赖明确；仓库README引用示例中作者列表与PMLR存在差异，归档以PMLR为准；无湖岸气源真实验证。；PMLR 306论文记录及作者GitHub README。

**论文**：https://proceedings.mlr.press/v306/andrae26a.html；**代码**：https://github.com/Erik-Wikingsson/DAISI。
### 4. SURGE: Approximation and Training Free Particle Filter for Diffusion Surrogate（P1_后验纠偏理论与普通强对照）
**身份**：ICML 2026正式收录，PMLR 306:134046-134074；arXiv 2605.18745存在标题/版本变化，归档以会议正式题名为准。作者：Lifu Wei, Yinuo Ren, Naichen Shi, Yiping Lu；领域：概率计算/动态数据同化/ICML。

**原问题**：扩散观测guidance改善视觉吻合却未必来自正确后验分布。

**输入→状态→运算→输出**：预训练扩散动态代理、序贯稀疏观测、观测似然和粒子群。 → 扩散轨迹与对应的重要性权重/粒子。 → 在路径测度上按观测似然更新SMC权重并重采样，对引导轨迹做必要概率纠偏。 → 近似正确的状态后验粒子群和预测不确定性。

**具体改造**：作为『PMFS路径采样／神经引导不应改变目标后验』的强方法学对照；须先定义多气团联合随机性、条件观测似然及权重，之后评估源概率校准。

**GSL创新边界**：不是气体源定位方法；原始目标是扩散生成状态后验，不是任意离散源标签/原生PMFS占据概率。

**可否证实验**：比较未校正引导与权重校正的校准、ESS、重复计算成本和真源rank；若即使精确后验仍错源，应归因前向物理/观测定义，不能归因采样。

**部署信息与算力**：当前浓度/hit、局地风/位姿与训练代理；真实多气团流场在线不可得。；预训练扩散动力代理+多路径SMC，采样成本高；不适合当前最低成本首选。

**局限与证据**：未核验作者公开SURGE正式实现；仅确认正式论文与有关arXiv版本，未运行模型。；PMLR正式会议页面；注意早期arXiv标题存在不同版本。

**论文**：https://proceedings.mlr.press/v306/wei26w.html；**代码**：未核验到正式论文作者实现。
### 5. Training-Free Bayesian Filtering with Generative Emulators（P1_强普通粒子滤波基线）
**身份**：ICML 2026正式收录，PMLR 306:107889-107912。作者：Thomas Savary, François Rozet, Gilles Louppe；领域：气象/非线性粒子滤波/ICML。

**原问题**：传统高维粒子滤波权重退化，普通预测提议不利用新观测导致低有效样本数。

**输入→状态→运算→输出**：现成扩散天气动态模拟器(作者实验用GenCast)、上一时刻粒子、新观测、观测掩码及噪声模型。 → 带权高维天气状态粒子，接近最优条件提议q(x_{k+1}|x_k,y_{k+1})。 → 用生成模拟器和观测得到的条件提议进行fully-adapted auxiliary particle filtering，并使用协方差膨胀控制权重退化。 → 后验天气场状态粒子与不确定性。

**具体改造**：给PMFS历史流场与传感器事件滤波提供粒子权重退化诊断，不建议直接调用全球GenCast作湖岸微尺度源模板。

**GSL创新边界**：已有成熟FA-APF原理+2026生成实现，不能将优化PF提议当作气体源新理论；必须比较普通PF、APF、HMM和同输入的PMFS。

**可否证实验**：固定候选源、模拟轨迹和观测时间，仅比较bootstrap PF、APF、FA-APF和新机制源间评分/校准/ESS/时延。

**部署信息与算力**：实际只有沿途局地观测，适用必须具有该环境可用的经过验证的生成动力预测器。；使用大型GenCast/ERA5预训练权重，硬件和存储成本高；作者仓库含配置和filtering/fa_apf.py。

**局限与证据**：标题的Training-Free是对生成代理基础上的滤波器无需额外训练，不意味着不用预训练GenCast；不能拿训练全场隐式输入比稀疏普通基线。；PMLR正式论文、作者GitHub README/代码结构。

**论文**：https://proceedings.mlr.press/v306/savary26a.html；**代码**：https://github.com/ThomasSavary08/FA-APF。
### 6. Noise enhances odor source localization（P0_仿生噪声策略已有技术查重）
**身份**：2026-01-12 arXiv预印本；已在气体/气味源定位领域，不能归类为外领域首次迁移。作者：Francesco Marcolli, Martin James, Agnese Seminara；领域：GSL已有技术/仿生嗅觉。

**原问题**：湍流羽流时空相关会影响多传感器源定位信息，特定配置下知觉位置噪声反而改善贝叶斯估计。

**输入→状态→运算→输出**：分布式多传感器阵列的二元气味读数、带误差的自身位置、本身推断模型。 → 源相对位置二维后验，定位不确定性。 → 在知觉坐标中注入/建模噪声，改变似然几何和时空相关，寻找适当噪声尺度。 → 更准确或更稳定的源相对定位后验（只在论文指定条件验证）。

**具体改造**：作为已有GSL强近邻和批判性反例，不移植成主创新；可与两无人机/机体三探头有无额外感知噪声对比，但必须区分物理运动扰动与纯观测误差。

**GSL创新边界**：这篇本身已是气源定位，添加自感知噪声绝不能声称首次跨领域迁移；传感器布局与用户单机沿途采样不等价。

**可否证实验**：保持真实位置/航迹不变，只在推断端添加合成位姿噪声，与零噪声及校准位姿误差模型比较多seed真源rank/Brier；若现实GPS与地图误差条件下退化则拒绝。

**部署信息与算力**：实际位姿误差估计、时间戳和沿途多探头可得，但论文大规模固定/分布式传感网络信息未必可得。；基础贝叶斯后验核算，较轻；多噪声尺度搜索额外成本。

**局限与证据**：模型假设多传感器空间分布及湍流条件，效果条件性强；未核验该论文新增实验的独立完整可执行作者代码，正文仅给早期CFD框架外链。；arXiv全文、PubMed条目标注为预印本。

**论文**：https://arxiv.org/abs/2601.07445；**代码**：未核验到论文作者新的完整实现；只有相关早期CFD代码说明。

## 3. 用户研究：一个可立即执行的最小机制判定实验（不是宣称效果）

固定原生PMFS候选源集合、随机种子、真实位姿与过去风输入、每源相同CPU。对每条候选的**完整联合气团时序轨迹**，定义浓度驱动 $c_s(t)$、传感器内部态 $z_{t+1}=\alpha z_t+(1-\alpha)c_s(t-d)$、实际报告 $h_t=\mathbf 1\{\max_{\tau\in W_t}(z_\tau+\epsilon_\tau)>T\}$，使模型预测 $P(h_t=1\mid s,\mathcal H_{t-1})$。对照原生占据边缘率、普通window Bernoulli、普通一阶时间响应、普通HMM/切换滤波，**最后**才加待创新联合历史表征。

必须首先做“同逐时刻接触边缘率、不同连续接触长度”控制实验；若源间hit似然没有改变，说明这类历史表征不必要。否则衡量不同源对的源评分差、真源rank、Top-5%、Brier/ECE、误报率及CPU。E3/B4真源前向无响应时，区分「源本身物理不可能」与「观测窗口定义错」与「模型截断不足」；若真实源仍被高预算前向判0，禁止用仅提高MC速度解释为恢复定位。

风况变化压力轴必须包括稳风、风向反转、突变、不同气团到达时延；所有在线方法不得读取未来风或全场真值。以不依赖旧随机数表的独立随机驱动验证一次结构适配A′是否改变原始统计目标。成本与模型训练投入按CPU/GPU实测，试探和预热全计入预算。

## 4. 结果与止损门槛

当前**没有实测主创新晋级**。解释应分三项：A. 传感器事件意义不一致；B. 风历史不可辨识；C. 正确事件似然下的源本质不可区分。若普通时间响应/HMM解决A，则把它作为工程校准，不得算跨领域主贡献。若高预算校准后仍C，优先考虑反证采样而非更复杂生成器。若只是MC方差问题，要超过同CPU OCBA/普通IS/CFI约束GMM/普通WE后才讨论AIMMD。
