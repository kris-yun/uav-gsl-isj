# 跨领域主创新文献雷达（UAV 气体源定位）

- 建立日期：2026-10-17。
- 更新频率：每两天，关联 ChatGPT 自动文献雷达。**自动任务已启用；GitHub 写入是否成功需以当次任务提交记录为准。**
- 用途：研究未知湖岸环境下，利用实际沿途浓度、局地风、位姿与在线地图，将源位置表示为二维概率分布，并经真实反馈闭环检验。
- 严格禁止：以测试现场逐源全场浓度/真风作为部署输入，未来观测泄漏，复用开发数据冒充独立确认，把接口工程修补或基线已有机制包装成创新。

## 文献条目的统一评价框架

1. **真实来源**：标题、期刊/会议、DOI、论文和作者代码、正式/预印本身份以及核查日期。
2. **原领域的具体困难**：触发条件、错误假设、实际失败端点。
3. **核心计算机制**：可见输入、隐藏状态、关键公式/算子和明确输出。
4. **气体源定位迁移**：现有GSL/PMFS缺口、额外假设、输入权限、计算预算、物理边界和可能退化条件。
5. **最邻近工作的重复性检查**：相同功能是否已由普通概率校准、HMM、Beta、源项联合反演等实现。
6. **实证分层**：理论候选 / 数值玩具 / 真实观测固定历史 / ROS独立闭环 / 湖岸野外。未运行不得升格。
7. **裁决**：GO（科学机制与强对照增量均通过），HOLD（机制候选但缺有效数据），NO-GO（强对照解释或否证）。保留所有反例。

## 当前核心课题与控制

- **近期源代码和原生数据科学线**：PMFS在连续hit/no-hit间歇输入下，观测侧的log-odds接触信念是否与候选模拟的时间占据频率表达同一物理统计量；是否导致真实源相对证据改变。
- **湖岸后续线**：局地风与气体实际传播历史不同步时，是否发生真实源错误解释。
- 凡仅改善预测分布却不能改善真源排序与任务端点者，仍是模型校准而不是主创新。
