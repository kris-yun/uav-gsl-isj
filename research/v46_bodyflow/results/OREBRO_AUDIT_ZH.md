# 本轮直接完成的公开实测数据资格审计

## 资源与范围

官方仓库：<https://github.com/jburgues/Orebro3DSEN>。固定提交 `d5a55a0fc5e77b95456fbb7be62bc8154508dbee`；10 个官方 CSV 已实际下载、按 SHA-256 校验并解析。原始仓库 README / LICENSE / parser 同时保存，数据与代码按其 GPL-3.0 许可提供。本工程只发布审计脚本、摘要和哈希清单，不把大体积原始数据混入论文 ZIP。

这是固定阵列的**字段和资格审计**，不评价新 M1 定位效果，不构造无人机移动后的反事实观测。所有 10 组均已用于本轮可用性检查，后续不得称这些摘要为未经查看的独立形态门测试。

## 对 V46 理论和代码的直接影响

1. **原始负值必须留存。** 可执行参考链把整流限制在控制副本，后验仍接收原始 y；本数据说明此分流有实际必要，但不是 M1 优越性的证据。
2. **时间有效性不能只看采样标称值。** CSV 时刻单调、近似 2 Hz 已核对，仪器动态时延和跨探头时钟误差仍需额外标定，不能从 0.5 s 中位间隔推出感受同步。
3. **不能制造局地风。** 表中只有公共 `Wdir` / `Wspd` 两列，官方描述为房间中央风测量；不能复制为 27 个实测局部风向量，从而宣称完整 M1 流向输入已获实证。
4. **形态稳定和真实相干不同。** L1 差分位数在记录间变化明显；没有共同释放年龄标签与独立验证阈值，无法计算形态门的误拒/误放率。`Q_shape` 可描述而 `Q_coh`、`Q_model` 仍 UNKNOWN。
5. **索引不是米坐标。** `C_ijk` 标记 3×3×3 网格探头身份，本审计没有将索引擅自当作物理米坐标。
6. **运动闭环边界保留。** 数据来自固定阵列，未记录的新轨迹没有真实观测；不能据此做 M1 重构后的实际定位排名。公开 VGR 保存场在接口资格通过后才承担移动闭环验证。

## 复现

```bash
python3 audit_orebro.py --download \
  --commit d5a55a0fc5e77b95456fbb7be62bc8154508dbee \
  --data-dir data_external/Orebro3DSEN \
  --output results/orebro_qualification_audit.json
```

`results/orebro_qualification_audit.json` 包含每个原文件的 URL、大小、SHA-256、完整列名及全部描述统计。该审计没有选择“能让方法赢”的窗口、探头、阈值或源。
