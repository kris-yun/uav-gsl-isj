# V43 负结果与共享数值底座的独立复核

这个小包用于复现已经查清的代码与源强支持问题。它没有接入原生 S2 场、真实传感器时钟或飞行接口，**native 性能与主论文实验仍为 UNVERIFIED**。这里的成功只说明指定反例及修复可重现，不能据此声称 BIO 优于普通方法。

## 运行

需要 Python 3.10 或更高版本以及 NumPy、SciPy。首次复核实际使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0；每次运行都会把本机版本写入结果。

```bash
python -m pip install -r requirements.txt
python run_verification.py
python run_verification.py --closed-loop
```

第一条复核命令读取包内已经冻结的旧轨迹与原始观测，检查连续源强积分、XY 熵、两机连续距离及传感器延迟。在本次环境耗时约 0.35 秒。第二条命令额外执行三种旧控制模式各 20 步的共享 65 点源强支持诊断，在本次环境总耗时约 9 秒；它不是论文级多场景实验。

脚本均使用自身文件位置解析输入，不要求从某个工作目录启动，也不依赖原项目绝对路径。首次命令输出 `results/verification_quick.json`；包含闭环时输出 `results/verification_with_closed_loop.json`。`reference_results/` 保存此前复核的参考数值，不会在运行中改写。

## 四个可判别问题

### 1. 同一旧轨迹、同一原始读数，检查源强支持

`data/frozen_historical_observations.json` 只保存旧四点源强版本中三个模式的真实诊断输入：时间、位置、浓度及旧结果摘要。没有替换观测，也不重新选择轨迹。检查对每个候选源使用**整个历史共同的一个源强 q**，先形成联合响应，再对 q 积分；没有逐窗单独拟合 q。

`diagnostics/reference_repairs.py` 给出均匀先验 q∈[0.5,4] 下高斯似然的解析积分，函数参数不含生成真值。`verify_reference_repairs.py` 另用固定区间上的 4、17、33、65、129、257、513 个对数网格节点和梯形权重复核 log-uniform 先验的积分收敛。节点由区间与分辨率定义，没有把生成值 1.15 插入候选点。

必须区分以下口径：

- 原旧代码 `q_prior=1/4` 定义四个离散节点等概率。若它本就有意采用离散四点先验，问题是强度先验模型与生成过程不匹配；若四点意在代表连续先验，则是支持与积分分辨率未通过资格检查。不能把两者统称为求积器算错。
- 固定 log-uniform 先验的收敛序列使用梯形权重，端点权重为内部点的一半。旧四点等概率先验不是这条求积序列中的严格同一个概率模型。
- 解析 uniform 与数值 log-uniform 是两个不同先验。两者都能修正 MAP 失败，不等于其详细后验概率可作为同先验结果逐项比较。

预期结果：旧 BIO 路径对应的旧四点 MAP 误差为 4 m，正确候选源概率约 1.997×10⁻⁹⁴；保持该轨迹和全部读数，连续 uniform 积分的 MAP 回到 (0,0)，正确候选源概率约 0.99999999649。具体数值以 JSON 为准。

### 2. 非 oracle 的短闭环支持修复

`--closed-loop` 运行 `bio`、`bio_noidentity` 和 `ordinary_projected_full`。所有模式共享 `geomspace(0.5,4,65)`、每点相同离散权重、候选源域、生成模型及测量噪声种子。该网格由开发阶段的固定轨迹收敛检查选定，**不是前瞻预注册的性能实验**。65 个节点均不等于 1.15。

本次重跑三个模式的 MAP 均为 (0,0)，误差均为 0。路径长度分别为 32.625、43.875、45.900 m。这些单场景结果只用于说明此前失败不应被直接判作 M1 理论失败；不把长度差或同模型定位成功写成性能优势。路径变化会改变后续观测，各模式之间不能再称“同一数据的后验比较”。只有上一节的冻结观测积分检查严格保持同一数据。

闭环仍调用历史控制器，**仅改变 q 支持**。XY EIG 与连续避碰修复作为独立共享参考函数存在，没有偷偷同时接入历史闭环；这样才可以归因 q 支持修复。旧控制器的模型与安全接口也不具备部署资格。

### 3. XY 目标与高度边缘化

反例有两个源候选，它们 XY 相同而高度不同。定位目标 p(x,y) 只有一个可能值，真实 XY 熵及新 XY 信息增益必须为零。旧实现对三维候选索引求熵，得到 log(2)≈0.693147；参考实现先把重复 XY 的高度与源强概率边缘化，结果为 0。

该问题影响多高度支持时的评分目标。本次旧 4 m 失败使用固定高度，不能把它错误归因给 XY 熵问题。

### 4. 连续路径与延迟时域

两机常速度段的最小距离有解析解。所附反例在 t=0.05 s 达到 3.9998 m，小于要求的 4 m；旧每 0.1 s 采样的碰撞检查误接受。参考实现求整段连续最小值后拒绝该动作，返回安全悬停。这里只认证常速度线段上的两机距离；地形接口必须另行保证整段合法性，跟踪误差与执行裕度也需外部校准。

传感器例子使用 2 s 延迟及 1 s 时间常数。相同历史下，“移动”与“保持”在未来前两次读出的差为零，第 3 次才出现约 0.0092 的响应差。因此时域太短会使合法动作在模型中尚未可见；不能以这种评价直接否定方法。

## 文件来源与修改范围

`legacy_v43/` 仅包含运行所需的十个小文件：V41 底座加任务包中的 V43 修正覆盖层，以及六项旧科学断言。为保留原导入关系，包含一个很小的 V34 local-puff 适配依赖；本复核不调用它，也不把它称作原生 S2 后端。原文件逐字复制，SHA-256 记于 `SOURCE_MANIFEST.json`。

`diagnostics/` 从审计脚本复制，仅把源码输入、固定观测输入和结果输出改为包内相对路径；科学计算及默认参数不变。`reference_repairs.py` 是独立的共享数值参考实现，原历史源码没有被修改。`run_verification.py` 仅编排这些函数、保存环境信息并检查指定数值证书。

这里未验证的新 M1 原生执行接口、完整生成模型覆盖、同一真实时钟、全域模型差异界、复杂地形连续可达性、多源多种子统计性能，应继续保留 OPEN/UNVERIFIED。不能把本包的 PASS 扩展为这些项目通过。
