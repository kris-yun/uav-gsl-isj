# V46 可执行双通路参考实现

这里提供**真实运行的控制—观测—后验闭环**，以及尚待原生接入的精确边界。`v46_flowolf/core.py` 会计算候选原始响应、共同有限库评分、连续恒速安全、实际新观测和唯一后验更新；不是只返回接口占位。随包的 Green/ZOH 环境是明确给定的数学/软件参考模型，所有演示与 JSON 收据均不作为原生定位成绩。

## 运行

```bash
python3 tests/test_chain.py
python3 run_reference.py --output results/reference_run.json
```

依赖 Python 3.10+ 和 NumPy。原 V45A 六项代数/历史证书由总工程 `tools/verify.py` 保留。本目录内的新测试覆盖完整链路而非重复包装这些旧证书。

## 方法、源码和顺序

| 论文运算 | 实际函数 | 已实现范围 |
|---|---|---|
| 原始记录与不可重复计证 | `RawFrame` / `RawBlock` / `GaussianPosterior.update_once` | 物理 ID、真实时间、原始负值、历史保存，样本 ID 去重；重打包或重排行也拒绝重复 |
| 合格集合和窗口 | `Controller.observe` | 控制 mask 改变立即重启；控制资格与 raw 故障类型分别记录 |
| 因果气味记忆、体心位置、双极编码 | `Controller._encode_decode` / `m1_decoders` | 保留 V45A 数学核；gain/background 由物理 ID 对应；先掩码再归一化 |
| 两种运动读出 | `decode` | 一阶共同速度、分支二阶矩分别求逆、零和相对速度 |
| 共同候选和统一速度缩放 | `common_catalog` / `common_scale` | 所有方法共享 63 个参数化候选；固定语义 ID，先限速后评分 |
| 连续安全 | `ConvexBoxSafety.legal` | 凸长方体内完整直线段和机间连续最近距离；给定跟踪裕度；不冒充一般飞控保证 |
| 同 K 子集 | `Controller._shortlist` | 以 T、R、T+R 对共同库做近邻筛选；普通方法改变筛选输入，保持库/后端/预算相同 |
| M2 原始响应评分 | `Controller._score` | 每个相同 θ 行跨历史和未来共享 s/h/q；最小竞争源距离，或有限 Monte Carlo XY EIG |
| 四类科学资格 | `Qualifications` | 时间、形态、真实气团相干、前向模型分开 PASS/FAIL/UNKNOWN；安全独立处理 |
| 实际执行和新观测 | `execute_and_update` / `ReferenceWorld.execute` | 实际部分执行也保存真实路径；下一 raw block 更新一次 |
| 二维概率 | `xy_probability` | 对相同 XY 的 h/q 支持求和，禁止用完整三维熵冒充水平信息 |

参考 `update_once` 对所有有限合法负读数使用原始高斯似然。失格控制通道不会污染 χ，但其合法 raw 仍可更新。明确的 `SATURATED`/故障标志需要专门测量模型；本高斯参考后端拒绝伪造似然，保留收到的 raw 供补充模型后重算。

## 共同候选域与公平对照

参考域包含 9 个共同平移（静止及 8 个方向）与 7 个普通相对模板（零、扩展、收缩、正反转动、轴向拉伸、剪切）的笛卡尔积，共 63 个带固定语义 ID 的候选。相对模板按当前体心几何生成，对任意 N 保持零和。它是**本实验共同采用的有限动作域**，不能说成所有物理上可能的连续机动。用户可换更密库，必须全部方法共同更换并记录 J。

各候选先统一限速、再检验完整轨迹安全、再选至多 K 个并预测评分。评分后不另改 α 或偷偷执行另一条轨迹。若控制器被中断，后验使用已发生的实际轨迹，不沿用计划位移的秩结论。

实现的受控比较模式为：`m1_full`、`no_history`、`merged_r`、`t_only`、`r_only`、`no_polarity_t`、`upwind`、`ordinary_array`、`gradient`、`information_uniform`。后一模式以共同有限库的均匀覆盖取得 K 个候选，然后使用与 M1 相同的昂贵评分。完整库 EIG 是额外算力参考，不能声称低预算 M1 在同一准则下严格超过其最优值。

`score_kind` 可切换 `min_separation` 或 `xy_eig`，做机制比较时所有方法使用同一种。EIG 使用固定共同 Monte Carlo 抽样，允许有限样本估计为负，不能剪成零掩盖近似误差。主指标以二维源概率为准。

## 置换等变的精确范围

输入必须把**同一物理探头的 ID、gain、background、sigma、时延、历史、位置和风一起搬动**。程序按不可变物理 ID 规范存储，再用固定的候选 family/参数键决胜，输出可映射回调用顺序。不同存储次序得到完全相同的语义动作。

这不等价于随意交换真实传感器身份、不交换标定值，或任意重命名 ID；固定地图/候选方向/决胜键也不构成完整坐标刚体协变。T/R 内核的更强坐标性质保留在其自身适用范围。

## 资格与声明

时间 UNKNOWN/FAIL 时只做冻结时长的补测，然后以合格位姿覆盖。当前无气味先覆盖，避免无接触却无限等形态的死锁。模型 UNKNOWN 可以执行明确标识的、安全的 M1 探索和条件后验，不能生成认证源确认。模型 FAIL 回退到覆盖。形态稳定不推出真实气团相干，未知误差也不会被改写成零。

可选的 `confirmation_threshold` 默认禁用。只有明确声明的有限源域、固定模型和**全部已计证历史**的时间/模型资格通过时，才可按冻结 XY 区域概率规则给出 `CONDITIONAL_CONFIRMED`。该状态不等于校准的频率误报保证；当前一个 PASS 不能追认旧 UNKNOWN。PASS→UNKNOWN→PASS 仍保留撤销状态，直到有覆盖全部历史的合格依据并从原始数据重算。模型参数签名改变会拒绝在旧后验上继续相乘，必须新建后验对象并重放已归档 raw。

有限源/干扰 bank 的最小响应距离是候选评分，不是连续源域下确界的认证下界。未知连续覆盖、真实前向误差和物理独立校准仍保留 UNKNOWN。raw Fisher 理论与 M1 ReLU 编码是两条不同链；本后端的 raw 加性高斯模型也没有偷换为附录中对数噪声的 Green 对比信息模型。

`_score` 中历史路径已实现并冻结，它是联合响应的有限库设计诊断，不是对“历史已条件化”的随机量重复求 Fisher，也不是无条件自适应闭环 Fisher。要检验附录固定设计 Green 对比条件，应由更早历史确定动作，再取得两份没有参与动作选择的新验证窗。

## 参考物理与待接入原生项

`GreenZOHModel` 采用已知常风、扩散系数和释放时刻的单次三维脉冲。源位置、高度和强度在有限 bank 中共同推断。输入浓度取实际直线段中点，分段常值送入一阶传感器的精确 ZOH 递推，延迟为整数采样步。该离散定义在程序和世界一致，不能称连续传感积分或复杂边界输运的精确解。

`ReferenceWorld` 唯一掌握真源，只向控制器交付当前已发生的 raw block。预测器只接受指定 θ、先前状态与候选，不访问 world、未来场或真源。其测量噪声按世界样本号和物理 ID 固定，不因数组顺序改变。

原生 GADEN/VGR 的一次公共时钟推进、飞控轨迹、局地风校正、传感器误差及连续源预测器仍须按 `protocol/CODEX_EXECUTION_CONTRACT.md` 接入。数学/软件参考闭环跑通不代表这些接口已经通过。

## 实际成本

设 P 为联合源/干扰 bank 大小，J 为共同候选数，K 为实际评分数，N 为探头数，Hc 为控制记忆长度，Hp 为候选采样步数，Ho 为已有原始步数。

| 部分 | 本直接实现的成本 | 说明 |
|---|---|---|
| M1 记忆/编码 | O(NHc+Nd) | 固定 Hc/d 时才关于 N 线性 |
| 双读出 | O(Nd²+d³) | d=2；共享矩阵求逆 |
| 候选生成/筛选 | O(JN+JN A+J log J) | A≤3 个 M1 锚点，J=63 仅为本参考库配置 |
| 全候选恒速安全 | O(JN²) | 地图这里为凸盒；一般地图需另外计线段验证成本 |
| 源条件预测 | O(KPNHp) | 指定 Green/ZOH；CFD/复杂模型不是此成本 |
| bank 最坏距离评分 | O(KP²N(Ho+Hp)) | 本朴素实现对完整历史与未来比较，非全系统线性 |
| EIG（可选） | O(KBPNHp) | B 为 Monte Carlo 样本数；历史已在 posterior 中 |
| 新 raw 后验更新 | O(PNHnew) | 指定独立加性噪声与确定传感状态；一般联合协方差/粒子状态另计 |
| XY 边缘化 | O(P) | 分组表可预计算 |

运行收据同时记录真实昂贵预测次数、P/N/H、J/K 和安全 pair 检查数。一般方法没有固定 J 上界；若改成每机 L 动作的全联合枚举，J=L^N，不能拿 M1 的 O(N) 隐去该指数项。
