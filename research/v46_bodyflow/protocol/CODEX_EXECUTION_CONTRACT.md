## 4. 执行阶段与硬闸

### N0：运行已有数学与代码证书

运行总工程保留的六项 V45A 证书，以及 `tests/test_chain.py` 和 `run_reference.py`。核验 V46 full-chain 存储重排、固定 gain/lag、raw 重包拒绝、负值、mask 改变、连续最近距离、实际截断路径和全库同评分阴性。新增或修改内核须保留前后哈希及最小反例，不允许删除应有反例让测试“全正”。

Green 源信息的物理验证另有设计条件：先由**更早的历史**冻结 M1 动作，再采一份新的第一验证窗，执行已冻结动作，再采第二验证窗。两份验证窗的噪声不得再参与动作选择，才能把固定设计的对数对比 Fisher 结论用于该对照。若第一验证窗同时用于选动作，只报告已实现路径上的响应 Jacobian/设计诊断，或按完整自适应联合似然计算 Fisher；不得直接套 `EᵀE/(2σ²)` 当无条件闭环 Fisher。本参考程序 `_score` 只是固定已实现设计下的有限 bank 响应距离，未声称闭环 Fisher。

### N1：找到原始数据并证明接口资格

用 `preflight_native.py` 校验每个声明文件的 SHA-256、单位、时间支持和收据。每个 case 记录住宅/配置/源标签版本、真实 CFD realization ID、可查询范围、地图及传感标定来源。真实源只进入环境与终点评估器，不能传到提案/预测/停止规则。

必须实际写并运行 `clock_probe`：一次全局 `advance(dt)` 之后再同步读取 N 台；分别以 N=1 与 N=3 查询，确认查询本身不推进时间。同一 `(world_id, time, position)` 重复查询返回同一场状态，观测噪声按物理 ID/世界时刻绑定。不同无人机循环调用 `step()` 导致世界加速时，必须先修复，不能进入方法排名。

真实传感字段至少包含 `sample_id, physical_id, readout_time, sample/footprint_time, raw_y, position_xyz, velocity_xyz, ambient_wind_xyz, calibration_version, status`；风只有中央观测时须明确共同风近似，不能当作已校准局地风。时延、tau、饱和和故障状态按声明模型处理。全部负背景扣除值保留。

### N2：接入共同 B0，做一次小规模接线回归

优先调用已有正确普通前向和原始后验，不另用真源周围的支持网格。本目录的 `GaussianPosterior` 是固定 bank + 独立 raw 高斯噪声的实现；只有原生声明符合该条件时才可复用。否则实现完整块条件似然/滤波状态，清楚标记变更；原始数据账本原则不变。

每个 θ=(s,ν,m) 的释放/仪器状态跨历史与未来共同传递，不能每窗独立重拟合 q 以吞掉全部位置变化。q 的支持由独立任务/传感尺度给定，各法一致；不插入真实 q。对同一固定数据将 q 积分或网格逐级细化，直到 XY 后验最大绝对差 < 1e-3 且目标估计位移 < 共同 XY 栅格半对角线，并检查至少相邻两次加密；若预算不能达到则标数值未收敛。该 1e-3 是本合同的数值准则，不是统计错误概率。

先在三个既有开发住宅各一个原有配置、一个固定观测噪声 seed 做 300 s 接线回归：M1-FULL、普通逆风、普通阵列、同预算普通信息提案。它用于核对轨迹/时钟/预算/接口，不用来宣布优越。根据出现的具体错误做共享修复；禁止按输赢更换源、风、初始条件或丢掉回合。

### N3：冻结公平协议后做完整比较

冻结 `native_manifest.json` 中全部环境、配置、初态、数据文件哈希、源/干扰支持、采样、K、路径/速度/分离约束、参数、评分准则、随机数和硬件。数值单位/原有 native 参数以现有合格收据为权威；不将参考 Green 的 5 m 长度或虚拟 sigma 自动移植到住宅。只允许在开发阶段按尺寸/传感标定明确换算，变更须在看测试效果之前提交。

**时长固定为公共世界 300 s，主要原生终点为原函数 `ExpectedValue(sourceProbability, 0.05)` 所得水平位置的欧氏误差。** 双方二维概率图采用共同地图、相同函数实现和单位，另并列报告预定的共同 XY MAP 误差。记录预热是否计入这 300 s，并沿用已冻结原生基线口径；所有方法完全相同。不能多给 M1 传感等待/飞行时间，不能将 5 min/10 min 任选终点。若要报告时间曲线，300 s 终点仍为主，不提前选最优时刻。

噪声重复 seeds 固定为 `[2026102801, 2026102802, 2026102803]`；这些只是同世界观测/策略噪声重复，外层统计单位为住宅/CFD 配置，不能把它们记作独立流场。先完成冻结矩阵内的全部回合，再计算比较，不能达到显著性就停止。

## 5. 必须比较哪些代码

### 5.1 M1 机制受控比较（共同后端）

全部共享同一合法动作域、同一 B0、M2 评分、M3 状态规则、初态、物理预算和昂贵预测次数 K。参考实现提供 `m1_full`、`upwind`、`ordinary_array`、`gradient`、`information_uniform`。后者是通用候选覆盖加昂贵信息评分，不能冒称某已发表优化器的逐行复现；另有可复现强近似 EIG/GLR 原生实现时，应纳入并完整记录其调用预算。

全部数据驱动普通基线使用同一质量掩码和标定。普通梯度只拟合合格通道；二维仿射拟合秩不足时显式回退到合格风的共同逆风动作。普通逆风也只汇总合格风。不能让 M1 排除故障探头，而基线继续吃同一个探头的巨幅脏值，以此制造优势。

主要 K 固定为 8；成本曲线为 K=4、8、16，以及 K≥J 的完整库阴性对照。若原生库小于某档，明确实际 K=min(K,J_safe)。完整库对相同评分和决胜键必须给出相同动作；不相同说明实现或比较不一致。除安全剔除外，不能针对 M1 单独添加几何自由度。

主控制参数起始值随本代码保存：β=.65、Hc=8、vc=.35、vf=.8、λT=.2、vR=.5、εR=.15、L=5、u0=.1；它们是参考实现参数，不是已经在住宅验证的最优参数。尺度/速度按上述 N2 的物理单位审计冻结，并共同限制基线可行域；不可仅为本方法调有利的测试参数。

### 5.2 单因素删除消融

必须保留 `no_history`、`merged_r`、`t_only`、`r_only`、`no_polarity_t`。去位置关联使用预先固定、按物理 ID 的错误配对，保持浓度/极性边际值及预算；不能把随机重编号（应等变）错误当作去身份消融。时间门与模型门消融只能取消对应决策门，不能同时改变真实传感器或安全规则。

允许并预期出现：均匀场与规则阵列 T≈普通逆风；单支激活合并 R 与分支 R 一样；所有历史相同去历史打平；普通展开达到同一实际 D 时源信息一样；全库同评分动作一样；无气味或延迟窗内新动作不可见时无差异。保留这些案例，不称它们自动证明 M1 没用。

### 5.3 完整原生 PMFS 比较（独立算法层）

native PMFS 保留其原实现、置信/接触概率图、导航和源概率更新，不强改成本论文后验后继续叫 native PMFS。执行器、场世界、原始可观测量、300 s 时长、路程/安全预算及终点评估口径共用。冻结并记录原生 `ExpectedValue(sourceProbability, 0.05)` 实际源码所在文件/函数/commit及单位；参数0.05的语义以源码为准，不凭名字推断。该函数给出的300 s水平位置误差是主要原生终点；双方二维源概率须经同一共同地图与相同函数实现求值，核对栅格坐标到物理米的转换。共同 XY MAP 误差及概率指标为并列预定指标，分列报告，不替换主终点。

native PMFS 与本完整方法的差异只能归到整个算法；M1 贡献的归因依赖上一节共享 B0 的受控比较。源强积分、XY边缘化、时钟或碰撞修复属于共享卫生修复，不属于 M1 新收益。

## 6. 输出、统计与失败诊断

**主要原生终点**：每个回合 t=300 s，按原函数 `ExpectedValue(sourceProbability, 0.05)` 得到的水平位置与真源水平位置之间的欧氏误差。双方使用共同二维地图、同一已冻结函数实现和物理单位；核对栅格原点、分辨率、面积权重及坐标转换。共同 XY MAP 欧氏误差作为并列预定指标，不能与主终点混列或替换它。共享后端的受控机制组可另以同后端 XY MAP 比较提案效果，但须标明该组的统计口径，不称其为主要原生终点。补充统一XY分区的NLL、Brier、规定半径内概率质量、路程、前向调用数、墙钟、峰值内存、UNKNOWN比例、补测时间、错误高置信声明与安全中断。没有独立确认校准时，只报告模型条件后验质量，不写频率误报保证。

退出、超时、无接触和碰撞中断全部保留。时间型指标按300 s截尾，同时给失败率，不能仅统计成功回合。先逐住宅/配置得到配对效果，再做分组区间；少量住宅时描述限制，不能把传感器/重叠窗口/噪声重复当独立样本。

每个阴性必须写 `failure_class` 与最小证据：

| 类别 | 判定证据 | 应做工作 |
|---|---|---|
| IMPLEMENTATION | 数学恒等/ID/账本/候选/安全测试失败 | 最小反例与修复前后收据，重跑共同方法 |
| NUMERICAL | q/网格/MC/优化未收敛 | 固定同一 raw 数据，共同加密，不给本法插真值 |
| CAUSAL_INTERFACE | 时钟、延迟、实际位移与假定不一致 | 修接口，禁止解释为机制失败 |
| UNFAIR_COMPARISON | 域/K/时间/安全/先验不一致 | 统一并重做 |
| MODEL_UNQUALIFIED | 前向域/独立误差缺失或违反 | 保留 raw、条件后验和 UNKNOWN，不能宣告全域认证 |
| THEORETICAL_DEGENERACY | 零信号、共线、J_s落入Jν、扩散抵消、全域别名 | 保留真实反例，检查是否处于预期有效条件 |
| QUALIFIED_NO_GAIN | 上述均通过，同预算强基线仍打平/更好 | 如实接受经验阴性，说明适用域/代价，不换测试直到赢 |
| UNRESOLVED | 缺数据/字段/适配器 | 写清缺口并继续其他已授权审计；不得伪造结果 |
