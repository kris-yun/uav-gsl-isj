# 未知输入下的源判别：一次构造与反例审查

**日期：**2026-09-26。**交付类型：**理论—算法设计验收，不是实验结果。**最终状态：B，未形成独立构造。**

## 1. 一页部署合同

部署对象是一个固定但未知位置的单一泄漏。在线 `context` 只能来自**同一次泄漏、同一架 UAV 在决策时刻之前实际采得**的记录；候选源的目标环境模拟库不是 context。下面的“可得”严格区分仓库有仿真字段、可在一架机器人上测到，以及已经证明可在真实设备上测到。

| 量 | 离线仿真/训练 | 环境调试 | 在线同泄漏 context | Oracle / 当前缺口 |
|---|---|---|---|---|
| 候选源支持与地图 | E1 有几何选取的六源、30 probe、occupancy；可定义先验支持 | 地图需在飞行前建好并与 sensor/风坐标标定 | 地图可读取，但真源 ID 不能输入 | 仿真真源标签只用于离线评分；真实地图误差未量化 |
| UAV 位姿、时间戳、航迹 | House02 历史导航日志有 `t_sim_s,x,y,z` 字段 | 需要记录 TF、时钟同步、可达性和速度限制 | 机载里程计理论可用；本轮未验证设备精度 | 10×30 全场 probe 不是单机航迹 |
| 局部风 | 仿真日志有 `wind_u,v,w`；旧方向接口有语义冲突 | 需要风速计、map-frame downwind adapter 与 W0 实机检查 | 仅在装置及校准通过后可用 | 11 个真实仿真 wind arrays 和全场真风不属于在线输入 |
| 局部浓度与 sensor response | 仿真日志区分 `true_gas_ppm` 和 `measured_gas_ppm` | 需明确响应时间、检测限、漂移、采样频率、气流入口与延迟 | 只允许已标定传感器在已访问位置的过去读数 | 真实机传感器响应合同及误差界目前未落实；原浓度 cube 是 oracle 场值 |
| 源位置 `s` | 训练仿真可知标签、测试时仅候选集合已知 | 候选单元需映射到已知坐标和合法 source height | 真源未知 | 不可用测试标签选路径、调 nuisance 或校准 posterior |
| 释放率 `r_t` / onset `τ` | 仿真生成参数可能记录在 provenance | 实际泄漏起始及源强需作为有界不确定/未知 | 不可假定已知；只能由同泄漏观测约束 | 任意自由的逐时刻输入会消灭很多可辨识性；`r` 恒定和区间界目前未由部署证据保证 |
| 运输 `θ`、初始 plume `x_0`、过程扰动 `w_t` | GADEN 风与几何可作离线生成条件 | 若拟作 bounded family，必须给出真实流场偏差界、时间变化范围 | 至多局部测风；全场 `A(θ)` 不可在线直接读取 | 不能把风真值或自由未知函数默认为已知模型 |
| prior / 输出 | 离线可冻结候选支持和先验 | 若要概率图，须固定 likelihood、prior、噪声模型并校准 | 可持续更新同泄漏 posterior，context 只计一次 | 集合/拒判本身不是 PMFS microcell 概率图；任意 softmax 不是校准后验 |

E1 的 30 个 probe 是每栋 House 的几何采样合同，固定时间索引为 `100,150,...,550`；E2 OPEN 数组的形状是每环境 `6×4×10×30`。每个时刻同时读取 30 个固定空间位置的场值才得到 `10×30`；这不等于单架 UAV 一次航迹的 300 个读数，也不是 300 个独立样本。要改造成单机合同，必须事先有速度、路网、传感器响应和时间同步，并把 `H(p_t)` 定义为**实际到达位置和时间**上的采样。House02 的历史导航 trace 有这类列名，但对应另一批仿真/源，不能替代 E2 六源的配对确认数据。

## 2. 唯一尝试的命题及其假设

把状态、未知注入支持和不确定性分开：

\[
x_{t+1}=A(\theta)x_t+b_s r_t+w_t,\qquad
y_t=H(p_t)x_t+v_t.
\]

`s` 是候选 microcell；`r_t` 是释放过程；`θ` 是同一泄漏窗口内共享的运输参数；`p_t` 是合法 UAV 位姿；`x_0` 包含窗口开始前残留 plume；`w_t,v_t` 分别为过程和测量误差。移动主要改变 `H(p_t)`，不会控制泄漏输入。若 `r_t,θ_t,w_t,x_0` 全部任意自由，源区分一般不成立。

为测试一个尽可能具体的构造，**尝试**限制窗口内 `r_t=r∈[r_-,r_+]`、`θ∈Θ` 固定，onset 属于有限集合，传感器响应及噪声界已知。在给定合法时空路径 `P` 时，令 `g_s(θ,τ;P)` 为模型产生的单位释放观测序列，定义候选可行集合

\[
K_s(P)=\{r g_s(\theta,\tau;P)+g_{x_0}(\theta;P):
r\in[r_-,r_+],\theta\in\Theta,\tau\in\mathcal T,x_0\in\mathcal X_0\}.
\]

同泄漏的早期 context `C` 与后续记录 `Y` 必须按时间拼接为**一个**观测向量，且整个向量共用同一 `s,θ,r,τ,x_0`；不能先用 `C` 适配再把它当独立证据乘一次。尝试的对象是两个候选集合在该合法观测合同下的距离 `m_ab(P)=dist(K_a(P),K_b(P))`，或观测 `y` 到每个集合的距离 `d_s(y,P)`。这不是 source odds；若要 odds，必须另外固定 `p(s)`, `p(θ,r,τ,x_0|s)` 和噪声分布。

**尝试的命题。**若真实无噪声观测属于 `K_a(P)`、观测总误差范数不超过 `ε`，且 `m_ab(P)>2ε`，则 `b` 不可能也与观测相容。证明只有三角不等式：若同一 `y` 距两集合都不超过 `ε`，两集合距离至多 `2ε`。若两个候选存在 nuisance 参数使观测分布完全相同，任何源判别器在该参数点都无法保证区分。这是**固定模型族、固定路径、全局集合**上的确定性充分条件，不是随机羽流的有限样本定理。

**已知部分与新增部分的审查。**`ker(O)⊆ker(L)`、只恢复目标量、功能观测器、未知输入观测器和带噪集合分离都已有一般理论。这里唯一可能的增量原想是“同泄漏 context 约束一个共享运输 nuisance，再只证书化源支持”。但一旦将历史与未来读数正确堆叠进同一个 `K_s(P)`，它就是普通的带共同 nuisance 的集合逆问题；没有出现一个不同于现有 profile likelihood / set-membership 的条件、保证或更低成本更新规则。因此**不把上述命题标为新定理或主创新**。

## 3. 三个必须通过的解析反例

随包 `COUNTEREXAMPLES.py` 只核算以下小矩阵，不把它们当 GADEN 证据。

1. **完整状态不可辨识，源可辨识。**设 `x=(x_1,x_2,u)`，其中 `u` 可任意变化且不被观测；源 `a` 注入 `(r,0,u)`，源 `b` 注入 `(0,r,u)`，`1≤r≤2`；`H=[e_1^T;e_2^T]`。改变 `u` 不改变观测，完整状态不可恢复；两源观测分别在正横轴、正纵轴，互不相交。这个例子显示问题值得问，但恰是功能可辨识性的普通例子。
2. **源与 nuisance 别名。**只用合法读数 `H_1=[1,2,0]` 时，`(s=a,r=2)` 与 `(s=b,r=1)` 都给 `y=2`。若两边附加相同噪声分布，完整观测分布也相同。任何方法在这两个参数点都必须保留歧义；改变阈值或把输出强行归一化无法创造信息。
3. **一项合法观测消除歧义。**如果 UAV 实际可以在规定时间到达第二位置，加入 `H_2=[1,0,0]`。上例变为 `(2,2)` 对 `(2,0)`；且在 `1≤r≤2` 的整个集合中，第二分量对 `a` 至少为 1、对 `b` 恒为 0。若总误差界 `ε<0.5`，有 `m_ab≥1>2ε`。起作用的是新增位置的浓度通道，不是隐含源标签；但该传感器布置效应也属普通可观测性/观测设计。

三例同时说明：结构唯一性可以随着合法观测改变，且需要对未知率与未观测状态写明约束。`m_ab` 很小但非零时，有限噪声下会频繁误判；已知两点同方差 Gaussian 的简单特例中，等先验最优错误率为 `Φ[-m_ab/(2σ)]`，不能由“唯一”直接推出 12/16 realization 的定位准确率。过程随机性下应比较**观测分布**，而非两条不同随机样本的数值。

## 4. 算法合同审查：为什么不立项

若用这个命题实现，输入是候选支持、路径、共享 `Θ` 与释放区间、unit-response `g_s`、噪声界和同泄漏读数；每步为每个 `s` 优化 `r,θ,τ,x_0`，输出 `S_ε(y)={s:d_s(y)≤ε}` 并在集合重叠时保留歧义。离散化 `|Θ|=M`、观测长 `T`、候选数 `S` 且 `x_0` 已可处理时，穷举约 `O(SMT)` 次响应比较，储存 `O(S+T)`；若在线重算 transport，前向模拟成本会主导。最强可运行普通对照是**同一响应族、同一先验/支持、同一航迹和预算的 joint nuisance profile likelihood 或 Bayes marginalization**。它会对 `C,Y` 共用 nuisance，并自然保留 source/rate 别名。

更致命的是，在固定 `g_s`、未知正标量率和各向同性 Gaussian 噪声特例，普通 profile likelihood 已给出

\[
\hat r_s=\operatorname{clip}_{[r_-,r_+]}
\frac{g_s^\top y}{g_s^\top g_s},\qquad
d_s^2=\min_r\|y-rg_s\|^2.
\]

不触边界时 `d_s²=||y||²-(g_s^Ty)²/||g_s||²`。所谓“消除未知 release amplitude 后比较源方向”的统计量与该普通基线**逐点相同**；同泄漏 context 只是在 `y,g_s` 后面增加行。`COUNTEREXAMPLES.py` 对此给出精确数值恒等式。加入共享 `θ` 后仍是 standard profile over `(r,θ)`。这项尝试没有一个强基线不会自动实现的主增量，故不写新的网络或方法名。

这个集合输出也不能直接满足最终 PMFS microcell 概率图。若不另加已验证 likelihood/prior，`S_ε` 只是相容集合；对它做 softmax 会虚构校准概率。即使改成 Bayes posterior，联合边际化是概率底座，不是本次新增机制。若模型响应族不可信、风只局部可测或噪声界不成立，集合证书会错误排除真源；正确行为是“不签发证书/扩大歧义”，但这仍是标准稳健推断行为。

## 5. 第一刀反证规范的可执行性决定

**本次不冻结或执行第一刀实验。**这不是回避反证，而是任务规定只有独立命题与算法成立时才写唯一实验；当前构造已与普通 profile baseline 等价。未来若有真正不同的构造，其第一刀必须使用同泄漏单机 `C→Y` 记录、固定合法路径、可校准局部风/传感器模型、同先验与支持的强基线，以及在看 target 前固定的**一个**新增机制主终点和停止阈值。不能拿 toy 成功率定 GADEN 阈值。

现有资产角色：E1/E2 的几何合同和三个 E2 OPEN environments 可作设计/开发素材，已看过的 OPEN targets 不再具有 fresh 身份；它们的 10×30 全场张量不是部署级单机 context。House02 历史导航 trace 可核接口列与数据格式，但源合同与 E2 六源不同，不能组成相同未知泄漏的多候选确认集。H01 DEV 与 House03 保持封存；本轮没有读取其浓度，也没有新仿真。缺口是未触碰、同路径/同源条件下的合法时间序列及风/传感器误差合同。没有这些资产，就无法给一个可靠性或样本效率主增量设事前阈值，也不能声称 0 新 plume 的确认实验已准备好。
