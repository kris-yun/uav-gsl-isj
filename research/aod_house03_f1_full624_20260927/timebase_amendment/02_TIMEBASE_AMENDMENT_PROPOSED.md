# TIMEBASE AMENDMENT — PROPOSED / NOT AUTHORIZED

## 目的与状态

原实验 `AOD_F1_HOLD_TIMEBASE` 永久保留。建议在任何 target 浓度解码或评分之前，签署一次元数据驱动的采样合同修订；不是修改时间容差使旧检查通过。

以下改变了观测时间定义，不能登记为纯链接/基础设施修复。新版本应保留原 pre-target commit、metadata HOLD commit、本次时间证据与新的 amendment commit，说明修订时仅已生成首条 target，且浓度未读。

## 不变项

## 修订一：源启用与离散批次分开

`t=0`仍是模拟/路径起点，释放过程在起点启用；不平移时间原点，不强制塞入首个filament，不改变releaseAccumulator。

每次调用先累计 `7 * float32(0.1)`，再生成整数部分。首个整数批次出现在零基第1次调用的原生时钟 `0.10000000149011612 s`，这是当前实现的可复现离散释放规则。

`first_nonzero_filament_count`是AdvanceTimestep返回后首次发现非空群体的日志，不是直接记录AddFilaments内部的连续物理源启用时刻。以后保留该诊断，不再用“必须在0秒观察到非空群体”替代释放启用检查。核对配置与代码哈希，不按是否有气体/浓度大小重新选起点。

## 修订二：十次理想请求映射到一张固定原生保存状态表

保留理想路径槽 `tau = 50,100,...,500` 作为请求计划。实际评价对象改为：每个请求之前最后一个已保存的原生状态。

规则仅在本次签署时依据已复核的确定性时间表计算一次：

`j*(tau) = argmax_j {t_native_before(j) <= tau}`。

该规则不是最近邻，也不插值。十个ID和对应 `(integration_step, clock_before, wind_before, stage)` 全部写入 `NATIVE_SNAPSHOT_SCHEDULE_PROPOSED.tsv` 并哈希冻结。后续95条逐条核对同一张表，不针对每条run重新挑不同的“接近帧”。

冻结ID依次为：`91,174,265,365,465,565,665,765,865,965`。

原生时钟依次为：
`49.69981384277344, 99.49905395507812, 149.79994201660156, 199.80299377441406, 249.80604553222656, 299.80908203125, 349.8121337890625, 399.815185546875, 449.8182373046875, 499.8212890625` 秒。

这是对实际采样定义的修订；不能把这些记录重新标成精确的50、100、...、500秒。最大原生时钟偏移约0.500946秒。该偏移对间歇羽流是否有实质影响，本轮没有证据；所有方法一视同仁，且不能依据浓度选择规则。

## 状态阶段不可省略

固定核心顺序为：`Add -> Move -> Save -> Wind update -> Clock increment`。

日志中的 `physical_sim_time_s`实际来自Advance前的GetCurrentTime，保存内容已做过本次Move。因此保留：
- `clock_before_s`：原始日志值，绝不篡改；
- `integration_step`：零基调用序号；
- `completed_integration_steps=integration_step+1`；
- `nominal_post_update_time_s=(integration_step+1)/10`：名义步端点，不能冒称额外测得的真实时间；
- `state_stage=POST_MOVE_PRE_WIND_PRE_CLOCK`；
- writer原wind index。

样本的权威定义是这个原生状态元组，不是未经验证的连续时间真值。本草案选中的十状态，原生时钟与名义步端点都不超过对应请求槽，最后也都不超过500秒。

## 执行与停止边界

1. 先签署并冻结修订、十状态表与读取器；所有科学阈值保持原签署值。
2. 每run仅先验 metadata/hash；任一状态元组缺失/不同就停止，不在该run改采样规则。
3. 继续原清单剩余95条；完整取得后才按原评分器做624候选科学评价；不提前展示部分source排名再选方法。
4. 记录真实wind相位：本草案十状态为 `7,2,10,10,10,10,10,10,10,10`。不得称其为十种独立相位，不改相位、不扫时间。
5. 每条run归档到有余量的宿主盘，哈希校验完成后才能申请释放工作副本；禁止删除唯一副本或覆写旧结果目录。完整模板/原始bank保持可恢复。
6. 若坚持原“精确50–500秒连续采样”任务，本草案不适用；维持原HOLD，不悄悄修改时钟、writer或容差。本轮不推荐改动力学来满足原合同。
