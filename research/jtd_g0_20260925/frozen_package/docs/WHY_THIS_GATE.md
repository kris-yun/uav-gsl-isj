# WHY THIS GATE EXISTS

The previous R0 result established that source-conditioned encounter/support profiles have stable between-source structure across 16 stochastic realizations/source.

It did **not** establish that higher-order temporal history carries additional source information.

The present Gate asks a narrower falsifiable question:

> After preserving each time block's marginal distribution exactly, does destroying the identity link between blocks reduce held-out source evidence?

This is important because:

- if NO, then expensive joint temporal/process models are not justified by the current benchmark;
- if YES, then the project has direct data evidence that an information component discarded by marginal/block-independent evidence is source-relevant.

A YES still does not identify the final mother theory or final paper method.
It only authorizes the next theory-search/confirmation stage.

Existing 18-source results are discovery evidence only. Dense-source confirmation must later include near-neighbor competition and fresh independent targets.
