# 最小反事实物理源响应 K：资格与导出合同

**此文档是下一轮实验的数据接口，不代表已执行新实验。** 优先寻找仓库旧 House/S2X 中已存在的合法成对物理响应，避免重新花时间生成大世界。

### 每个物理环境 m 的最小元数据

- 几何：自由/障碍、源候选可行域、传感器高度、三维/岸线高度基准。原始导航搜索格与物理传播域不能混淆。
- 气象：同一已定义物理条件内所有候选使用相同外部强迫，实测/可估计风与仿真真风分别标识；在线禁止读取 oracle。
- 源：至少两个事前锁定的合法候选（其中是否含真源不能作为在线筛选依据），每列完整独立前向，释放位置、时间、单位排放强度、线性性验证；必要时对每个源做 Q 与 2Q 检验。
- 观测：`window_id, physical_time_s, sensor_id, x_m, y_m, z_m, ppm, sigma_ppm, sensor_calibration_id, frame/service_owner_id`。物理帧、时钟与 PID 消费窗口需要明确对应，不能猜测 owner。
- 前向 K：每列是给定源在**同一组 window_id** 上的单位排放浓度，采用合法同源观测算子（质量、sigma、3D 距离、遮挡、PID时滞/滤波）；仅二维占格不能冒充该列。
- 血统：具体代码提交和 SHA256、每个条件的随机种子/世界身份、墙钟与物理时间关系、风模型、原始帧及参数，以便逐窗口离线复算。

### 冻结最低验收

1. `OBS_OPERATOR_PARITY`：从物理帧重算原生观测传感器 ppm，在匹配时空窗口与标定后核对一致。
2. `Q_LINEARITY`：固定天气/粒子模型的合法条件下检查 Q 与 2Q 是否允许线性重缩放；超出误差门必须重新建模，不能强行 NEMO。
3. `SOURCE_PAIR_EXISTS`：至少两个不同合法源在同一时空受体/风/几何条件下各有完整物理响应列；测试真源独立于生成列的选择。
4. `IDENTIFIABILITY`：按噪声和未知源强剖面测源列可区分性，若无法区分，新增网络也不能恢复不存在的信息。
5. `A_A_PRIME_FAIR`：先运行普通 2D 事件合同/普通浓度似然/普通 3D 前向强对照，再考虑 NEMO。

如果只有真源物理帧和多个二维 PMFS 模拟候选：返回 `NO_VALID_PPM_K_COLUMNS`，**不得训练 B、不得编造定位提升**。
