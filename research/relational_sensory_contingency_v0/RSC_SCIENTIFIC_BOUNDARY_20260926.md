# RSC scientific boundary and novelty guard

## What SPX established

SPX established only an exclusion diagnosis: neither source-only nor probe-only frozen rule explained the crossed House02/W0 result, so the label is source×probe interaction.

It did not establish a new physical interaction law.

## Why sensorimotor contingencies are only provisional inspiration

Biological active sensing theory emphasizes that sensory processing depends on the statistical relation between environmental state and sensing action/configuration.

This matches the SPX observation conceptually, but active sensing is already established in olfaction and robotic odor localization.

Therefore novelty cannot be:
- moving the sensor;
- selecting the next probe;
- using source/probe coordinates;
- conditioning on robot pose;
- generic adaptive sensing.

The only potentially novel claim worth testing is:

> a candidate-conditioned relational source–probe–flow context can predict and gate which temporal evidence should influence the source posterior.

RSC-G0 tests the prerequisite predictive mechanism before any architecture is built.

## Domain physics boundary

2026 PRX Life work on temporal reformatting shows turbulent flow can filter, spread and generate temporal spectral content between source and sensor.

That is important physical grounding, but `flow reformats odor signals` is not novel to this project.

The project would need to connect source–probe–flow relational context to source-discriminative posterior evidence in a way that survives ordinary baselines.
