# E1 implementation rules fixed before geometry output

- Read canonical `OccupancyGrid3D.csv` with the validated Gate1A `read_occ` and `fine_index` functions.
- Read the existing PMFS `pruned_occupancy.bin` and `pruned_meta.json` geometry exports from the same source-blind navigation setup for H01/H02/H03. Verify each House's seed0/seed1 pruned bytes have identical SHA256. PMFS free is byte `1` at flat index `i + width*j`, per `Grid2DMetadata::indexOf`.
- Use 0.20 m for both observation and source height. The user explicitly froze `z_source=0.20 m` for all three Houses; historical per-family source heights are provenance only. If any House cannot supply the six required source free voxels at this height, report `SOURCE_HEIGHT_CONTRACT_INCOMPATIBLE` and stop.
- Probe candidates are 2x2 pooled native GADEN blocks (ceil edges allowed) whose every native cell is free at observation z and belongs to a PMFS-pruned free cell. The center is the mean of native cell centers. This reuses the Gate1A `avg_pool_2x2_then_sample` geometry and PMFS navigation mask.
- Farthest-point sampling uses squared Euclidean distance in exact integer grid units. First-point centroid distances are compared with integer numerators; ties are lexicographic `(i,j)`. This avoids floating-point tie drift.
- Source candidates are PMFS 0.30 m cell centers in the pruned free mask whose containing 3D occupancy cell is free at the frozen source z. Neighbor clearance is Euclidean distance to the nearest non-free PMFS cell or map boundary, whichever is closer. Equal-clearance partners follow the frozen offset order.
- E1B has no numerical equivalence threshold preregistered in the charter. The only outcome-blind equivalence test permitted here is exact equality of the 30 pooled block index sets, with every legacy block still valid. Otherwise choose E1A. No plume value is read before that decision.
- For the provisional budget, a House02 existing run counts only if a retained raw 10x83x119 concentration cube can be re-extracted at the new probes, the source xyz matches the E1 panel, the wind matches, and its independent seed is known. Legacy Gate1A 300-value vectors are excluded under E1A. House01/03 historical data are excluded because their frozen observation operator differs.
- This note fixes implementation choices, not a scientific outcome. The provisional budget is not authorization to run GADEN.
