# 运算、事件与读出

实际PID原始值`c(t)`（ppm）→停留消费窗均值`c_bar`→`y=(c_bar>0.1)`。
窗口均值和未平均原始PID流分别交付，不把两者混名。

原生更新：`L_i += logit(lerp(.3, hit?.6f:.1f, w_i)) - logit(.3)`；
`w_i`由原生风拉伸Gaussian、可见性、路径传播距离/方向给出；native clamp保留。
`omega_i += Gaussian1D(distance_i, sigma)`，`confidence_i=1-exp(-omega_i/weight²)`。
反复2/5检出时，原生静态状态更新可能趋近0；这不是“计算错了”，也不是定位失败的充分条件。
论文与历史代码的confidence指数写法差异保留，未悄悄改成论文另一公式。

前向量：二维无质量点在一个时间步是否占据格，按时间求频率，再做原生模糊。
实际传感器检出是不同高度上的浓度叠加越阈事件；二者不能默认同义。
候选的`points`记录只写二维源释放坐标，格式在`Audit.hpp`可核对；不是三维气团轨迹。

源评分沿用原生：`score(s)=product_free[1-D*confidence_i*abs(p_contact_i-h_s_i)]`。
逐叶评分赋给该叶全部自由格，再按自由格归一化，保留叶面积效应。
在log空间重算并对照捕获long-double结果；所有D从对应归档读取，未统一成一个方便的常数。
这是一套工作源权重，NLL/Brier只评价这套权重，不冒充已证明校准的生成后验。

O1：`sum(w*y)/sum(w)`，未接触格保留共同先验.3。
O2：共同Beta(.3,.7)，`a=.3+sum(w*y), b=.7+sum(w*(1-y))`；区间为Beta逆CDF的2.5%、97.5%。
O3：每个当前/已完成停留先取权重、加权检出的窗口均值，然后按停留累计Beta；不读取未来窗口。
它是普通有效块对照，不宣称各停留真的独立；五点序列不硬拟合相关时间。
空间权重只做平滑，Beta区间属于相关、分数计数下的工作区间，不是独立样本数的证据。

主组固定native confidence；第二组独立改为按停留平均覆盖再累计的coverage，仍用原指数式。
模糊/未模糊图是分开的普通前向敏感性，**不是**“物理检出事件已对齐”。

竞争格只由上一epoch的native图决定；第一epoch无竞争差，标ABSTAIN。
源MAP、真源严格排名及并列数、格质量、1.5m区域质量均保存。
90%诊断按更高概率格的累计质量判断等概率组可包含性；边界并列不解释为唯一的像素集合。
Top-5%是自由格数量的5%，不是5%概率质量，使用作者原文C++ `ExpectedValue` 和float坐标。
O0读出保留归档原始double源图，避免重算1e-18量级差异改变并列排序。
控制组的源方差和假想坐标只用于诊断；没有沿其新路径产生观测，没有新的停机、时间或成功率结果。
