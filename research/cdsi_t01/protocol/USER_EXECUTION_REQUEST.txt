## 第一步：利用 S2/S2X 真正漂亮的 matched-source 设计

# 第一项指标：source tangent 能否跨 realization 重现

每个 context：

\[
\bar\delta_c
=
\frac14\sum_{r=1}^4\delta_{c,r}.
\]

做 leave-one-replicate-out：

\[
\bar\delta_{c,-r}
=
\frac13\sum_{j\neq r}\delta_{c,j}.
\]

然后看：

\[
q_{c,r}
=
\cos
(
\delta_{c,r},
\bar\delta_{c,-r}
).
\]

物理意义：

> 用另外三个 plume realization 得到的“换源方向”，能不能预测第四个 realization 换源后 trajectory 往哪个方向变化？

如果只是随机 plume：

\[
q\approx0.
\]

如果存在稳定 source tangent：

\[
q>0.
\]

这比训练分类器干净太多。

---

# 第二项指标：真正对应 \(I_{\rm eff}\) 的量

前面理论里：

\[
I_{\rm eff}
\]

描述“source effect 相对于 nuisance variance 的强度”。

当前只有一条 source displacement：

\[
\Delta S_c=S_B-S_A.
\]

所以先估计这个方向上的有效信息：

\[
\boxed{
I_{\rm dir,c}
=
u_c^\top
I_{\rm eff,c}
u_c
}
\]

其中：

\[
u_c=
\frac{\Delta S_c}{\|\Delta S_c\|}.
\]

数据上不需要真正拟合 likelihood。

使用 **cross-validated Mahalanobis distance / crossnobis**。

直观形式：

取独立两组 realization：

\[
d_1=\bar x_{B}^{(1)}-\bar x_A^{(1)},
\]

\[
d_2=\bar x_B^{(2)}-\bar x_A^{(2)}.
\]

然后：

\[
\boxed{
D_{\rm cv}
=
d_1^\top
\Sigma_{\eta}^{-1}
d_2
}
\]

其中：

\[
\Sigma_\eta
\]

是 fixed-source realization variation 的 covariance，用 shrinkage covariance 防止 300 维、小样本奇异。

为什么一定要 cross-validation？

普通：

\[
d^\top\Sigma^{-1}d
\]

即使没有真实 source signal，也会因为噪声天然为正。

crossnobis 在零信号情况下期望约为：

\[
0.
\]

因此：

\[
D_{\rm cv}>0
\]

才是非常漂亮的“真实 source information 超过 nuisance noise”的证据。

这样三个问题一次分清楚：

\[

说明完整动态信息比静态累计多。

\[

说明真正关键的是跨时间 pairing，而不是单时间 marginal。

这会和你之前 R0 的结果形成非常漂亮的闭环。

# 第四项：完全不用人工拍阈值，做 exact permutation

因为每个 context 只有4个 matched source pairs。

在 null hypothesis：

> A/B source 不产生稳定差异

下，每个 matched pair 的：

可以随机翻符号：

\[

四对只有：

2^4=16

种 exact sign-flip。

所以每个 context 都可以**穷举精确置换**，不用正态假设。

跨8 context 再做 aggregated sign-flip / paired permutation。

这比“我规定 cosine > 0.5 就 PASS”科学得多。
