## 2. M1：来源、二次改造与代码边界

### 2.1 已实现运算

对应 `src/gsl_discrimination/m1_opponent/operator.py`、`calibration.py`。

1. 原始气体读数经 `log1p(max(x-background,0)/scale)` 变换。共模强度和半左右差采用真实时钟的梯形平均，不能写成等步长索引平均。
2. 母方法的结构是双侧共享的两个因果滤波器、ReLU 和镜像相减；PNAS 原文还有 sigmoid 侧别输出及可学习滤波器。V7 的自由参数已限制为固定有限指数核库，不能称为复现了原文学习过程。
3. 固定核库包含静态梯度与 6 个动态候选。动态核采用因果端点指数权重和明示 dt 求积，与共模/静态梯度的梯形规则不同。核形式为 `f1 = w0 − η wlag; f2 = −w0`，两侧交换后输出变号。
4. 共模量化为 1 bit，选中奇部量化为三值，编码为单一联合符号 `z = even_bit + 2 Σ 3^j odd_trit_j`。其字母表大小为 `2·3^m`。不能说完整浓度保留，也不能把同一块的多个派生特征分别作为独立证据乘入。
5. 条件表按动作、候选源和共享干扰状态建立，计数单位为完整训练块。固定总 Dirichlet 质量为 α，而非每个符号都加固定 α；新增通道的平滑分布可边缘化回旧表，避免表维数改变平滑总量。
6. 选择目标为各源对最不利干扰状态 JS 距离的截断和 `Σ min(JS, κ)`。共同强度为初始表示，贪心增加正增益通道；最多 3 通道。经验嵌套 JS 单调并不推出次模或贪心全局最优，特征协同可能产生零单步增益。
7. 有限源条件表不能直接对未训练的空间坐标给出可靠源似然；源坐标泛化必须是独立后续能力。

代码依据：`operator.py` blob `c2b708456a6d598a8315fb00bc82925b6e311c5e`；`calibration.py` blob `438439ad5cc49700b3d3d7fff33ae045fbe09042`。完整路径与本地哈希见清单。

### 2.2 后验与信息边界

源与整段共享干扰状态的联合权重递推后再对干扰边缘化；不应在每个窗口重新使用相同初始干扰先验积分。当前主通道使用冻结有限表及驻留块，行进期事件另进入 M2。只要行进期侧信息没有被纳入正确的条件观测律，所谓工作后验就不等于完整已见历史的精确贝叶斯后验。

每个原始块在源后验中只使用一次。窗口不重叠消除样本重用，但不能自动建立物理条件独立；重叠必须按条件增量而非完整窗口似然直接连乘。确定性编码服从数据处理不等式，M1 的候选价值是有限样本、模型或通信预算下的判别表示；它不会创造原始观测中不存在的信息。M2 改变位置，才会改变可获得的观测分布。

### 2.3 时钟与传感器

程序的最大帧间隔、同步和差分延迟检查只是资格条件，不是对真实 PID 带宽的校准。原本 0.2/0.5/1 s 滞后、0.25 s 最大间隔的快速配置拒绝了约 0.6 s 的原生归档。后续粗采样配置在解码浓度前冻结为 1.8/3/6 s 滞后、1.5 s 衰减、0.61 s 最大间隔及 0.5/1 两个抑制强度。这属于适应可用带宽的配置调整，不构成算法创新。

该开发轮次用理想零延迟原生浓度，`sensor_calibrated=false`。快响应气敏传感器、管路延迟、转子扰动、两侧传感器一致性及真实同步飞行均未得到本轮验证。真实时钟也不意味着物理频带足够。

### 2.4 已发现的结构退化

`TRAIN_FIT_RECEIPT.json`、`models/secondary/operator.json` 与 `R2_RESULT.json` 一致表明：两源只有一个源对；共同强度初始训练 JS 约 0.242586，已经超过 κ = 0.04；初始目标即达 0.04，所有新增通道增益为 0，`selected=[]`。

因此首轮所谓 M1 实际只使用共同强度 bit，动态镜像数为 0。将其写为镜像动态结构“已经独立比较且失败”也不准确：直接被检验的是这一选择目标下退化后的实现。可以提出用源条件预测损失、约束式可学习滤波或其他覆盖目标作为下一版本研究，但必须标注未实现、未前瞻验证，不能强制加入一个通道后追改历史成绩。

`mother_best_one` 同样不是完整母算法复现：它从同一受限库、同一截断源对目标选一个通道；本轮选的是静态梯度 index 0。严格母算法迁移对照仍待实现。

## 3. M2：记忆与判别几何的实际作用

对应 `m2_boundary/memory.py`、`formation.py`、`calibration.py`。

- 边界进入记忆更新为 `m ← a m + b d̂`，b 不必为 1−a。方向来自实际运动窗口；机头 yaw、未来轨迹或静止时羽流扫过不能替代已发生的运动方向。进入/退出延迟、记忆物理年龄与确认时刻分开。
- 无风版本只保留进入记忆，是明确适配；有风版本增加退出与上风门控，也不是 Nature 全部随机导航动力学的逐项复现。记忆函数不读真源标签，但并不意味着记忆与源在统计上独立。
- 归一化方向采用 Jacobian 传播方向协方差；从当前位置而非旧边界固定点构造有限返回区域。该区域没有经验 95% 覆盖保证。方向抵消、历史过期或无合格运动时应失效。
- 当前双机提议是同高度平面中心、基线长度和方向。源条件原始浓度均值/梯度及偶奇协方差来自训练或已发生信息；与 M1 的 log 变换明确分开。普通 RBF 适配不是创新。
- 源对几何距离是响应差的联合协方差二次型，不是源似然、KL 或 e 值；它不更新源概率。
- 短基线一阶近似在 Hessian 有界时有二阶余项；代码只检查声明的局部半径，没有实证证明 Hessian 界。长基线不得继承该近似保证。
- “基线与梯度差平行最优”只在均值差为零、协方差不随方向变化、非零梯度差且忽略其他方向成本/限制时成立。
- 输出全部源对矩阵。返回区内没有有效判别提议而区外存在时允许释放；M3 的覆盖和显式挑战不能被后验或返回区永久阻止。
- 端点合法性不等同整段无碰路径、同步到达或转子/采样姿态资格。

代码主要 blob：`memory.py` `be3612d1aa6d1588c6436e1d9b5e9b0130c20c2c`；`formation.py` `0e63a56204cc651b12c88c5022818492850688ea`。现有原型读取运动事件，正式原生 M2 实验尚未执行。与强基线比较时，不能仅让 M2 拥有行进期原始气体侧信息。

## 4. M3：成本、覆盖及审计的条件性

对应 `m3_audit/planner.py`、`ledger.py`、`THEORY.md`。

### 4.1 成本分配

安装模型给出各源在每个动作下的预测分布。当前主假设由工作后验决定，但其余合法源不按后验删去。正常分配最大化“对所有对手的最坏期望 KL / 期望成本”。变量变换为 `y=λ/(c·λ)` 后有线性约束 `c·y=1`，动作频率恢复为 `λ=y/Σy`。内部资源份额 `c·y` 不等于抽样频率。

两源时只有一个约束，退化为最大 KL/c 动作；两源固定探针数据不能验证多源成本配置。普通 EIG 优化后验平均熵下降，与这里目标不同，但不同目标本身不能证明更优。

付费覆盖混合默认 ε = 0.2，覆盖分布不依赖源后验，域为当时合法且剩余预算可承担的动作。正常利用掩码可来自 M2；覆盖和显式源对挑战保留全域访问。固定动作域中的未访问概率界只说明持续访问机会，不保证有限成本辨识、错误后验恢复或真实源信息率。预算尾段合法域变化时，不能继续套用固定全域的渐近结论。

无可用利用动作、零最坏信息率、支持导致无穷 KL 或显式挑战时，程序使用源对双向 KL 较小值/成本的回退；该回退不继承完整 LP 最优性。代码没有把结构零偷偷加 ε 来伪造有限 KL。原型动作成本基于返回共同起点的行程；一般连续、时变路径成本尚待独立处理。

### 4.2 新后缀审计

审计从过去可决定的起点开始，不继承旧源赔率。对固定整段共享干扰 r，维护全后缀 `L_ir=Π_k P_k(z_k|i,r,a_k,F_{k-1})`。替代混合 `Q_-i` 的正初始权重在起点确定，下一步替代预测在结果出现前冻结。审计量为 `E_i=Q_-i/max_r L_ir`；分母是“全后缀似然对一个共享 r 取最大”，不是逐步最大值相乘。

若真源和一个固定真实干扰状态在安装族内，模型是给定实际过去及动作的真实正规条件律，动作/起点/替代预测可预测且没有重复条件增量，则 E 被真参数似然比超鞅点态支配，获得 Ville 越界界。E 自身不必为超鞅。训练直方图/高斯拟合、独立新后缀和可预测拟合本身都不足以证明模型包含性或频率学风险控制。

当前可相容列表允许重新进入；从未越界列表单调缩小。两者都不是源后验。审计只触发下一次挑战，不把 e 值、其倒数或相容列表重新乘入源后验。初始零先验或结构零已经永久消去的源不能靠乘法自动恢复。

全安装族无法解释后缀时应报模型支持失败；事后加入概率下限会改变零假设和检验律，必须重新校准。多个审计重启还需明确 alpha 分配。真正物理模型下的风险及恢复速度均未验证。

主要 blob：`planner.py` `9d1c6a6733e85f05907514f749f9ad520401241e`；审计 `ledger.py` `c4a4be9531318b506e3c56efa81797f2c6b70e5f`。
