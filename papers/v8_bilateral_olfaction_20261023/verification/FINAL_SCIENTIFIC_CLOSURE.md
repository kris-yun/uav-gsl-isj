## 2. 排版调整后的四项数学等价检查

### 2.1 M2：Σ_T(s) 的拆分等价

当前定义：

- Σ_T(s)=Σ_x+q_m Δt_m I+(v_max σ_τ)^2 I+s²Σ_u；
- R_t(s)=r_0+k_T sqrt(n_tᵀΣ_T(s)n_t)。

将第一式代回第二式，完全得到原来写在平方根中的矩阵表达式。位置散布、按记忆年龄增长的漂移、延迟位移界及方向散布的四项均保留，s²没有误改成s；在声明的非负参数和半正定输入下，根内量非负。空间量纲仍为位置平方，最后半径为长度。

返回集合的折行只把纵向/横向约束移到下一行，没有改变 0≤s≤L_T 或 |ζ|≤R_t(s)。中心仍为两机平面均值；“工程近似、未校准概率覆盖”限制没有因缩写而删除。

### 2.2 M3：q 的权重混合与零质量分支等价

当 Q_(−i)(t−1)>0 时，混合权重为：

`a_jr = w_jr^(-i) L_jr(t−1) / Q_(-i)(t−1)`。

由于 Q 的定义为这些分子之和，权重非负且总和为1。当前两行 q 式表示：

`q_(-i,t)(z) = Σ_(j≠i,r) a_jr P_t(z|s_j,r,a_t,F_(t−1))`。

将与 j、r 无关的 Q 从分母提到每一项中，与原“大分式中的加权和”严格等价。换行后的乘号仍属于同一个求和项，没有将状态条件 P 移出求和。

当 Q=0，公式的适用条件明确排除0/0，随后文字指定下一步使用正规分布，但 Q 的累计乘积维持0。此分支与冻结代码 `AuditLedger.prepare` 一致。均匀下一预测没有被当作新的正路径质量；它也不恢复旧后验。

### 2.3 M3：成本LP与频率恢复等价

利用域非空、成本为正及KL有限时：

`y_a = λ_a / Σ_b λ_b c_t(b)`

给出 `Σ_a c_t(a)y_a=1`，且单位成本最坏分离率变为 `min_j Σ_a y_aD_(i_t,j,t)(a)`。反向由 `λ_a=y_a/Σ_b y_b` 恢复动作频率。当前把 λ 恢复式独立排在下一行，没有增加新的限制，也没有把 c_a y_a 当成动作概率。

正文明确求和域是 A_use，源约束覆盖所有 j≠i_t；求解后补零到 A_legal,aff。无限KL、空利用域、低于容差等情况走已明示的工程回退，不误用这个有限LP的最优性结论。图3的主假设/对手结构与此一致。

### 2.4 M3：后缀似然、e值及条件证明保持一致

L_ir和Q分成两行后，仍对一个固定r形成整个后缀乘积。E_i=Q_(−i)/max_r L_ir没有变成逐步max的乘积，或把r每步重新选择。当前相容集与从未越界集分成两行后，其恢复/单调属性仍正确。

在所述真实条件族包含性、可预测性及不重复增量前提下，max_r L_ir≥L_ir*，所以 E_i≤Q_(−i)/L_ir*；正规替代预测给出非负似然比检验超鞅的支配，再用Ville界。正文仍明确E本身不必为超鞅、拟合表不自动产生物理风险保证、重启需累计错误预算。

在扩展非负实数意义下，某个源分母为0而替代质量为正对应E=+∞；若所有安装状态都为0，正文明确为模型支持失败。该边界与新Q=0说明互相一致，没有引入“概率地板认证”。
