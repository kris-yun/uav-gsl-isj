# CESS Post-Pro Review — Mainline Revision

Date: 2026-09-25

Status:
**B remains the main-innovation candidate, but the scientific gate is revised before execution.**

## 1. What the auxiliary Pro corrected

The uploaded theory/red-team package identified four constraints that the
mainline now accepts:

1. a fixed unknown source cell is not automatically a dynamical microstate;
2. deterministic coarse-graining under the same prior cannot create Shannon
   information;
3. macro accuracy or uniform-macro EI can improve merely because the task/prior
   changed;
4. the decisive empirical endpoint must return to the **same microcell outcome
   space and same source prior**, using fresh-target proper scores.

Therefore the paper-level object is provisionally named:

**causal-emergence-inspired multiscale source identifiability**

until a stronger causal-emergence bridge is independently justified.

## 2. What remains valid

R0 still supports encounter/support profiles as a stable source-conditioned
observation object.

The corrected 18x16 D0 still provides useful discovery evidence that spatial
neighboring sources may share estimable encounter structure.

However, that D0 is only motivation. It is not confirmation of causal emergence
and cannot select the final source partition.

## 3. D1A decision gate is withdrawn before execution

Do not execute the previously written D1A scientific PASS/STOP analysis.

The 168-source dense region remains useful, but its first use is now to build a
**reference bank only**.

No final target is generated at this stage.

## 5. Controls required before D1C

The final confirmation must include, at minimum:

- identity partition;
- all-in-one negative control;
- size-matched random partitions;
- geometry-only connected partition;
- ordinary profile-clustering baseline with equal selection budget;
- ordinary hierarchical pooling/shrinkage baseline if mathematically compatible.

A mainline claim cannot survive if ordinary pooling/clustering explains the
entire effect.

## 6. Partition validity

Reference-only development must report:

- 8/8 split profile reproducibility;
- partition VI / ARI across independent reference halves;
- co-membership uncertainty;
- within-group information/fidelity loss;
- physical connectedness and wall-crossing;
- whether amplitude/raw-concentration information is being discarded by the
  encounter-only channel.

A stable all-in-one partition is not success.

## 7. Interpretation boundary

Even if D1C succeeds, the mainline claim is not:

"macro states contain more true information than micro source cells."

The valid claim is:

> under finite stochastic realization budgets, a reproducible source
> coarse-graining can reduce estimation/generalization risk while preserving
> unresolved source uncertainty on the original microcell probability map.

Whether this deserves the stronger label "causal emergence" remains a separate
theory/novelty question.
