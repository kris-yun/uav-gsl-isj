# 从不变分数走向源—输运解混的主动实验设计

日期：2026-09-21。性质：研究方案与条件推导，不是已经完成的新算法或论文新颖性证明。

## 结论与所属领域

当前 TNQC 主要是表示/似然修正。用户希望的是能够改变闭环效果的一个主思想。建议方向是：以物理生成模型为基础的主动系统辨识与双重控制，以逆问题可辨识性和贝叶斯实验设计为数学支撑。

一句话：不只把当前观测变得更稳健，而是让机器人主动取得能区分“源变了”与“风/标定变了”的观测。

PMFS 已有候选源到在线扩散预测、再到 probabilistic gas-hit map 比较的生成建模基础。[L1] 将其称为新的“世界模型”本身并不新；需要补出动作与时间条件化的观测预测。神经网络可以用于加速这些预测，但不是算法是否拥有一级原理的判据。

## 一、为什么选择 B 为对象、A 为工具

定义源 s、输运参数 θ、标定参数 φ，动作序列 A 和历史 D_t。一个源对应的预测集合是

M_s(A;D_t) = { μ(s,θ,φ;A,D_t) : (θ,φ) 与历史及物理边界一致 }。

一般室内风场变化并不天然构成作用在 hit-logit 上的可逆群。因而使用 nuisance set/manifold 比直接宣称 transport orbit 更准确。对确为全局正仿射的 calibration 子群可以解析消元、规范化或边缘化；不能任意扩张到真实输运。

集合变大不仅可能容纳正确环境，也可能使不同源集合重叠，识别更困难。不得靠给每个 candidate × cell 单独调整 θ 来把所有源都拟合好。正确操作是 min_θ Σ_i loss_i，不是 Σ_i min_{θ_i} loss_i。θ 是一个共享、或按事先规定动态模型变化的世界状态，不是逐观测自由旋钮。

还须避免退化集合：若增益可以趋于 0、背景无限制，所有源都可能生成相同常量场。因此必须依据可获得的传感器/风测量与物理边界设定参数域，不能用真实源坐标缩窄。

## 二、动作条件化的物理生成模型

研究模型可写为：

c_{t+Δ} = F_θ(c_t, s, map, Δ),
y_t = h_φ(c_t(r_t), z_t) + ε_t,
z_{t+Δ} = G_φ(z_t,c_t(r_t),Δ),
w_t = g_θ(r_t) + η_t。

c 是气体场，z 是传感器内部响应状态，r_t 是机器人位置，w 是可测的风。固定源与动态输运状态要区分。第一版可在短窗口中假设 θ 常量；该窗口长度必须以数据检验，不能默许整段 300 秒完全稳态。无人机下洗等若会改变测量，应限制工作条件或明确作为误差，不能只补一个任意低维 θ 后宣称物理完备。

已有静态 hit-map 可以作为短时近似，不自动包含未来时间相关性。必须保存预测均值、噪声/模型误差范围及条件。世界模型的职责是回答“到哪个可达位置、停多久，在各个仍可能的世界中会看到什么”。

联合后验可概念化为 b_t(s,θ,φ)。源后验是对 nuisance 的积分或有权求和；观察历史后 θ 与 s 一般相关，不能把 p(θ|s,D_t) 无理由改成同一个无条件 p(θ)。相同历史只计入一次，不能把每个累计 hit-map 当独立新样本反复乘似然。

## 三、理论命题 1：什么时候任何新分数都救不了

设两组世界 H1=(s1,θ1,φ1)、H2=(s2,θ2,φ2)。如果对预算内所有可达动作，在所有具有共同正概率的历史下，下一观测的条件分布完全一致，则任何适应性策略生成的全历史分布也一致。

证明：第一步观测核相同；归纳地，给定相同历史时策略的动作分布相同、观测核相同，故下一步历史分布相同。最终任何估计器都是历史的函数（允许独立随机化），输出分布相同。对两种世界等先验的二元判别，最小平均错误率为 1/2。

这是完全分布层面的不可辨识结论。仅固定旧轨迹上的均值相同，不足以推出所有可行动作都不可辨识；协方差等也可能含信息。学习网络不能在同样信息与先验下突破这个不可能性，额外先验/额外传感器可以改变问题。

因此下一代问题不是“能否把旧分数调对”，而是“预算内是否存在打破等价观测的可达动作序列”。

## 四、理论命题 2：源信息中哪些部分不能由 nuisance 冒充

在给定候选世界附近，设高斯局部模型、已知固定正定噪声协方差 Σ，线性化为

δy ≈ J_s δs + J_ν δν + ε，ν=(θ,φ)。

白化 A=Σ^{-1/2}J_s，B=Σ^{-1/2}J_ν，令 P_B=B B^+。则

I_eff = A^T(I-P_B)A，
min_{δν} ||Aδs+Bδν||² = δs^T I_eff δs。

证明：最小二乘将 Aδs 投影到 col(B)，剩余是正交分量。(I-P_B) 是对称幂等投影，平方范数即二次型。

当 B 满列秩时，这也等于通常的 Fisher Schur complement：I_ss - I_sν I_νν^{-1} I_νs。此为已有统计工具，不是本方案发明。类似通过 Fisher 信息投影构造 nuisance-hardened summaries 的方法已有明确文献。[L7]

物理意义：若移动源所导致的预测变化，可以被某种风/标定变化抵消，则这部分变化不提供独立的一阶源信息。若 I_eff 的最小特征值较小，某个源方向仍高度混淆。只有在正则条件下满秩才给常规局部可辨识性；某点导数为零不排除高阶可辨识，不能把局部 Fisher 零直接宣布全局不可能。

数据秩上界 rank(I_eff) <= min(dim(s), n-rank(B))。n 是白化模型中的独立观测维数，不是简单 CSV 行数。任意加 ridge 后矩阵可逆不是数据已可辨识；若引入真实先验，必须区分先验信息与新增观测信息。

### 至关重要的组合性质

单个动作的 nuisance 消元信息不能简单相加，必须先把历史和新动作的观测堆叠、保持同一 ν，再消元。

例：y1=s+ν+ε1；y2=s-ν+ε2；独立单位方差噪声。单看 y1 或 y2，其 I_eff 都为 0；联合后 I_eff=2。两个单独看都“不值得去”的位置，合起来完全可区分源与 nuisance。

这要求规划评估短动作序列和条件价值，而不是只在每个位置独立计算一个投影分数。

## 五、理论命题 3：预测集合分离的稳健判据

考虑离散源候选的预测集合 M_s(A)。假设真实源及其参数在候选集合中，并且白化观测相对某个真实集合元素的误差不超过 r+ε_m；r 为测量误差界、ε_m 为模型误差界。

令 Δ(A)=min_{s≠s'} inf_{u∈M_s,v∈M_s'} ||u-v||。

若 Δ(A)>2(r+ε_m)，最近集合判别唯一选对源。

证明：观测到真实集合距离 <=r+ε_m；到任一错误集合距离 >=Δ-(r+ε_m)>r+ε_m，故结论成立。

这是充分条件，不是必要条件，也不是任意真实环境的证书。可信域若排除了真实 θ/s，或模型误差界未经验证，该保证即不能使用。连续源的任意近邻之间 Δ 通常趋于 0；实际要对预定义空间分辨率/不同源区域作声明，不能保证无限精度。

对有限 bank 的分离还需计入网格覆盖误差。若模型对 θ 是 L-Lipschitz、bank 是 h-cover，则每个集合近似有至多 Lh 的偏差，分离下界最多应减去两个集合的覆盖误差；L 和 h 未知时不得自称连续参数的证书。高维、全自由风场可能使集合过于宽泛，任何可行动作都不能分离。

## 六、闭环目标：有限预算的最终源决策，而不是盲目压熵

保持 ν 是隐变量，不是必须“全部估准”的任务目标。又不能因为 ν 不是最终目标，就把测风/校准动作的未来价值消掉。

概念上定义完整剩余预算策略 π 的目标：

R(π|D_t)=E[ loss(E_native(b_{T,s}), S) | D_t,π ], T=300s。

E_native 必须对应论文冻结的坐标估计器。有限候选动作与 rollout 可以处理这个目标的非光滑性。若为了计算使用后验均方误差、信息增益或 I_eff 代理，必须说明它是 surrogate，不等于 native endpoint 定理。

单步信息设计的正确源目标是 I(S;Y_a|D_t)，而不是默认已知真实 nuisance 的 I(S;Y_a|ν,D_t)。联合信息 I(S,ν;Y_a|D_t)=I(S;Y_a|D_t)+I(ν;Y_a|S,D_t) 也可能把预算花在与源决策无关的环境细节上。

但单步源 MI 仍可能短视。应至少检查“先解混、再辨源”的两步互补动作，在剩余时间中计算导航、驻留、传感器响应、规划计算的成本。不是把所有 nuisance 学习都惩罚掉。

### 本轮执行的精确两步例子

S、ν 独立均匀二元，观测都花一单位预算，有三种动作：
1. calibration：准确观测 ν；
2. mixed probe：准确观测 S XOR ν；
3. direct probe：以 25% 翻转概率观测 S（重复时条件独立）。

第一步 calibration 与 mixed 的源 MI 都为 0，direct 的源 MI 为 0.1887218755 bit。精确枚举所有结果和两步决策：逐步最大源 MI 会选 direct 两次，最终 Bayes 分类错误率 25%；先 calibration 再 mixed，错误率为 0。

另一个单步例子表明联合 MI 会优先观测两个无关 nuisance bit（2 bit，源错误率仍 50%），而 10% 噪声的源观测只有 0.531 bit、错误率却为 10%。这两个例子共同说明“总熵越小越好”和“只贪心看当前源信息”都不是完整闭环原则。

这是数学反例，不是气体世界、不是 native ExpectedValue、更不是 PMFS 实验成绩；其价值是检验下一代的理论目标有没有遗漏动作互补性。

## 七、能否保证一定提高 300 秒成绩

不能从 quotient 定理、Fisher 满秩或 toy 成功推出这一点。

一个明确的条件比较界：对同一可行完整策略集合（包含原生策略 π0），如果估计风险 Rhat 对每个候选的真实风险 R 都有统一误差 <=ε，而策略优化误差 <=δ，则选中策略 πhat 满足

R(πhat) <= R(π0) + 2ε + δ。

证明：R(πhat)<=Rhat(πhat)+ε <= Rhat(π0)+δ+ε <=R(π0)+2ε+δ。

若已知选中方案相对基线的预测风险降低超过 2ε，则可对这两个已选方案得到严格期望改善；若用理论“最优候选”收益作为基准，还应减去 δ。这里要求相同损失、同一评价分布、完整策略成本可行、真实误差界成立。这个通用比较界本身不是新颖性；它指出真正要补的是模型误差与规划误差控制。对实际截断 rollout 或反复重规划，不能不加论证就套用完整策略界。

## 八、新颖性边界与优先级

已经存在的工作限制了可以主张的内容：

- PMFS：在线输运仿真与 probabilistic hit-map 候选推断。[L1]
- ICRA 2026：Concentration Measurement Ranking，免标定排名特征与源概率推断。[L2]
- Model-Based Active Source Identification：AD-PDE、降阶模型、最大化 Fisher 最小特征值的机器人采样。[L3]
- DCEE：未知源与未知风速风向、粒子滤波及探索/利用双重控制；作者注明短版本被 Automatica 接受。[L4]
- CL-DCEE：多估计器并行学习与源搜索，TAC 2023。[L5]
- GoBOED：2026-05-25 预印本，面向下游决策的实验设计，作者模型为单步非适应设计；本轮未核实顶会/顶刊录用，不称顶刊。[L6]

因此，不建议把“世界模型+信息增益”“联合估计风源”“Schur complement+路径规划”单独包装成主创新。

建议唯一主创新候选是：在地图约束、有限搜索预算、共享输运状态和校准不确定性下，显式识别可被短动作序列打破的源—输运混淆，并把该结构转换为可计算的闭环探测决策。

需要拿出的新增成果不是一句组合口号，而是：GSL 的具体物理退化条件；多点/短序列如何恢复源信息的可检查条件；利用这个结构、相对普通 BOED/DCEE/同-bank 贪心规划显著降低计算或改善固定预算定位的方法。若只实现一个普通 bank 然后最大化 MI，这是有用基线，不是已经满足用户要求的创新。

## 九、最小实现与验证顺序

保持当前 V5 只用于冻结验收，另开研究分支，不再根据六例结果调 V5 的温度或门控。

1. 诊断：用真实当前表征，检查 candidate × wind/calibration 条件下的跨源混淆；区分模型失配、固定轨迹缺信息、融合扭曲和规划走错。源 truth 只在评价端使用。
2. 同模推断对照：固定同一 transport bank、共享参数规则、噪声与支持，比较原生规划与源专用信息规划。全部累计历史只计一次，bank 采样/粒子数对齐。
3. 两步探测：比较同-bank 的单步策略与短序列解混策略，统计模型预测的源区分能力是否由真实后续观测证实。候选动作始终受地图、剩余时间与原生动力学限制；不能用离线未来真实浓度选点。
4. 闭环：同一预定义场景分布、不同随机种子配对，对照原生 PMFS、bank+原生 planner、bank+单步 source-MI、bank+两步解混。时间、导航、传感器响应与算力成本一致；加入恰当实现的 DCEE/Fisher 相关基线以定位贡献。

固定轨迹日志不能自动识别新策略的闭环价值：它缺少未执行动作的观测。可以做模型驱动离线闭环仿真，但评估环境必须独立于 planner 的低维 bank，测试网格外风向、时变风、地图/传感器失配，避免同一个前向模型生成和评价的 inverse crime。原先六例若参与研究判断，对新版本就不再是完全未见的测试集；应另留真正未见环境/种子，并如实标注旧基准。

理论闸门先完成：假设、噪声模型、参数共享窗口、可辨识定义、误差界、反例、计算预算。然后才做小规模动作干预测试，最后到统一 native 300s 终点。遇到门控失败不再追加一层门控；先定位哪项理论假设被破坏。
