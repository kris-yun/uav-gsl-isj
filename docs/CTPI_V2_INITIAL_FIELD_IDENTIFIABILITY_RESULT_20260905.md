# 未知初场的可辨识性反例

这是三格线性算子单元测试，不是新 House、seed 或源场实验。先写 `CTPI_V2_INITIAL_FIELD_PROBE_CONTRACT.json`，后编译执行 `tools/selftest_ctpi_v2_initial_field.cpp`。无 bank、真源数据或随机抽样。结果不构成新 M1 或闭环 PASS。

## 反例与证明

离散输运状态 `x`、已知正向风 `u=0.5`、扩散 `D=0.01`、单位格距及已知源强 `q=1`。三格链两端 no-flux，使用现有 V2 守恒核心。两种源分别位于相邻的格 0 与格 1。

令 `d=q/(u+D)`，两初场分别为 `xA(0)=(10,10,10)`、`xB(0)=(10-d,10,10)`，都非负。输运生成元 `Q` 满足：

`Q (d e0) + q(e0-e1) = 0`。

所以同一显式推进算子下，若某步 `xA-xB=d e0`，下一步仍为 `d e0`；由归纳法，全时域差异都局限在格 0。只要观测位置不包含格 0，两个源的完整气体时间序列就完全相同。相同初始状态、相同参数的因果 FOPDT 也产生相同输出。添加相同分布、与源无关的测量噪声不消除这个等价性。

这证明的是：**当任意非负初场都被视为可行干扰时，已知风、源强和传感器参数仍不足以保证源位置可辨识。** 不证明实际 House 的初场都任意可行，更不证明所有移动路径不可辨识。是否可以进一步限制初场，必须由物理预历史/独立信息支持；不能因为需要一个集中后验就把初场设零。

## 执行结果

VM g++ C++17 编译（`-O2 -Wall -Wextra -Werror`）并执行通过，1,200 步确定性推进：

- 最大观测气场差：`8.5265128291212022e-14`。
- 最大传感器输出差：`1.7053025658242404e-13`，属于浮点误差。
- 正控制仅在数学测试最后 30 步观测格 0：传感器差为 `1.9423459557813825`，独立 FOPDT 线性响应预期 `1.9423459557813818`。
- 强制两候选从零气场开始解释 A 的观测：源 A 残差平方和 `1017636.9333041173`，源 B 为 `889627.50168846943`。这个错误模型反而偏好错误源 B，尽管风、源强和传感器均已知正确。

正控制改变的只是三格单元测试的观测算子，不授权修改真实控制器、启用 M3 或新增实验。初场取值是构造性反例证人，不是 House 标定参数；残差差异不等于任何 House 的任务效果。

## 对候选 M1 的要求

1. 必须说明输出指向物理源，还是某个先验/误差分配约定下的最优解释。
2. 若依赖初场受限、路径可观测性或额外风信息，须给出实际可获得且可测试的条件。
3. 不能把“发现不可辨识后不输出”替代目标中的有效定位方法；这个反例用于约束新机制，不是以诊断模块冒充 M1 完成。
4. 不能假装绕过信息限制，也不能把旧 zero-initial 模型的更尖后验当识别证据。
