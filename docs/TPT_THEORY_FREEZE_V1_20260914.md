# TPT Reactive-Path Theory Freeze V1

Date: 2026-09-14
Status: CANDIDATE THEORY — OFFLINE FALSIFICATION ONLY

## 1. Scientific bottleneck inherited from the project

The current House02 evidence shows that some `source × wind` combinations have zero or near-zero exposure under admissible sensing routes, and the source-response operator collapses in `W_slow`.

This motivates a transport-path question upstream of Bayes:

> For a candidate source, which stochastic transport trajectories successfully enter the robot-accessible sensing domain within the mission horizon, and does the geometry of those successful paths carry source identity across transport regimes?

## 2. Stochastic transport model

Treat a gas filament / tracer carrier emitted from candidate source `s` under transport regime `w` as a stochastic process `X_t` generated by the frozen GADEN filament law.

Let:

- `T` = mission horizon;
- `B_R(t)` = robot-accessible sensing tube induced by frozen sensing design `R`;
- `tau_B` = first time a carrier enters `B_R`;
- optional `A` = physically declared escape / absorbing set, only if the exact simulator semantics justify it.

The finite-horizon reachability probability is

`q_{s,w}^R = P(tau_B <= T | source=s, transport=w)`.

This is a **diagnostic/baseline only**. It is not the proposed novelty because source-conditioned detection probability already exists in robotic OSL.

## 3. Transition-path ensemble

Condition on successful transport:

`P_path^{s,w,R} = Law(X_[0:tau_B] | tau_B <= T)`.

The hypothesis is that the conditional path ensemble contains information not represented by the scalar `q`.

### First-entry measure

`mu_{s,w,R}(dx,dt) = P(X_tauB in dx, tau_B in dt | tau_B <= T)`.

This tells where and when successful source material first enters the sensing domain.

### Reactive occupancy

Discretize the robot-accessible sensing layer into cells. For successful paths, accumulate contribution-weighted occupancy in those cells and normalize to unit mass.

### Reactive current

Discretize successful path segments into directed transitions between adjacent accessible cells. Define a nonnegative directed-edge flow

`J_{s,w,R}(i->j) proportional to total successful-path contribution crossing i->j`.

Normalize the flattened directed-edge flow to unit L1 mass for cross-source comparison.

This is an empirical finite-time reactive-current analogue. Do not claim exact continuous-space TPT current unless the Markov/TPT construction required for that claim is explicitly implemented and validated.

## 4. Source-neighborhood masking

To prevent a trivial fingerprint caused by every path starting at its known candidate coordinate:

- only include path segments in the robot-accessible sensing layer / free-space mask;
- exclude a fixed neighborhood around each candidate source;
- the exclusion radius must be the same grid-resolution rule for every source and frozen before response evaluation;
- V1 rule: mask cells whose center is within `2 × gas-grid spacing` of the candidate source, unless exact grid semantics make this invalid; any change requires STOP and return to GPT before evaluation.

Unmasked results are diagnostic only.

## 5. What counts as source identity

Use transport-regime transfer rather than within-wind self-fit.

Design regimes: `W_fast`, `W_slow`.

For each representation, match each source representation in `W_fast` against all four source representations in `W_slow`, and reverse the direction. This gives 8 same-source cross-wind identity tests.

Representations:

1. `Q_ONLY`: scalar mission-level hit probability;
2. `ENTRY_ONLY`: normalized first-entry location/time histogram;
3. `UNCONDITIONED_VISIT`: marginal accessible-cell visit/occupancy from all carrier trajectories, without conditioning on successful source-to-sensing transitions;
4. `REACTIVE_CURRENT`: normalized directed-edge flow from successful paths after the fixed mask.

No learned embedding and no trained metric.

V1 distance for nonnegative normalized vectors: cosine distance `1-cos(x,y)`. For `Q_ONLY`, absolute difference is reported only as a scalar baseline and cannot satisfy the path-geometry novelty gate.

## 6. Design-wind premise gate

`REACTIVE_CURRENT` must achieve:

- `8/8` cross-wind same-source nearest match;
- positive same-source-vs-best-false margin in every match;
- strictly larger minimum margin than both `ENTRY_ONLY` and `UNCONDITIONED_VISIT`;
- direction-destruction control must reduce rank count or minimum margin.

If marginal baselines match or exceed it, conclude:

`TPT_PATH_ENSEMBLE_NOT_LOAD_BEARING`.

## 7. Failure-matching gate

On the already frozen AO_00 route, historical design evidence groups are:

- exposed group: `S_truth`, `S_k10`;
- zero-exposure group: `S_k01`, `S_k22`.

For each design wind, estimate mission-level hit probability from independent stochastic realizations and 95% Wilson intervals.

A strict failure-link gate is:

`max upperCI(q_zero_group) < min lowerCI(q_exposed_group)`.

If this does not hold, the candidate theory does not explain the project failure that motivated it and must not be promoted.

## 8. Held transport regime

`W_altfast` must remain unopened until all design-wind objects, mask, metric and gates are committed and pushed.

If design gates pass, freeze per-source prototype as the mean of normalized `W_fast` and `W_slow` reactive-current vectors. Then evaluate the independently generated `W_altfast` ensemble.

Held gate:

- `4/4` sources nearest-match their frozen same-source prototypes;
- all margins positive;
- minimum reactive-current margin strictly exceeds both `ENTRY_ONLY` and `UNCONDITIONED_VISIT`.

Label this only `INTERNAL_DEVELOPMENT_HOLDOUT`, not cross-dataset confirmation.

## 9. Negative controls

Mandatory:

- `EDGE_DIRECTION_SHUFFLE`: preserve visited cells / edge magnitudes but destroy edge direction association;
- `UNCONDITIONED_VISIT`: remove successful-path conditioning;
- `ENTRY_ONLY`: retain only first entry;
- `UNMASKED_CURRENT`: diagnostic only, cannot count for PASS.

The intended mechanism is load-bearing only if path conditioning and direction structure matter.

## 10. Claim boundary

If all premise gates pass, the only authorized statement is:

> In the controlled House02 stochastic transport bank, successful source-to-sensing transition-path geometry carries cross-transport source identity beyond marginal hit/entry/occupancy statistics.
