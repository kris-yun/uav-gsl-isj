**长期适用范围**：今后的硕士开题报告、研究现状、研究内容、技术路线、中文论文、英文论文初稿及投稿润色，优先遵循以下两套已核对的公开写作规范。

## 研究叙事
1. 论文从科研问题出发，说明现有方法、关键不足、拟提出的方法与检验方式。不要按“做过几轮，失败几个门，审计哪些合同”的研发过程写正文。STOP/HOLD/NO-GO、R0C/R1等实验代号只保留在研究记录或必要的规范化实验附录，不反复出现在开题报告里。
2. 把第一篇主线写成“湖岸复杂气体传播条件下的物理约束概率源定位”，保留二维源位置概率图为主要输出。三维气体传播和气象影响是方法依据，多无人机协同监测及闭环验证分成后续两项研究内容。
3. 可以参考课题组《复杂气象下无人机意图识别方法研究》中的学术语言与图文编排。但不能直接移植它的领域问题、公式、算法模块或夸称已验证的性能。三个研究内容依次递进，采用学校模板原有编号，内部用(1)(2)(3)及a)b)c)。
4. 研究现状按方向大块组织，各约一页。描述方法、适用条件、尚需研究的问题。每个具体文献观点均须与实际参考文献对应，禁止编造引用。图中从输入、方法、输出与反馈关系展示算法，而不是使用三张只有湖岸无人机的场景大图。

## 中文学术语言
1. 优先用“传播”描述气体物理过程，除文献原题名、直接引文及必须的专业固有术语外不写“输运”。
2. 句子主谓清楚，长句拆成2句。控制机械排比和重复“首先、其次、最后”；它们只在确有先后顺序时出现。
3. 禁止写作过程说明：“本次审核”“本版本恢复”“未通过门”“等待后续Codex”“截至某日的R1判决”。科研准备进度在“已有基础”写正常事实，不写项目周报。
4. 不写无意义的强反转：“不是……而是……”；不写言之无物的总结词“赋能”“深度融合”“系统性突破”“进一步凸显”。避免“可重复的…可信的…充分的…”等修饰链。
5. 正文避免英文破折号、中文长破折号、分号及符号拼接短语。优先使用句号、逗号。标点、单位、公式、文献题名与官方标准依规定保留，不强行篡改 DOI / 英文书目信息。
6. 减少自我削弱、防御口吻和没有读者提出的反驳。对未验证的拟研究内容用“拟研究”“拟通过……验证”，不要写成已经成功，也不要把结果局限隐藏成虚假确定性。
7. 同段避免标题重复陈述、单句式空泛结尾、无用的三分法和AI套话。不要用过度加粗或感叹句营造权威。

## 真实与准确性底线
- anti-defensive-writing的“围绕优势组织叙事”适用于研究正文，但不允许掩盖直接影响科研结论的失败、验证限制或材料不足；在正式论文结果、方法及实验局限处应准确披露。
- 当前PMFS完整原生复现尚未完成。旧H02异常不能写成已证实的原论文失效。拟研究算法及其提升属于计划，不能写成已获得的成果。
- 枫树岭DEM和湖岸地形是已有资料，模拟泄漏源与工业设施是人工设定。不能将仿真羽流或人工2.5D示意称为真实实测。
- 对“跨场景、跨风况有效”等结论必须有对应数据。模型和参考论文的发表年份、DOI需终校。
