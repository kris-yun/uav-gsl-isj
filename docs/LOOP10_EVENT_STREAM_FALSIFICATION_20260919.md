# Loop 10 — Event-Stream / TPP Candidate Falsification

Date: 2026-09-19
Status: INTERNAL SCREENING

Remote-domain anchors:
- ICML 2025: *Residual TPP: A Unified Lightweight Approach for Event Stream Data Analysis*.
- ICML 2025: *A Chaotic Dynamics Framework Inspired by Dorsal Stream for Event Signal Processing*.
- Nature Communications 2026: *Perception and neural representation of intermittent odor stimuli in mice*.

The existing controlled histories were converted into source-independent event representations using threshold-crossing onset/offsets, inter-event gaps, burst durations and derivative events. Fast-wind windows were used for the source probe and later slow-wind windows for held evaluation.

The result is mixed. Event features sometimes improve a 20 s held block, but lose or tie at other horizons/configurations. There is no robust cross-House advantage over raw temporal features.

**Decision: NO-GO as current M1.**

The scientific fact that intermittency matters is retained, but “event-based plume representation” by itself is too old and too weakly supported by the project data. A future TPP candidate would need a source-conditioned event law that produces a new probability-map evidence semantics, not handcrafted whiff statistics.
