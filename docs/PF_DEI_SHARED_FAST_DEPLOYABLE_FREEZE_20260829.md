# PF-DEI SHARED FAST DEPLOYABLE FREEZE — COMPUTE-BOUNDED CROSS-ENVIRONMENT MODEL

Date: 2026-08-29
Status: FINAL COMPUTE/DEPLOYMENT CONTRACT BEFORE SHARED TRAINING

This contract supersedes the heavier Siamese-eight-TCN shared-comparator implementation proposal. It is activated before any shared-model result is observed. The purpose is to preserve the scientific claim while preventing another multi-hour/day reference-only training cycle and ensuring the learned weights are the actual cross-environment deployable asset.

## 1. Deployment invariant

The final neural asset must be one shared set of weights across environments. A new environment may regenerate source-independent geometry/wind-conditioned native GADEN predictive banks and perform source-independent sensor calibration, but may not retrain or fine-tune neural weights using source labels or localization error.

House-specific H01/H02/H03 models are diagnostic/reference only and are not deployable final assets.

## 2. Final shared inference object

For observed measured sequence y_obs[t] and candidate carrier s with frozen predictive ensemble y_sim[j,t], j=1..8, learn a physics-conditioned compatibility score r_psi(D_obs, P_s, geometry, wind).

The model must compare observation to the candidate's predictive ensemble explicitly. It must not take House ID, source truth, historical error, or hidden latent placement as an input.

Posterior remains:
q_t(s) proportional q0(s) * exp(r_psi(s,t)).
No native-gas posterior multiplication, temperature fitting, KL blend, Active Probe, or House-specific threshold.

## 3. Compute-efficient physics residual set encoder

Do NOT run a full temporal encoder independently on the observed sequence and all eight simulated members.

At each time sample t:

1. transform observed and simulated measured ppm using the fixed physical transform
   a_t = log1p(max(y_obs[t],0)/thresholdGas)
   b_jt = log1p(max(y_sim[j,t],0)/thresholdGas)
2. for each member j build
   v_jt = [a_t, b_jt, a_t-b_jt, abs(a_t-b_jt), (a_t-b_jt)^2]
3. apply a shared member MLP phi to every v_jt:
   5 -> 24 -> 16, GELU
4. aggregate over the eight members with permutation-invariant first and second moments:
   m_t = mean_j phi(v_jt)
   v_t = mean_j phi(v_jt)^2 - m_t^2
5. concatenate [m_t, v_t] with source-independent/candidate-fixed context fields:
   - robot position relative to carrier free-cell centroid, divided by map diagonal;
   - measured wind x/y in SI units with fixed predeclared physical clipping only;
   - delta_t / 0.2 s;
   - stop-start marker;
   - block-boundary marker;
   - carrier rectangle width/height divided by map diagonal;
   - 2x2 free-cell mask;
   - normalized free-cell count.

This produces one per-time physics-residual representation. Only this one sequence is passed through the temporal encoder.

## 4. Frozen temporal encoder

Use one causal TCN:
- input projection -> width 48 -> GELU;
- 8 residual causal Conv1D blocks;
- width 48, kernel 5;
- dilations 1,2,4,8,16,32,64,128;
- LayerNorm + GELU;
- masked global mean pooling concatenated with final valid hidden state;
- head 96 -> 48 -> 1, GELU.

No Transformer/RNN/attention/architecture sweep.

This architecture is intentionally cheaper than encoding 9 long sequences separately and is the final deployment architecture if it passes LOHO.

## 5. Training construction and leakage controls

Positive observation generated by nuisance member j must exclude exact member j from the candidate predictive ensemble. Use the remaining seven members for the positive candidate comparison. Negative candidate uses the exact same observed sequence, trajectory and environment while changing only carrier s- sampled from q0.

Balanced BCE joint-vs-product classification.

No House ID. No held-out House samples in training, validation, checkpoint selection, normalization fitting or feature-statistic estimation.

All feature normalization must use fixed physical constants or training-House-only statistics frozen before held-out evaluation.

## 6. Compute budget

Shared LOHO qualification uses one optimization seed 2701 per fold.

Training recipe:
- AdamW lr 3e-4, weight decay 1e-4;
- batch 64 candidate comparisons where memory permits; otherwise 32 without changing gradients via accumulation;
- max 25 epochs;
- early-stop patience 4;
- gradient clip 1.0;
- mixed precision/TF32 are allowed as engineering acceleration because neural bitwise reproducibility is not a scientific requirement; record framework/CUDA/GPU versions and exact weight hashes;
- no change to scientific data, nuisance members or labels;
- validation every epoch.

If one fold epoch time exceeds 12 minutes after the first two warm-up epochs, treat this as an engineering/data-loader problem and optimize batching/I/O only. Do not increase the scientific training budget.

No LOHO fold may exceed 25 epochs. No patience reset can extend beyond max 25.

## 7. Strict LOHO

Run exactly:
- H01+H02 -> H03
- H01+H03 -> H02
- H02+H03 -> H01

Held-out House contributes only its source-independent native predictive bank at qualification/inference time.

Synthetic LOHO thresholds are frozen before results:
- true carrier top-5 recall >= 0.70;
- median normalized true-carrier rank <= 0.15;
- mean log posterior/prior gain > 0;
- rank beats q0 baseline;
- member and carrier permutation invariance;
- zero forbidden-field leakage.

Any fold failure => PF_DEI_SHARED_LOHO_NO_GO. No House-specific rescue.

## 8. Historical truth-blind predictive gate

Only if all synthetic LOHO folds pass, apply each frozen fold model to the 10 historical OFF runs of its held-out House with no true source/error access.

Use the existing four chronological prefix/future splits and future predictive energy-score comparison. Each House must pass >=5/10 and positive mean future predictive gain.

Failure => PF_DEI_SHARED_HISTORICAL_PREDICTIVE_NO_GO.

## 9. Final deployment weights

Only after all LOHO gates pass, train final shared ensemble on simulation data from H01+H02+H03 with exactly the same architecture/objective and seeds 2801,2802,2803. Train the three seeds in parallel where hardware permits.

These are the only final neural weights. New environments do not retrain them.

## 10. Runtime compute contract

Real deployment must not recompute a full candidate history from scratch at every source update if incremental causal state caching is possible.

Implement batched candidate inference and cache causal-TCN convolution state per candidate across updates. Only newly arrived samples are appended. The native predictive bank is indexed by candidate and timestamp/trajectory schedule.

Measure source-update inference latency. Target: inference wall time <= 10% of the native sensing/source-update interval on the deployment computer. If latency fails, optimize batching/caching/kernel implementation only; do not prune source candidates or change posterior semantics without a separately frozen method revision.

## 11. Real-world deployment caveat

The current simulation benchmark freezes Q=10 ppm. A future real-world experiment is scientifically valid without retraining only if either:
(a) physical source emission strength is externally controlled/calibrated to the benchmarked regime; or
(b) before any real-world localization outcome is observed, a source-independent Q-nuisance extension is frozen and simulator linearity/scale semantics are proven.

Do not use real source labels to calibrate Q.

Likewise, real-room wind/map preparation and sensor calibration must be source-label independent.
