# PF-DEI shared cross-environment freeze — post-H01 reference gate

Date: 2026-08-29
Status: **CONDITIONAL FINAL SHARED-MODEL CONTRACT**

This file becomes active **only if the already-running H01 house-specific reference model passes its original reserved qualification without restart or scientific modification**. The H01 model is retained only as an identifiability/reference upper bound. It is not the final deployable method.

If H01 reference qualification fails, terminate `NEURAL_PF_DEI_NO_GO`; do not train a shared model.

## 1. Deployment claim to be tested

The final deployable method must use **one set of neural weights across environments**.

For a new environment, allowed environment-specific work is limited to:

- source-independent map/geometry preparation;
- source-independent wind-field/configuration preparation;
- source-independent sensor calibration;
- generation/query of the native GADEN predictive bank for that environment.

Forbidden for a new environment:

- training or fine-tuning neural weights using source labels;
- using true source/location error to tune the model;
- House-specific thresholds, temperatures, blend weights, or architecture changes.

The target claim is therefore:

> **new environment = regenerate physics bank, not retrain inference weights.**

## 2. Final shared inference object

Do not use a direct House-specific classifier `f(D,s,House)` as the final method.

The shared model is a **physics-conditioned observation-to-predictive-ensemble comparator**.

For an observed causal prefix `D_obs[1:t]`, candidate carrier `s`, environment `kappa`, and the frozen V3 native predictive ensemble for that same candidate/trajectory,

`P_s = {D_sim_j[1:t] : j=1..8}`,

the shared model estimates a source-support ratio score

`r_psi(D_obs[1:t], P_s, geom_s, trajectory_context)`.

The predictive ensemble is generated by the already-frozen V3 chain

`(carrier region S, latent 3-D placement U_j, transport Z_j, Q=10) -> physical ppm -> persistent native sensor -> simulated measured ppm`.

The neural model therefore learns how to compare a real/held-out sequence with a candidate's **physics-predicted distribution**, instead of memorizing a House-specific source map.

No House ID is an input feature.

## 3. Candidate prior and posterior

Preserve the V3 carrier prior exactly:

`q0(s) = |F_s| / total_free-cells`.

For candidate scores `r_psi`, form

`q_t(s) proportional q0(s) * exp(r_psi(D_obs[1:t], P_s,...))`.

Do not multiply by the native gas posterior from the same observations. Do not use KL blend, temperature fitting, Active Probe, or House-specific thresholds.

## 4. Shared comparator architecture

The architecture is frozen before any LOHO result.

### 4.1 Sequence representation

For both the observed sequence and every simulated ensemble-member sequence, use the same causal per-sample fields:

- `log1p(measured_ppm / thresholdGas)`;
- robot position relative to the candidate carrier free-cell centroid, normalized by that House map diagonal;
- measured/known wind vector at that sample in the frozen physical normalization;
- `delta_t / 0.2 s`;
- stop-start marker;
- block-boundary marker;
- fixed carrier-region descriptors: rectangle width/height, 2x2 free-cell mask, normalized free-cell count.

Absolute House ID and historical true-source fields are forbidden.

### 4.2 Siamese causal encoder

Use one shared causal TCN encoder `E_psi` for observed and simulated sequences:

- input projection -> width 48 -> GELU;
- residual causal Conv1D blocks, kernel 5;
- dilations `1,2,4,8,16,32,64,128`;
- width 48 throughout;
- LayerNorm + GELU;
- masked global mean pooled embedding concatenated with final valid hidden state;
- embedding dimension 96.

The same encoder weights process observation and simulation members.

### 4.3 Member comparison and permutation-invariant aggregation

For each predictive member `j`:

`z_o = E_psi(D_obs)`

`z_j = E_psi(D_sim_j)`

Build pair representation

`h_j = MLP_pair([z_o, z_j, z_o-z_j, z_o*z_j])`

with fixed widths `384 -> 96 -> 48`, GELU.

Aggregate predictive members by arithmetic mean:

`h_set = mean_j h_j`.

Final logit:

`r_psi = MLP_out(h_set): 48 -> 32 -> 1`.

Member order must be permutation invariant numerically; explicit permutation tests are mandatory.

No attention/Transformer/RNN architecture sweep is allowed.

## 5. Training construction

### 5.1 No exact self-match shortcut

For a positive training observation generated by V3 nuisance member `j`, its positive candidate predictive set must exclude that exact generating member and use the other seven training members.

This is a leave-one-member-out predictive comparison, preventing the model from solving the task by exact trace retrieval.

For a negative source carrier `s_minus`, use the same observation, same trajectory, same environment, and that alternative carrier's predictive ensemble.

Positive and negative candidate carriers are sampled from the same frozen carrier prior.

### 5.2 Training objective

Balanced BCE joint-vs-product classification. The observation is held fixed when constructing the negative candidate.

Optimizer:

- AdamW;
- learning rate `3e-4`;
- weight decay `1e-4`;
- batch size 32 candidate comparisons;
- gradient clip 1.0;
- maximum 60 epochs;
- early-stop patience 8 on simulator-only validation BCE;
- deterministic CUDA as already used in the H01 reference.

No hyperparameter change after seeing an LOHO result.

## 6. Strict three-fold leave-one-House-out (LOHO)

The shared-model claim is qualified only by all three folds:

1. train on H01+H02, test H03;
2. train on H01+H03, test H02;
3. train on H02+H03, test H01.

For LOHO qualification, the held-out House contributes **zero neural-training examples and zero validation examples**.

Its map/wind/physics bank is allowed at inference because this is exactly the proposed deployment contract: new environment -> physics bank, frozen weights.

Use one frozen LOHO optimization seed `2701` per fold. These models are qualification models only, not final deployment weights.

## 7. Held-out-House synthetic qualification

For each held-out House, evaluate only reserved V3 nuisance members and reserved trajectory skeletons. The observation-generating reserved nuisance member must never appear in the 8-member candidate predictive ensemble.

Use the same deterministic 32-carrier qualification set and at least 128 cases per held-out House.

A LOHO fold passes only if all hold:

- true carrier top-5 recall >= 0.70;
- median normalized true-carrier rank <= 0.15;
- mean log posterior/prior gain at true carrier > 0;
- carrier-index permutation invariance;
- predictive-member permutation invariance;
- zero forbidden-field leakage;
- mean true-carrier rank beats q0 prior baseline.

The thresholds are slightly weaker than the H01 environment-specific reference because this gate tests cross-environment transfer, not the environment-specific upper bound. They are frozen before any LOHO result.

Failure of any fold is terminal:

`PF_DEI_SHARED_LOHO_NO_GO`.

No House-specific retraining follows.

## 8. Held-out-House historical truth-blind predictive qualification

Only after the synthetic LOHO gate passes, apply that fold's frozen model to the 10 historical OFF runs of its held-out House without reading source truth/error.

At each of the same four chronological prefix/future splits:

- infer `q_t(s)` from the real measured prefix;
- construct candidate future predictive mixtures from the held-out House native bank;
- compare posterior predictive energy score with the frozen geometry-prior predictive mixture.

Held-out House passes iff at least 5/10 runs pass the existing future-predictive contract and the mean future predictive gain across the 10 runs is positive.

All three held-out Houses must pass.

Failure is terminal:

`PF_DEI_SHARED_HISTORICAL_PREDICTIVE_NO_GO`.

## 9. Train final shared deployment ensemble only after LOHO PASS

If and only if all three LOHO synthetic and historical predictive gates pass, train the final shared deployment model on simulation data from H01+H02+H03 using the identical architecture/objective.

Use frozen final training seeds:

`2801, 2802, 2803`.

Runtime logit = arithmetic mean of the three shared-model logits.

No House-specific weights remain in the final method.

Freeze all weights/hashes before opening development localization truth.

## 10. Development and real-world deployment

The existing V3 runtime source-posterior replacement and planner contracts remain unchanged, except the inference engine is this final shared ensemble.

Development 60-arm remains:

`H01,H02,H03 x seeds0..9 x OFF/ON`, 300 s.

GO criteria remain unchanged:

- pooled expected-location error reduction >=10%;
- >=20/30 paired runs improve;
- no House pooled mean degradation >5%;
- zero new false-confident collapses.

For a future physical room, neural weights remain frozen. Allowed new-room work is only source-independent geometry/wind/sensor calibration plus generation of that room's native predictive bank. Source-labelled real flights are evaluation, not training.

## 11. Claim discipline

If successful, claim:

> a shared physics-conditioned spatiotemporal inference model transfers across held-out simulated environments when supplied only with each new environment's source-independent physics bank.

Do not claim universal zero-shot transfer to arbitrary real buildings until a physically held-out real environment is tested.
