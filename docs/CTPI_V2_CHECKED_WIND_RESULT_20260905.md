# 风场输入：求解检查与时间证据消融

状态：`CHECKED_WIND_ABLATION_NOT_M1_OR_CLOSED_LOOP_PASS`。
本轮是已花费 H01 seed12 A0 风记录的确定性计算，不是新的 House 闭环。
源真值、气体数据及 bank 均未访问。目标仍是取得 M1/M2 真实有效性证据，未完成。

## 实现改变

新增 `CTPIGmrfCheckedWindV2.hpp`，不修改当前安装的 GMRF 库，也不覆盖旧参考路径。
针对底层更新函数返回 void、内部可能捕获异常的问题，新版本：

1. 每次线性求解前把旧解置为 NaN，防止早退后复用上次的解。
2. 检查 Cholesky 状态、H 与解的有限性。
3. 从实际观测因子独立重建右端项 G，验证 `H solution = G` 的归一化后向残差。
   保持当前源码的协方差行列式下限，不借机更换噪声模型。
4. 检查输出场严格满足原算法 `new = 0.5 solution + 0.5 old` 的更新关系。
5. 重复原 Picard 步，至少两次，使用原有相对变化阈值 0.01；最多 100 次。
   这是数值资源上限，不是可随 House 调整的算法参数。
6. 任一失败使这个风生产器不可继续使用；不输出假完成标记。

这些检查证明的是当前数值步骤满足指定方程及停止条件，不是非线性全局最优、
真实物理风场、联合不确定性校准或源位置可辨识。

## 执行前固定的比较

契约：`CTPI_V2_WIND_SOLVER_TEMPORAL_ABLATION_20260905.json`。
两臂均使用上轮已哈希绑定的导航高度地图、同一 1200 条风记录、原权重与噪声设置：

- `checked_cumulative`：保留全部历史观测，只改求解检查和收敛。
- `checked_latest_cell`：使用同样的检查，但每个 GMRF 格只保留最新风观测。
  其他格仍保留最后观测，不设置可拟合时间窗。它只是检验时间证据语义的对照，
  不是可保证动态场准确性的滤波模型。

位置查询在当前风值入图之前执行；不使用被预测的风值，也不使用气体观测。
旧 R3 的一次迭代、累计历史结果作为保留的对照，没有覆盖或重新选择输入。

`checked_cumulative` 的平均迭代次数 2.371667，最大 15；
最大归一化线性残差 `7.870414156507263e-14`，更新方程偏差为 0。
其同打印位置 RMSE 为 0.367774，改变打印位置 RMSE 为 0.411421，
对应保持上一读数为 0.250824 与 0.361809。
完成数值收敛修正仍未弥合当前条件均值预测与保持基线的差距。
这不排除其他数值或物理问题，也不证明 M1 思路失败。

`checked_latest_cell` 已接受并完成 110 次更新，在 step=111、t=22.2 s 的更新中
达到 100 次迭代上限仍未满足阈值。记录为
`GMRF_FIXED_POINT_DID_NOT_CONVERGE_WITHIN_RESOURCE_LIMIT`，没有完成标记。
已写出的第 111 步预测来自 t=22.0 的先前场；它不是第 111 次更新成功的证据。
没有增加迭代上限、改权重或省略该观测。其有利或不利前缀均不作为完整比较。

这次失败只否定“当前这套非线性 Picard 更新可以直接配上每格最新观测并稳定执行”
的运行前提；不证明一切动态风模型不可行，也不支持继续使用它的失败后状态。
