# 同源可达预历史不是单独充分的识别条件

检验用途：为当前 M1 候选做实施前准入判断，而非增加一个可称为模块 PASS 的单测。
没有改控制器、使用 House 浓度或真值、生成 bank 或启动新 seed。

考虑候选改进：初始气团不再取任意非负向量，而必须由该候选源的过去释放生成。
这是一条真实的物理一致性约束，但不能仅凭该约束宣称源位置可辨识。

## 可达的反例

使用原三格模型的已实现推进，a=u+D=0.51，dt=0.2，未来两源释放率均 q=1。
令 d=q/a。观测开始前一个时间步，两模型均从零气场开始：

- A 源位于格0，该步释放率 d/dt；
- B 源位于格1，该步释放率0。

这一模型的单步末端注入产生 xA(0)=d e0、xB(0)=0；**没有手工指定初场**。
随后两模型均连续以 q 释放。生成元 Q 满足

`Q(d e0) + q(e0-e1) = 0`。

因此其状态差始终为 d e0。任意只观测格1/2的路径都看不到这个差异。
测试交替观测格1/2，并通过实际 FOPDT；两传感器使用同一已声明的启动状态0。
这与气场是否已有预历史是两个问题，没有用传感器启动代替零初场假设。

VM C++17 编译执行1200步后，最大观测场差8.53e-14，传感器差7.11e-14。
最后30步改测格0的单位测试正控制，差为1.942346。正控制不授权实际导航改动。

## 正确的结论边界

反例中的过去释放率是为代数见证构造的，不是 House 标定值，也没有满足某个指定
GADEN随机释放先验的主张。它说明：**对任意非负释放历史，增加“同源可达”限制
仍不足以保证唯一源位置**。

这不是两源在某个共同随机先验下的完整观测分布相等证明。
一个有来源的释放概率规律可能给这些历史不同权重，进而使边缘源分布不同；
但那种信息必须作为统计假设明确展示，不能归功于因果符号或省略初场。
它也不否定其他路径、输运条件或真实 House 中可能存在的辨识信息。

对本轮唯一候选的直接决定：不能把“同源生成预历史＋标准边缘化”单独作为已立住的
识别创新进入昂贵实现。需要具体说明额外识别信息或计算贡献；普通贝叶斯可以是求解器，
不要求它输给同模型的新名字。
