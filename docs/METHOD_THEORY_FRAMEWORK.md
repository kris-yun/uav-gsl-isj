## 模块1: Poisson Filament检测模型

### 公式
```
φ(s) = σ(γ·(d₀ - d)) × (1 + α_w·cosθ·c_w)
```
其中：
- σ(·) = sigmoid函数
- d = ||s - c|| = 源假设位置与当前位置的欧氏距离
- d₀ = 1.5m = 特征检测距离
- γ = 2.0 = 过渡锐度
- θ = 风向与源-UAV连线的夹角
- α_w = 风向调制系数
- c_w = 风场置信度

### 理论依据

**为什么用sigmoid而不是指数衰减？**

传统方法用 exp(-d/ℓ)，但：
- 在室内低风环境中，气体filament的浓度分布不是平滑指数衰减
- GADEN仿真数据表明：检测概率在d≈1.5m处从"高"过渡到"低"，呈S形
- sigmoid是二分类问题的标准链接函数（logistic regression）

**d₀=1.5m和γ=2.0的来源：**

从GADEN House01场景的统计分析：
- 在300个随机位置采样，记录是否检测到气体
- 按距离分箱，计算每箱的检测频率
- 拟合logistic曲线：d₀=1.5m（中位检测距离），γ=2.0（过渡宽度≈1m）

3. 敏感性分析：d₀∈{1.0, 1.5, 2.0}，γ∈{1.0, 2.0, 3.0}对最终误差的影响

## 模块2: GBI后验更新 + Surprisal η

### 公式
```
π_{t+1}(s) ∝ π_t(s) × exp(-η_t · ℓ_t(s))

ℓ_t(s) = -log P(z_t | s, wind)   // 对数损失

η_t = {
  -log(φ_map),      if detected
  -log(1-φ_map),    if not detected
}
clamp(η_t, 0.05, 1.0)
```

### 理论依据

**为什么用GBI而不是标准贝叶斯？**

标准贝叶斯的η=1，在模型误设时会收敛到错误值（Grünwald 2012 SafeBayes）。

GBI (Bissiri et al. 2016 JRSS-B) 证明：
- 当η∈(0,1)时，后验收敛到"最优近似"而非"错误的真实"
- η越小，对模型误设越鲁棒，但收敛越慢

**为什么用surprisal作为η？**

surprisal = -log P(观测 | 最佳假设)

这是**信息论中观测信息量的标准度量**（Shannon信息量）。

直觉：
- 如果MAP预测φ_map=0.8（应该能检测到），实际检测到了 → surprisal=-log(0.8)=0.22 → η低，因为这是"意料之中"的观测
- 如果MAP预测φ_map=0.05（不太可能检测到），实际检测到了 → surprisal=-log(0.05)=3.0→η=1.0，因为这是"非常意外"的观测

**关键优势：零手调常数**

η完全由Poisson模型的预测推导，不需要任何额外参数。

**循环依赖问题的处理：**

MAP → φ_map → η → 更新后验 → 新MAP

类比Kalman滤波器：
- Kalman增益K依赖当前状态估计x̂
- x̂依赖K
- 但Kalman滤波器 provably 收敛

在我们的case中：
- 随着后验集中（GBI在KL可辨识条件下保证），φ_map → φ(s_true)
- η收敛到固定点
- clamp[0.05, 1.0]保证数值稳定

2. 推论：当后验集中时，η收敛到-sigmoid(s_true)
3. 证明sketch（不需要完整证明，ISJ不要求）

## 模块3: E-Process停止规则

### 公式
```
M_t = ∏_{i=1}^{t} [1 + λ · (ℓ_t(s*) - ℓ_t(ŝ_t))]

停止当 M_t ≥ 1/δ  (δ=0.10)
```

### 理论依据

**什么是e-process？**

e-process M_t 是一个检验超鞅（test super-martingale），满足：
- E[M_t | F_{t-1}] ≤ M_{t-1}（在H₀下）
- P(sup_t M_t ≥ 1/δ) ≤ δ（anytime-valid）

**零假设H₀是什么？**

H₀: 后验MAP未收敛（MAP残差 > 阈值）

**与SPRT的区别：**

| | E-Process | SPRT |
|---|-----------|------|
| 保证类型 | anytime-valid | fixed-sample |
| 适用场景 | 不知道何时停止 | 有明确的N |
| 理论基础 | 游戏论统计 | 似然比检验 |

**论文中引用**：Ramdas et al. (2023) "Game-theoretic statistics"

## 模块4: SPRT停止规则

### 公式
```
S_t = Σ LLR_i

LLR_i = log(r₀/r₁) + (1/r₀ - 1/r₁) · r_i

停止当 S_t ≥ A = log((1-β)/α)  (接受H₁:已收敛)
       S_t ≤ B = log(β/(1-α))  (接受H₀:未收敛)
```

### 理论依据

**模型假设**：MAP残差 r_t ~ Exponential(λ)

**参数来源**：
- r₀ = 2.0m：未收敛时MAP的典型步间跳动（= 网格分辨率0.5m × 4格）
- r₁ = 0.3m：收敛后MAP的典型稳定性（= 源附近MAP抖动幅度）
- α = 0.05，β = 0.10：标准假设检验错误率

**Wald-Wolfowitz最优性**：SPRT在所有达到相同(α,β)的序贯检验中，期望样本量最小。

**论文中引用**：Wald (1945), Wald & Wolfowitz (1948)

## 模块5: 三阶段导航

### 阶段划分
1. **下风向探索**（气体命中<3次）：沿风向搜索，最大化覆盖
2. **上风向追踪**（检测到气体）：沿风向上游移动
3. **自适应收敛**（后验集中）：向MAP移动，GP选择高度

### 理论依据

**生物学基础**：昆虫嗅觉搜索的三阶段模式（Willis 2008）：
- Casting（横向搜索，寻找气味）
- Tracking（沿气味追踪）
- Source declaration（确认源位置）

**信息论基础**：Vergassola et al. (2007) infotaxis证明了在稀疏气味环境中，三阶段策略是最优的。
