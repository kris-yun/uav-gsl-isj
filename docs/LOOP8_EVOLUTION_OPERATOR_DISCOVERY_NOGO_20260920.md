## Remote-domain provenance

The candidate was motivated by recent top-conference work:

- ICML 2025 — Morel, Han, Oyallon, *DISCO: learning to DISCover an evolution Operator for multi-physics-agnostic prediction*.
  The key idea is to infer a compact evolution operator from a short trajectory and then use a small operator network for state evolution, separating dynamics identification from state prediction.
- ICML 2025 — Zhang et al., *KoopSTD: Reliable Similarity Analysis between Dynamical Systems via Approximating Koopman Spectrum with Timescale Decoupling*.
  The scientific object is dynamical-system identity/similarity represented through Koopman spectral structure with explicit timescale decoupling.
- ICML 2025 — Xu et al., *ResKoopNet: Learning Koopman Representations for Complex Dynamics with Spectral Residuals*.
- ICML 2025 — Bai & Ding, *KoNODE: Koopman-Driven Neural Ordinary Differential Equations with Evolving Parameters for Time Series Analysis*.

A direct GSL/OSL collision search did not find a 2025/2026 source-localization method built around learned evolution-operator identity or Koopman-spectrum source fingerprints. Recent source-estimation reviews mention DMD as a flow reconstruction/prediction tool, which means the broad dynamical-systems tool itself is known nearby; novelty would have required a source-identifying operator object.

## GSL hypothesis tested

Candidate thesis:

> A short gas/wind trajectory generated by one source contains a source-specific evolution operator that is more stable across wind than across source changes.

If true, source localization could compare an inferred operator/fingerprint against source hypotheses instead of directly comparing concentration histories.

## Minimal offline test

Existing frozen controlled histories:
- H01/H02/H03 × {SA,SB} × {fast,slow}.

For each history, fit source-blind ridge AR and ARX fingerprints:
- log-concentration delay orders p = 5, 10, 25;
- ARX additionally conditions on local wind and robot pose;
- horizons = 120, 180, 240 s.

Primary criterion:
same-source/different-wind operator distance < different-source operator distance.

Destructive control:
reverse the time series before fitting the same operator fingerprint.
A genuine directional/evolution-law source signature should be detectably damaged.

## Results

### H01
- 120 s: operator fingerprints separate sources (2/2), but time reversal leaves the result essentially unchanged.
- 180 s: all tested AR/ARX fingerprints fall to 1/2.
- 240 s: 2/2 returns, but the reversed-time fingerprints remain almost identical in discrimination.

### H02
- 120 s: no operator variant identifies the source (0/2), consistent with absent/insufficient physical support.
- 180/240 s: 2/2 is obtained, but time reversal again leaves ratios and decisions almost unchanged.

### H03
- 120/180 s: 2/2, with only modest degradation under reversal.
- 240 s: every tested AR/ARX operator falls to 1/2; same-source cross-wind operator distance can exceed cross-source distance.

## Decision

The simple evolution-operator fingerprint fails two essential gates:

1. **No stable cross-regime identity:** H01 at 180 s and H03 at 240 s break the source-specific-operator premise.
2. **Destructive control failure:** reversing temporal order usually leaves the operator discrimination nearly unchanged, so the apparent signal is largely autocorrelation/amplitude structure rather than a uniquely directional evolution law.

Therefore:

```
EVOLUTION_OPERATOR_SOURCE_IDENTITY = NO_GO
DISCO_AS_MAIN_INNOVATION = REJECT
KOOPMAN_SOURCE_FINGERPRINT = REJECT_IN_CURRENT_FORM
```

Do not rescue this line with a larger Koopman network or more spectral machinery unless a new source-specific physical invariant is first identified. A larger model would currently be method substitution without evidence.
