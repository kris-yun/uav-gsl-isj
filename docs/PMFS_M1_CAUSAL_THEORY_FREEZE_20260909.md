# M1 causal theory freeze: source-intervention, sensor-consistent likelihood

**Status:** design freeze.  This document defines the only M1 causal claim that
may be implemented or evaluated next.  It is not a performance claim and it
does not authorise a new multi-seed run.

## 1. The causal object

For a source candidate `c`, a fixed realised source-blind flight history
`A_{0:t}`, and a realised transport context `U_{0:t}`, define the counterfactual
exposure

`X^c_{0:t} = Transport(do(S=c), A_{0:t}, U_{0:t}, M)`.

`M` denotes residual transport-model discrepancy.  The measured concentration
is generated by the known sensor dynamics

`Y_{0:t} = H(X^S_{0:t}) + epsilon`,

where `H` is the exact delayed, piecewise-linear FOPDT sensor operator used by
the simulator.  The M1 estimand is therefore the candidate intervention
likelihood

`L_t(c) = integral p(Y_{0:t} | H(X^c_{0:t}), U_{0:t}, M) p(M | U_{0:t}) dM`.

The posterior update compares `L_t(c)` across candidates.  In plain language,
M1 asks: *with the same route, wind history and sensor law, would replacing the
true source by candidate `c` have produced the observations we actually saw?*
This `do(S=c)` comparison, rather than a late posterior update, covariance
penalty, or correlation feature, is the causal part of M1.

## 2. What the implementation must and must not do

The implementation may use a finite transport-member approximation to the
integral above, but each member must preserve a **time-resolved candidate
exposure trace** before application of `H`.  It must retain the FOPDT state
across observations.  An aggregate candidate exposure map followed by an
independent FOPDT reset at every PMFS update is not an implementation of this
estimand.

The member hierarchy represents partial, rather than unconditional, invariance: stable source-to-exposure structure is shared, while each transport
member is allowed its own residual response.  It must not subtract or average
away source-by-transport interaction.

`180 s` is not a causal rule.  The observed late emergence of a source main
effect is only a development diagnostic.  The online gate must instead be
computed from quantities available to the controller: predicted pairwise
candidate contrast, member disagreement, route coverage, and sensor-state
uncertainty.  When the lower confidence bound on contrast does not exceed the
transport/sensor discrepancy bound, M1 abstains from a concentrated source
update and the baseline exploration policy remains in control.

## 3. Recent theory and the precise mapping

| Theory | What it supports here | What it does **not** support |
|---|---|---|
| Madaleno et al., *Bayesian Hierarchical Invariant Prediction* (CLeaR 2026) | A hierarchical testable treatment of partially invariant mechanisms across heterogeneous environments; this motivates retaining transport-member effects rather than imposing global invariance. | It does not establish source identifiability or a PMFS performance gain. |
| Vishnubhatla et al., *Proxy-Guided Measurement Calibration* (CLeaR 2026) | The need to separate latent physical content from the observation/measurement operator. | Our deterministic FOPDT sensor is **not** an independent bias proxy.  No proxy-identification claim is permitted unless such a proxy and its independence assumption are added and tested. |
| Asiaee et al., *Sharp Bounds for Treatment Effect Generalization under Outcome Distribution Shift* (CLeaR 2026) | A sensitivity-bound discipline for transportability failure: uncertainty under a bounded shift should widen/abstain rather than be tuned to make a result win. | A sensitivity parameter is not a planner weight and cannot be selected using closed-loop gain. |
| Brouillard et al., *Learning a Spatial Partitioning and its Causal Relations from Temporal Data* (CLeaR 2026) | Temporal observations alone need structural constraints; this motivates explicit route, transport, and sensor constraints in the counterfactual likelihood. | It does not make raw PMFS histories causal by itself. |

Primary sources: [BHIP](https://proceedings.mlr.press/v323/madaleno26a.html),
[Proxy-Guided Measurement Calibration](https://proceedings.mlr.press/v323/vishnubhatla26a.html),
[Sharp Bounds under Outcome Distribution Shift](https://proceedings.mlr.press/v323/asiaee26a.html), and
[Spatial Partitioning from Temporal Data](https://proceedings.mlr.press/v323/brouillard26a.html).

## 4. Falsifiable assumptions and gates

1. **Forward-law fidelity.** Candidate exposure traces and the exact FOPDT law
   must predict held-out observations in the source-by-wind factorial
   development microbank.  A good fit only after seeing the true source fails
   this gate.
2. **Conditional observability.** Before an online posterior update, the
   lowest plausible candidate contrast must exceed member and sensor uncertainty.
   Otherwise the correct output is abstention, not a weaker source claim.
3. **Environment separation.** House identity, true source coordinates,
   future gas values, and evaluator labels are unavailable to the controller.
   Wind/map coordinate alignment is verified before the likelihood gate.
4. **Transportability.** Shift sensitivity is fixed before the held-out House
   run.  Overlapping candidate likelihood intervals force abstention; they may
   not be broken by a gain, time threshold, or posterior-mass heuristic.
5. **Closed-loop evidence.** Only after Gates 1--4 pass may one House-1/2/3,
   one-seed pilot compare this M1 to the frozen baseline.  A pilot success is
   not cross-dataset proof; a pilot failure is a causal-premise NO-GO unless a
   formula--code contradiction is demonstrated.

## 5. Consequence for the current PHIC code

The present PHIC implementation is a useful diagnostic but fails Gate 1: it
uses aggregate candidate exposure and resets sensor state on every source
update.  It therefore cannot be described as this causal M1 and will not be
tuned or sent to another closed-loop run.  The next permitted engineering task
is narrowly scoped: implement and unit-test the time-resolved
candidate-by-member exposure cache plus stateful exact sensor likelihood, then
run the factorial forward-law gate.  No M2 change is in scope.
