# V11独立复核与已完成的16次原生函数诊断

本轮裁决：V11推进了证据定位，没有交付合格的主创新算法。它不是没有进展；当前成果是排除了部分解释。现在已把其提议的最小四臂诊断实际执行，结果继续收紧了方向：固定精确真源仍未解释关键正检出，不能把E3主要归结为粗区域混源，也没有建立必须用NGDB补救的有限采样证据。

## 2. 四臂结果：未救回锁定源对

使用E3第4次源更新的同一局地风/GMRF快照、二维源支持、障碍规则、噪声0.5、最大warm-up500步、记录200步、deltaTime0.1。保持原生“同一记录步至少一个气团中心占格”事件。

| 臂 | 释放位置规则 | 4次原生兼容分数的均值 | 第9—13停留点的预测 |
|---|---|---:|---|
| A | 每气团在原5×4区域重新抽源 | 3.8974343e-5 | 所有4次、所有5点均为0 |
| B | 4个事前抽定位置，各自固定释放一次完整场景 | 4.0640478e-5 | 所有4次、所有5点均为0 |
| C | 固定实际真源(-4,-1.9)，仅离线诊断 | 1.3387007e-5 | 所有4次、所有5点均为0 |
| D | 固定旧锁定错MAP(-2.375,-4.875) | 2.5311304e-2 | 各点0.865—1.0 |

这5个停留点的真实记录各为5/5hit，共25个正窗口。固定精确真源C对锁定错源D的分数方向4次均未翻转，D/C约1658—2137。这里是原生兼容分数比，不是已校准的Bayes因子。

第8停留点出现有限波动：A为0、0.04、0.045、0.115；C为0、0、0.005、0.02。说明原来的所有零不能一概写成严格不可达。但主要的后5点矛盾仍存在，未形成“增加普通重复即可恢复源判别”的结果。

B的“先算每场景分数再平均”为4.0640478e-5，“先平均响应图再评分”为3.9211819e-5，两者不同，已分别保存。A/B也不是相同多气团事件的两个等价估计器：整个场景共享一个固定源，与每气团重新抽源，会改变联合占格事件。包内有可精确枚举的小例子，概率分别为0.5和0.75。

本轮四个预定均匀初态共享原生2500项高斯缓存，不能称四个独立物理世界，也不声称严格独立高斯轨迹或冻结程序冷启动的可控seed实验。未追加初态、改位置、换风、放开障碍或调阈值。

## 3. 正常反例：真源响应出现零，不是充分失败条件

对全部7条真源域合法的既有运行，使用与V11同口径的最终响应表，对照历史真实窗口，完整评分重放均通过。

| 运行 | 正窗口中真源代表图为零 | 原生Top-5%误差 |
|---|---:|---:|
| A2_R01_REFERENCE | 115/200 | 0.2425m |
| A2_R02 | 0/86 | 0.6132m |
| A2_R03 | 0/71 | 0.4972m |
| C3_R01 | 0/98 | 0.4296m |
| C3_R02（数据耗尽，未声明） | 0/105 | 0.6274m |
| D4_R01 | 0/45 | 0.7997m |
| E3_R01 | 30/62 | 3.2476m |

A2_R01虽然同口径有115个冲突正窗口，锁定MAP/真源分数比仅约1.10，定位仍接近真源。E3该比值约1339.76，错误MAP远离真源。应解释的是响应差异如何支持远处竞争源及形成大幅错误分差，不能仅把“有零响应”定为失效条件。

尤其这些表使用最终风估计去对照更早观测；它们是固定表诊断，不能当作各时刻的前瞻概率校准。A2反例也提示要区分风随历史改变、细胞代表位置和事件定义的影响。本轮没有据此认定时滞或GMRF是唯一根因。

## 4. V11说对了什么，哪里应收紧

正确：版本身份清楚；固定表源评分可复算；四种重评分没有恢复E3的MAP；不给不满足前提的母算法强发主创新资格；提议先做16次函数诊断而不是大规模ROS。

应收紧：四种固定表评分失败，只排除这四种诊断代理，不能排除所有统计方法、重新构建细化树或改变采样后可能有效。区域内重抽源确实与固定源场景不同，但本轮C的负结果已表明，它不足以单独解释这组关键零响应。小样本仍为零不证明严格物理零概率；不能因此宣布所有稀有事件方法永久无用。

## 5. 为什么仍没有合格主创新

缺口一：尚未有一个已验证的机制解释，指出在什么可描述条件下，合法局地信息生成的响应会系统性支持远处错源。候选原因仍包括风支持、二维输运、warm-up/记录时间、固定点代表、中心占格与真实浓度窗口事件差异。本轮去掉了部分分支，没有把剩余分支合并成唯一原因。

缺口二：NGDB的具体新增运算与当前瓶颈尚未对接。母论文研究条件扩散路径采样。它提高对既定过程的条件路径取样效率，不自动纠正错误漂移、观测算子或源身份。出处：[Neural Guided Diffusion Bridges, ICML2025](https://proceedings.mlr.press/v267/yang25af.html)，[原文](https://arxiv.org/html/2502.11909v2)。本次仅核查这一母方法与PMFS原文，没有宣称重新排查V11全部20篇来源。

还有两个必须推导的适配条件：目标是多气团联合占格事件，不能用单路径命中权重替代；原生噪声使用2500项缓存循环，不等同逐步独立Brownian增量。若另建独立增量SDE，应单列A′，并证明观测事件和目标概率如何对应，不能把更换随机过程的收益全记到NGDB。

缺口三：尚无同信息、同事件、同预算下超过普通强方法的可执行B结果，更没有新源/新物理世界上的独立增量。当前是4个源域合法场景配置中的7条已见程序运行，不是7个独立气体世界。E3单个错误声明不足以支撑跨场景通用主张。

PMFS原文已经讨论粗到细模拟的速度/精度折衷。因此仅细化源域、增加普通模拟或替换评分，首先应作为强对照，不能靠命名变成独立机制。出处：[PMFS原文IV-B/IV-C](https://arxiv.org/html/2304.08879v3)。

## 6. 交给Pro的下一步

现在不缺又一批原生ROS重复；增加同场景的闭环次数不能替代一个具体B。最小四臂证据已经补上，应让Pro据此修订机制，而不是再写“建议Codex先跑16次”。

只交付一个针对源条件响应证据的可运行主算子，列明它改变哪个变量或运算，以及在何种可核验前提下生效。若继续NGDB，先证明联合事件估计、目标随机律、误差来源与普通方差削减比较；若数据不支持有限采样缺口，就退出该精度型路线。若改观测接口，物理参数必须有来源，普通观测一致A′单独对照，不能自造年龄半径/源强后声称恢复论文算法。

新模块需在所有合格正反例上报告改善、伤害和不变，不只优化E3。当前SCREEN12与本轮16次都是开发证据；方法冻结后才谈独立确认。没有完整可执行B之前，本轮没有额外启动ROS闭环。

结论：V11方向中的“先找响应形成断点”是科学推进；“先补粗区域或直接上桥网络”尚无实验资格。新增原生函数结果和A2反例，已把可用的科学问题收紧到**响应条件失配如何形成远处错误源优势，以及怎样以同权限信息构造更可靠的候选源证据**，还不能宣称主创新已成立。
