# CTAER H03 one-shot development gate

CTAER is **Candidate-wise Time-Arrow Evidence Ratio**.  It reuses the frozen
TAORL observation representation and hardware-bounded sensor time constants,
but changes the candidate score from forward fit alone to the paired
forward-versus-reverse contrast at the same candidate and time constant.

Read in order:

1. `THEORY_AND_COLLISION_AUDIT.md`
2. `LITERATURE_TRACE.md`
3. `PREREGISTRATION_H03_SEED11.json`
4. `ctaer_h03_gate.py`

The H03 seed11 trace is exposed development data.  A pass can justify only a
new independently preregistered confirmation asset; it cannot establish
cross-dataset effectiveness or a main causal contribution.
