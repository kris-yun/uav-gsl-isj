## 2. What the Wisco audit actually establishes

Retain as scene evidence:
- low-altitude thermal structure can be strong;
- 6/16 usable strict M210 profiles across 3 dates show >=1 C sequential positive temperature difference in 10–100 m;
- occasional 60–100 m wind-direction contrasts >=30 deg exist, but the primary examples are mobile/sequential and concentrated on one day;
- one joint May24 window has strong wind/T/RH contrast, but no independent air-mass label.

These are valid reasons for treating lakeshore as a challenging application/validation scene, not as a proven first-paper causal novelty.

## 3. Strategic pivot

First-paper main innovation returns to a method question:

**Task-Sufficient Source–Plume World Model (TSS-SPWM)**

Goal:
learn a compact hidden state that is sufficient for:
1. source-location discrimination;
2. short-horizon plume/path/shape/concentration prediction relevant to UAV decisions;
while discarding nuisance variation that does not help these tasks.

Do NOT reconstruct a dense 3D plume merely for reconstruction accuracy.

Lake-shore meteorology enters as:
- environmental context;
- nuisance/shift/stress factor;
- later high-fidelity and real-flight validation;
not as an already-proven causal mechanism.

PMFS remains a classic baseline, not the mother framework.

## 4. Why this pivot is supported by the failed experiments

The sequence R1 -> R1A -> R1B -> Wisco audit shows:
- apparent scene-specific signals can be generated by generic residence time or model misspecification;
- dense/explicit physical interpretations are easy to over-attribute;
- the localization-relevant state is not identical to the full flow/plume state;
- the method must preserve source identity and prediction-relevant dynamics while remaining robust to plume realization, release level and wind/context shifts.

This is exactly the motivation for a task-sufficient latent representation.

## 6. Proposed three-module research logic

### Main innovation M1: source-task-sufficient latent state
Input history:
- UAV pose/trajectory;
- gas concentration or hit/miss;
- local wind;
- map/geometry when available;
- optional T/RH only as context, not mandatory lake-state truth.

Latent z_t must preserve:
- source coordinate/probability;
- short-horizon future observation distribution;
- coarse plume/path state needed for decision.

It should suppress:
- plume stochastic realization identity;
- release-amplitude nuisance where possible;
- irrelevant full-field detail.

### Auxiliary M2: flow-aligned latent memory
Update z_t with:
- UAV self-motion;
- wind-relative displacement;
- elapsed time.

Test whether a flow-aligned update preserves source ranking across trajectories/wind realizations better than:
- plain recurrent state;
- static aggregation;
- dense 3D reconstruction proxy.

### Auxiliary M3: ambiguity-triggered active probing
Only after M1/M2 show a positive offline signal:
- detect when competing source hypotheses remain indistinguishable;
- select a short action predicted to maximally separate their future observation distributions;
- equal-budget comparison against continue-current-path and generic information sampling.

Do not start M3 if M1 fails.

## 7. Required outputs to satisfy the supervisor

The first-paper method should output:
1. source-location probability map / coordinate estimate;
2. coarse plume path/centerline or transport-support descriptor;
3. plume shape descriptor or occupancy support at selected horizons;
4. short-horizon concentration prediction along UAV-relevant locations/trajectories;
5. uncertainty/reliability.

This satisfies “source + shape/path + concentration change + meteorological influence” without claiming full dense 3D CFD reconstruction.

## 8. T0 minimal feasibility experiment — before building a large network

Use the repaired clean S2X benchmark first.

Primary clean cases:
- H01/s0
- H01/s1
- H02/s0
- H02/s1
with fixed context, two sources per context, four independent realizations per source.

No new lake simulation.

### T0-A: Is a task-sufficient latent possible?
Construct observation histories at matched route/time budgets.

Compare representations with the SAME simple downstream source classifier/ranker:
A. raw observation history;
B. hand statistics / PMFS-like local evidence summary;
C. generic sequence autoencoder latent;
D. task-sufficient bottleneck latent.

Task-sufficient latent objective:
- source discrimination loss;
- future-observation predictive loss;
- bottleneck/minimality penalty;
- nuisance-invariance penalty across realizations of the same source/context.

Primary metric:
- held-out-realization source rank/AUC or pairwise source discrimination;
- cross-realization stability;
- future gas observation NLL/Brier.

The latent wins only if it improves source discrimination/generalization without requiring lower full-field reconstruction error.

### T0-B: Nuisance cross-swap
Within each fixed context:
- train on realization subset;
- test unseen realizations;
- where lineage is clean, cross release/wind/context as robustness only.

Measure whether z clusters by source/task rather than plume realization.

### T0-C: flow-aligned memory probe
Without full model training, compare:
- no-memory/static pooled;
- generic recurrent;
- wind-relative/flow-aligned state update.

Primary endpoint:
held-out source rank and future-observation prediction under trajectory shifts.

## 9. T0 gates

T0_GO only if, across the four fixed S2X cases:
- task-sufficient latent improves or is non-inferior on source rank in >=3/4 cases;
- median source-rank improvement >0 or pairwise source AUC gain >=0.05;
- future-observation prediction improves over a source-only discriminative latent;
- nuisance realization classifier from z is reduced while source classifier remains strong.

If source identity cannot be retained independently of plume realization:
T0_FAIL_TASK_SUFFICIENCY_MAINLINE.

If M1 passes but flow-aligned memory adds no robust gain:
keep M1, drop M2.

No closed loop until T0 is positive.
