# PMFS 官方代码、冻结 O24 与论文协议审计

裁决：**O24 确有 2024-09-18 官方代码血统，但不是逐字未改的官方程序，也未获论文性能复现资格。它不是旧 H26 B4。** 必须同时承认源码移植修复、信息权限和运行协议三类差异；不能只说“全是参数差异”，也不能说“原算法全错了”。

## 1. 官方提交与依赖

固定作者提交为 `a8d5a764b7cbfc1d5d1887aebfe890e2c75d7533`，提交时间 2024-09-18。185 个所选源码/配置文件逐一与新读取的官方 Git blob 核验一致。它不是截至9月底的最后提交；当前 humble 历史上截至2024-09-30的最新祖先是 `22aefc7da63292863131c9d816644f3ae4c53a4d`（9月26日）。论文未披露实验提交，不能按日期自动认定其中之一就是论文实跑版。

DDA 与 StateMachine 有官方 gitlink；GADEN/GMRF 虽写在 .gitmodules，a8 树没有对应 gitlink，无法从 GSL 的 SHA 推出准确历史依赖。O24 的 GMRF 是已核对的2024-02-16候选核心，节点增加缺TF拒绝和被动记录。源码/编译环境身份有据，精确论文依赖仍未认证。

## 2. 真正改变了什么

- `PMFSLib.cpp`（观测命中图、confidence、候选初始化、风查询）、移动策略及前向/评分的主要运算保持作者 a8 实现；新增候选/后验/RNG导出不等于更换模型。
- 空观测窗口改为等待，地图未准备时不读取数组。这些是启动/输入行为修复，有触发条件，不能笼统叫“完全无行为影响”。
- `PMFS_utils.cpp` 的两个 `j<width` 改成 `j<height`，影响矩形地图均值、Top5输出和方差/声明；不直接改变给定候选图的源评分或后验。它属于普通数值修复，不是创新。
- 编译关闭GADEN真风，O24运行用局地GMRF；公开启动例默认真风。科学信息权限不同，不能只看launch参数。
- 原生随机均匀函数仍为按墙钟初始化的xxHash链，Gaussian为原生缓存。被动记录没有额外抽样，但OpenMP时序/线程归属未证明不变，不能保证完整路径逐位复现。

## 3. 论文与公开实现本来就有差别

论文VI-B规定概率算法源位置方差低于1 m²停止；300秒明确写给Surge-Cast。公开a8启动例同时写PMFS `maxSearchTime=300`、`convergence_thr=1.5`。O24沿用了该公开例，不等于严格论文停止协议。

源码方差是全自由格的 `Var(x)+Var(y)`，不是Top5%方差，也不是标准差。论文未进一步明确轴向/trace实现约定；只改数字不能证明完全同义。矩形循环修复和阈值变更要分别记录。

论文Eq6的Omega平方、未显式带D的图评分，以及年龄覆盖描述，与公开实现仍存在已知差别。本轮未补公式、未创造年龄半径，继续保留官方代码定义。因此新增1m停止实验只能叫O24论文停止协议对照，不能宣称公式全部按论文复现。

## 4. 实际同输入检验

直接抽取两版C++的 `sourceProbFromMaps`、`expectedValueSource`、`varianceSourcePosition`，输入保存的真实O24数据，替换的仅是ROS依赖容器。

- 25次源更新、3964张候选图：两版评分完全相同，与已保存原生评分最大相对差为0。
- A2方图均值、Top5和方差一致。矩形图有19次方差差异；所检保存更新的1m声明判断分歧为0。这不是完整前向/闭环逐位等价证明。

A2阳性对照保留。E3的F01、F04、F05、F06是同一物理世界上的算法重复，其中F01、F05终态仍低于1m²而定位错误，不能仅因1.5/1的区别作废。B2被二维候选域排除，只保留候选域诊断，不能作为合格同格推断失败。旧H26 B4不得改名O24。

## 5. A–E资产

已核对20个原始配置、各1803帧的历史数据及哈希/结构/源位置、风资产和实际地图。它们是本地再生成的历史气体，不是作者当年原始轨迹。生成状态文件18份只是新建默认MT19937的样本，不是实际发动机checkpoint；按用户修订，这不单独阻止完整场回放，但不能认定为独立随机重复。

原始a8地图按原生25×25全自由及可达性规则，10个源位置受支持、10个二维投影格被排除；后者不自动等于论文无效或不能输出邻近位置，必须单列适用域及最近合法距离。不能给真源单独开格。

B1/B3保存世界的风路径与a8配置不同。历史B实际消费地图比锁定原图多1320个障碍像素；当前原图文件又与a8字节一致，历史差异的具体生产时点/来源未完整保留，不能声称已唯一归因。历史E3缓存机器人z=.1，作者配置及合格O24 E3运行z=0。这些均在机器表中逐项登记。

## 6. 对历史结论的处理

- O24固定身份下的原生评分、观测失配和E3错源事实保留其已登记条件；不推广为论文全部版本的缺陷，不唯一归因为二维或风/时间。
- H24/H26/BIO A′的正反结果继续保留各自身份；更换版本标签不能将其提升为O24证据，也不能据此永久否决所有迁移机制。
- 论文统计性能仍未复现；任何单次对照只报告实测值与论文公开均值的描述性差别。

## 7. 执行边界

本文件对应三重只读审计和确定性同输入对照，零新气体世界、零新增候选传播。用户随后授权先整理空间，再运行A2论文停止对照，结果另见 `O24_PAPER_STOP_A2_20261024`。没有自动启动20×30次批处理；未对B/C/D/E输入差异做静默修正。
