# How V2 maps to the PMFS scientific question

## MEAN_FIELD_ONLY
The useful object is the complete source-conditioned mean encounter field.
PMFS improvement should focus on obtaining/calibrating the mean forward evidence
more faithfully. Do not build a stochastic-world-model mainline from R0.

## INSTANTANEOUS_JOINT_ONLY
Complete binary marginals are not enough, but cross-time realization identity
is not required. The missing object is an each-time spatial joint/count law
(overdispersion/correlation/mixture at a snapshot). Before any world-model
language, compare ordinary count/joint models under the same information
budget.

## CROSS_TIME_SIGNAL
Even after the complete each-time snapshot/count distributions are preserved,
destroying which observations belong to the same realization across time hurts
source identification. This is the first result that would specifically justify
studying a temporal joint stochastic state as a scientific object.

It is still only OPEN 18-source development evidence. Next step would be fresh
confirmation with locked new sources/realizations and a predictor that retains
the complete marginal field rather than replacing it with counts.

## INCONSISTENT_HOLD
Do not force a story. Keep the data and search for a representation/score whose
scientific target is explicit before spending on a model.
