核验日期：2026-09-12。范围：最多深入两篇正式论文，读取官方期刊正文的方法与公式；不访问 bank/VM，不运行新 forward，不修改历史 M1R。项目边界依据 `docs/M1R_CAUSAL_IMPLEMENTATION_STATUS_20260912.md` 和既有 `m1r_causal_repair_20260912` 证据。

**结论：找到两篇真实、正式发表于 2026 年的 Nature Communications 论文，能支持一个明确的跨域实验设计原则：用可控且物理含义已知的测量通道，使目标响应与背景/介质响应具有不同投影，再做反演。未找到可在现有 PMFS 单通道静态日志上直接继承的源可辨识定理；当前不能据此宣称一个因果主创新已经可实现或成立。** 两篇都属于 Nature Communications，不将其写成 Nature 或 Nature Physics。

## 1. 已核验的正式记录与原文机制

### 1.1 用不同观测通道分别测相关与响应

Alexa Herter, Frieder Lindel, Laura Gabriel, Stefan Yoshi Buhmann, Jérôme Faist. **Experimentally separating vacuum fluctuations from source radiation**. *Nature Communications* **17**, 2863 (2026)，正式发表 **2026-02-17**。[官方全文及发表记录](https://www.nature.com/articles/s41467-026-69142-4)。

原文 Results 定义真空相关与延迟响应：

```
C(r,r',t,t') = 1/2 <{E(r,t), E(r',t')}>
R(r,r',t,t') = (i/hbar) theta(t-t') <[E(r,t), E(r',t')]>
```

Methods Eq. (3)–(6) 实际用两束脉冲和两种波片组合，分别测得脉冲包络对 C、R 的积分投影；两路均四分之一波片与一路半波片/一路四分之一波片分别对应不同 quadrature。关键不是把同一条相关曲线事后分成对称与反对称部分，而是**物理改变检测通道**。实验在 4 K 的 ZnTe 中使用可控时间延迟、已知空间间隔及相位敏感平衡检测。上述公式与实现均由官方正文核验。[原文 Methods](https://www.nature.com/articles/s41467-026-69142-4)。

**本任务的迁移解释：**若只测到 `O1=a*C+b*R`，数据不足以分离两项；额外通道 `O2=c*C+d*R` 只有在其耦合系数物理可知且 `ad-bc != 0` 时才带来独立信息。这个二通道矩阵是本报告的简化类比，不是论文给 PMFS 的公式或定理。

**不可移植条件：**气体传感器没有电磁场 quadrature、量子算符对易关系和已知光锥；室内羽流通常处于非平衡输运。不能把 PMFS 的 persistence 写成真空项、source/context 写成源辐射项，也不能把 `wind–gas covariance` 当作论文中的 R。论文研究的是辐射与背景的物理分离，**没有解决任意介质中的未知空间气源定位**。其模型仍使用介质 Green 张量、脉冲包络及实验参数；它并非任意模型失配下的免校准源检测。

### 1.2 先用已知输入测出真实非线性算子，再利用其通道结构

Daixuan Wu, Zhen Yi, Jiaming Liang, et al. **Inverse theory of wavefront shaping in nonlinear scattering media**. *Nature Communications* **17**, 6011 (2026)，**2026-05-04** 发表，页面记录 version of record **2026-07-09**。[官方全文及发表记录](https://www.nature.com/articles/s41467-026-72537-y)。

原文 Results Eq. (1)、(3) 用二次散射张量表示二次谐波：

```
Eout_m = Ein^T T_m Ein = Ttilde_m vec(Ein Ein^T).
```

已测张量给出目标二次调制 V；通过 Autonne–Takagi 分解提取主通道，并投影为可施加的相位调制。Methods “Global characterization of scattering tensors”、Eq. (22) 用多组已知随机相位输入 W 和测得强度恢复 `Iout=|Ttilde W|^2`；论文实验使用 `K=4N^2` 的采样规模。**真实介质经受控激励测量，才获得可逆控制的响应结构**，不是仅凭物理先验填入一个张量。[官方方法](https://www.nature.com/articles/s41467-026-72537-y)。

**本任务的迁移解释：**PMFS 若想把介质/传感失配与源参数分开，需要某种来源已知、作用已知的校准观测来约束输运/传感算子，或一组具有独立耦合方向的新测量。对旧 hit-map 列做高阶展开，并不等价于测得这种算子。

**不可移植条件：**论文依赖可控制输入相位、可重复介质、光学非线性和开放散射的复高斯统计。无人机不能任意调制未知气源，也不能把移动轨迹当作光学输入场。其闭式聚焦增益不是源估计误差界。另须谨慎处理原文“full rank”表述：二次探针 `vec(xx^T)` 位于对称子空间，普通完整 `N^2` 表示存在重复分量；不得在 PMFS 中直接照抄 `N^2` 满秩作为可辨识证明。该代数限制为本报告独立核查，不否定论文实验。

## 2. 两篇共同启发的唯一条件性模块

候选概念为：**受控测量下消除已知 nuisance 的源响应对比**。这里的“受控”必须作用于实际采样过程或独立可验证的物理输入，不能对测得风数值做 `do(W)` 后声称改变真实流场。以下是本报告的候选推导，不是两篇原文已证明的气体算法，也不宣称新颖性成立。

设一次预先规定的短采样周期中，q 记录实际采样位置/入口状态，模型为

```
y(q) = a * f_s(q, eta) + D(q) beta + epsilon.
```

其中 s 是整次运行不变的源点；`eta` 是明确受限的输运/传感 nuisance；a 是该周期共享的正尺度；`D beta` 仅包含有独立依据的共同背景项。测量算子应设计成给源空间响应增加独立维度，同时使背景列可消去。取列正交的 U 满足 `U^T D=0`，再计算

```
z = U^T y,
v_s(eta) = U^T f_s(q,eta),
C_s = { v_s(eta)/||v_s(eta)|| : eta in the justified nuisance class,
                                             ||v_s(eta)|| > 0 }.
```

在此前提下 Dβ 被消去，共享正尺度不影响归一化方向。只有新测量使 `C_s` 与 `C_r` 不重叠，且测量噪声小于可核验的类间间隔时，才可能区分源 s 和 r。若两类重叠、响应为零、或源变换可完全被 eta 吸收，应保留歧义，不能选一个正则化最喜欢的源再称已识别。

这与旧共同非负 score 重权的区别在于：新测量 q 首先改变被观察的连续空间/响应信息，随后才消除有依据的背景项。**若仍使用相同旧列，U 不可能把完全相同的两列变得不同。** 普通 Bayes 在相同正确生成模型、相同新测量和 nuisance 处理下也可达到这些信息；因此该候选的可辩护贡献必须是可核验的观测设计/失配消除性质，而不是“使用了因果术语”。

### 一个可检查的代数实现例子，不是已获准算法

在等间隔的 A–B–B–A 采样中，若空间场在整个周期足够稳定、传感状态一致，并且公共背景严格为 `b0+b1*t`，则

```
d_AB = (y_A(t1)+y_A(t4)-y_B(t2)-y_B(t3))/2
     = a*(f_s(A)-f_s(B)) + noise.
```

正负相抵同时消掉常数和线性时间漂移。多个位置对才可能产生有方向的响应指纹；一个标量差异加未知 a 仍可能无法识别源。原理来自已知实验设计的代数，不来自气体的量子相位或光锥。现有 controller 没有执行这种配对周期，因此不可把保存的任意时间点拼接冒充实验。

这一例子至少需要：新采样动作或并行取样入口；传感记忆已知且可控制/校正；同周期源释放和输运变化满足声明模型；候选源空间响应对 nuisance 的可核验约束。非平衡羽流、传感器迟滞和周期内源强变化均会破坏等式。若需要暂停、冲洗、双入口或额外动作预算，应把它们作为新增观测成本正式验收。**这里没有请求运行或实施这些动作。**

## 3. 当前项目准入状态和最短证伪顺序

当前历史结果继续保留：M1R 在三个 House 中终点 2/3 改善、AUC 3/3 改善；不能因此免除源证据门。当前的 G0 仅证明现有局部风和浓度存在变异，不是上述新测量 q，也没有证明 `D`、a 或 eta 的适用性。完整 FOPDT/provider 的 H01 1/2 反例及 V3 两例弃权均继续有效。

1. **先检查物理采样可实施性与 nuisance 等式。** 需要明确哪一操作改变了观测的混合系数、哪些背景项确实共享，及它们如何独立校准。若这些条件只能由真源/未来/全场真值推出来，立即不准入。不要先跑新 forward 来掩盖条件缺失。
2. **只在第一项有依据后，检验新测量能否分开保存的 alias。** 使用完整候选支持；先冻结 q、算子和 nuisance 类，再让评价层读真源标签。若 `C_s` 与某竞争源的类相交，或差异只有数值噪声，直接 NO-GO。
3. **再比较同信息的普通 Bayes和匹配测量预算对照。** 必须在每个 House 分别证明源证据收益，并通过原 H01 SA/SB 失败例；移除难例、全部弃权、或只让真源绝对分数上涨均不算通过。之后才有资格讨论同期闭环与独立确认。

**最终判定：`PHYSICS_2026_MEASUREMENT_PRINCIPLE_SUPPORTED_BUT_PMFS_CAUSAL_MODULE_NOT_ADMITTED`。** 两篇提供了有实质内容的远领域借鉴；它们支持把目标放在新增可分离观测上，不能把当前有限日志变成已经成立的因果主创新。若要求保持当前全部传感/动作流程不变，则本次没有找到合适的物理定理或直接可用机制，应如实停在这个结论。

## 4. 对 A–B–B–A / B–A–A–B 候选的反驳审查

该候选比被动共同重权更合理，因为真实的新采样算子 q 可能产生旧 hit 列没有的连续空间差异；但“主动采样＋投影消背景”目前只能算条件性实验设计，不能因远领域引用而直接升级为主创新。

- **最小存在条件：**令 `d_sr=mu_s(q)-mu_r(q)`，存在 `c^T B=0` 且 `c^T d_sr!=0` 当且仅当 `rank([B,d_sr])>rank(B)`。这只是线性代数条件；若旧 alias 给出 d=0，任何 c 都无用。若 nuisance 维数耗尽观测自由度，也不存在有效对比。
- **传感 nuisance 未必候选共同：**仓库记录传感状态跨停止点延续，且传感记忆并非全部源错误的解释。特别是非线性/不对称传感器中，初始状态和释放/输运效应可能依赖输入与源；不能先假定一个与源无关的 B，再将这些列无损投影掉。对比的完整响应应包含实际移动和等待过程。
- **两种顺序不自动构成配对干预：**不同周期的羽流、源释放和传感初态可能不同。ABBA/BAAB 的差别可能只有这些时间效应；相同空间位置不能保证相同输运条件。需要独立依据支持周期内/周期间的共享 nuisance 范围，并将行程、等待、冲洗和恢复时间算入统一预算。
- **已有谱系必须承认：**`docs/PF_DEI_FULL_RECONSTRUCTION_FAILURES_AND_FINAL_METHOD_20260829.md` 已记录 V5 Active Probe 与信息驱动主动感知高度重叠，并可能放大错误 forward。其 `0/30` 指 fresh passive replay 无 ACCEPT，不能改写成 ABBA 实验已经 0/30 失败。ME-ACI 也已用未知释放/传感截距消除与 nuisance 边缘化。与 CCDE 的源/失配子空间投影在代数上高度同构；可能的新内容只能来自**新增可实施测量 q、独立建立的 nuisance 耦合结构，以及对保存源 alias 的真实排除**。
- **新颖性与因果资格：**DOE、差分/锁相测量和 nuisance 投影都是明显的先验邻域，本轮没有做完整优先权搜索，不能宣称该组合新颖。`do(position)` 的可控性也不等于 `do(source)` 已识别。即使上述秩条件成立，仍需正确/覆盖真实响应的源字典、跨 nuisance 分离和同输入普通 Bayes 对照。

所以这个候选可以作为下一项有界实验设计问题，但还不能作为已选定的因果算法实现。若其最强理论结果仅是 `c^T B=0`，那么当前证据更支持“既有方法的应用”，而不是独立主创新。
