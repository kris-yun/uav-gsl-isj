# C0 Pilot Charter — Controlled Source Interventions for M4

Date: 2026-09-23  
Branch: `research/causal-compositional-plume-world-model-v1`

## 0. Purpose

Before building any causal world model, create the smallest dataset that can distinguish:

- ordinary source-conditioned interpolation;
- genuine mechanism reuse under intervention.

Start with **source intervention only** because the existing GADEN generator already supports source position as independent parameters while holding occupancy and wind fixed.

Do not wait for a second wind field to begin C0.

## 1. Existing generator interface — verified

The existing script:

`reference/generate_hcmc_v1_realizations.sh`

invokes GADEN with independent parameters:

- `occupancy3D_data`;
- `wind_data`;
- `source_position_x`;
- `source_position_y`;
- `source_position_z`;
- `GADEN_RNG_SEED`.

Therefore a source intervention can be generated by changing only source position while freezing:
- House occupancy;
- wind directory;
- gas model parameters;
- simulation time;
- all other GADEN settings.

This is a valid controlled intervention.

## 2. First House

Use **House02** first.

Reasons:
- existing recovered data is hit-bearing / more informative than House01;
- existing evidence exposes a 27×39 PMFS grid with 631 free cells;
- canonical wind path is already known:
  `House02/gas_simulations/3,5-1_fast/.../wind`.

Do not use source truth to choose pilot positions.

## 3. Source-position selection

Select 4 source positions using a deterministic source-blind spatial design.

Preferred procedure:

1. use the House02 occupancy/free-space grid;
2. exclude cells within a predeclared wall-clearance threshold;
3. perform deterministic farthest-point sampling over the remaining free cells;
4. validate every chosen `(x,y,z)` against the actual 3-D GADEN occupancy before generation;
5. if a chosen point is invalid at the benchmark source height, move to the nearest valid cell using a deterministic rule.

The point-selection script must be committed before generation.

No point may be chosen using downstream truth rank.

## 4. Seeds

For each source position generate exactly two independent plume realizations.

Use fixed predeclared seeds, e.g.:

- seed A = 2026092301;
- seed B = 2026092302.

The exact seeds are arbitrary but must be frozen before outcomes are inspected.

## 5. Simulation length

Do NOT start with 1000 s formal runs.

First benchmark:

- 120 s or 180 s per source/seed;

provided it produces enough post-warmup snapshots for the chosen representation.

Record:
- wall clock;
- disk;
- peak memory;
- iteration count.

If this is cheap, expand only after C0 structure checks.

## 6. Outputs

Prefer compact online extraction.

At predeclared times export:

- concentration or hit-probability slice at sensor height;
- wind vector field at matching points;
- obstacle/free-space mask;
- source intervention label;
- plume seed;
- timestamp.

If M5 is also being screened, optionally export filament states in the same run.

Do not enable giant full-concentration serialization unless necessary.

## 7. C0 model comparison

Do not start with a large world model.

Use matched low-capacity baselines.

### Model A — monolithic
[
F(S,W,O) ightarrow H.
]

### Model B — explicit compositional source mechanism
[
H_{m env}=E(W,O)
]

[
H_s=D(H_{m env},Q_s).
]

Both should have approximately matched parameter counts.

The point is not architecture performance; it is whether separating source injection from environment transport improves intervention generalization.

## 8. C0 split

With four source interventions:

- train on S1, S2, S3;
- hold out S4 completely.

Evaluation:
- field/hit prediction on S4;
- PMFS candidate replay including S4 and neighboring source candidates.

This is **source-intervention generalization**, not yet full compositional source×wind generalization.

## 9. C0 hard metric

After all models/hyperparameters freeze:

- truth-containing source-candidate rank in held-out plume realizations.

Supporting:
- field error;
- hit/miss likelihood;
- spatial plume overlap.

No reconstruction metric can rescue source-rank failure.

## 10. Wind-intervention fork

Before C1, enumerate actual wind configurations under the same House02 canonical scenario.

### If ≥2 real wind fields already exist
Advance to a 2×2 sparse composition:

- S1-W1;
- S2-W1;
- S1-W2;
- hold out S2-W2.

### If only one real wind field exists
Do NOT invent arbitrary rotated/scaled wind as the headline causal test.

Options:
1. generate/reuse a second physically simulated wind configuration;
2. keep M4 on HOLD after source-only C0;
3. let M6/M3 proceed while wind intervention infrastructure is prepared.

## 11. C1 decisive test

M4 becomes a serious main candidate only if, on an unseen source×wind combination:

- compositional model beats matched monolithic model;
- source rank improves;
- source and wind module swaps produce physically expected changes;
- intervention-label shuffle destroys the advantage.

## 12. Kill conditions

Kill/demote M4 if:
- source-only factorization gives no generalization gain;
- no feasible real wind intervention can be obtained;
- monolithic model matches it on unseen combinations;
- module semantics fail intervention-specific tests;
- source-rank does not improve.
