# HCMC V1 — targeted prior-art collision screen

Date: 2026-09-22
Status: **NO DIRECT COLLISION FOUND IN TARGETED SCREEN / NOT AN EXHAUSTIVE NOVELTY PROOF**

## Exact novelty target

The claim is deliberately narrow:

> **source inference by hypothesis-conditioned conformity of measured and simulated turbulent-scalar multiscaling laws.**

Operationally, each candidate source defines a simulated support field. The candidate is judged by mismatch between measured and simulated multi-order structure-function scale slopes, not by a global plume statistic and not by temporal intermittency alone.

## What is already established and must NOT be claimed as new

Odor/gas-source-localization literature already establishes that turbulent plume statistics carry source information, including:

- odor encounter intermittency;
- burst / packet frequency;
- blank duration;
- intensity statistics;
- concentration variance, skewness and related plume descriptors;
- learned mappings from temporal odor statistics to source distance/location;
- information-theoretic or Bayesian source inference under turbulent plume models.

Therefore HCMC must not claim:
- "intermittency is useful for OSL";
- "turbulence statistics contain source information";
- "structure in a plume is more useful than a concentration gradient";
- "multiscale analysis itself is new".

## Targeted search families checked

Search combinations included:

- gas source localization + structure function + turbulence;
- odor source localization + structure function + multiscale;
- gas source localization + scaling exponent;
- odor source localization + multifractal / intermittency;
- source localization + turbulent-scalar structure function.

The returned OSL/GSL work centered on temporal intermittency, burst statistics, particle filtering, plume-search behavior, distributed sensing and standard Bayesian/information approaches.

No direct hit was found for:

- candidate-wise structure-function exponent spectra;
- measured-vs-simulated `zeta_p` conformity as a source-hypothesis score;
- source posterior construction from multi-order turbulent-scalar scaling-law mismatch.

## Near-neighbor literature that motivates but does not collide

1. OSL studies using intermittent burst timing/intensity:
   these operate on temporal encounter features and learn or infer source distance/location.

2. Biological olfaction work:
   frequency, blank duration and intermittency guide navigation decisions.

3. General turbulent-scalar physics:
   structure functions and anomalous/multiscaling exponents characterize cross-scale scalar statistics.

The HCMC transfer is specifically the bridge between (3) and source-hypothesis inference.

## Safe novelty wording

Preferred:

> We formulate gas-source hypotheses as competing turbulent-scalar generators and rank them by the conformity of their measured and simulated cross-scale structure-function laws.

Also defensible:

> HCMC replaces pointwise plume matching with candidate-conditioned multiscaling-law matching.

Avoid:

> We are the first to use intermittency for odor-source localization.
