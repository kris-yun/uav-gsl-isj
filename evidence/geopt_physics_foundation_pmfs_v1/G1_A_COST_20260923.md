## Scope and freeze

This is the required one-source 30/120/300 s benchmark. It uses the pre-registered
House02 training source 1 selected from geometry-only farthest-point sampling:
`(x,y,z)=(-1.942730188369751,-1.300879955291748,0.20)` m. The source is not
selected from gas values, posterior scores, or model output. Occupancy and the
physical wind directory are reused; CFD is not rerun.

The exact launcher is `research/geopt_physics_foundation_pmfs_v1/g1a_cost_benchmark.sh`.
It uses the audited HCMC seed-only build and `GADEN_RNG_SEED=2026092311`.
`save_results=0` was deliberate for this cost gate: zero `iteration_*` plume
frames were written. The run measures simulator compute and memory only; it is
not a field target or pilot result.

with about 90 MB RSS when result frames are disabled, so a compact field-slice
pilot is computationally practical. This does **not** pass G1-B: no spatial

House02 source plane (`z=0.20 m`), source split, and proven seed interface.
