# MAIN THESIS CANDIDATE — Semiparametric Active Deconfounding for PMFS

## 1. What is the "big idea"?

The main idea is **not** diffusion, not a new plume model, not DRO by itself, and not a replacement information reward.

The scientific thesis is:

> **Gas-source identity is a target variable observed through a nuisance transport environment. Active sensing should be designed to identify the source after explicitly removing the component of evidence that can be explained by transport nuisance.**

This is a semiparametric / nuisance-orthogonal experimental-design view of mobile gas-source localization.

Short name:

**Semiparametric Active Deconfounding (SAD) for GSL**

Alternative paper-facing wording if acronym is undesirable:

**Active Source–Transport Deconfounding**

## 2. Remote-field mother idea

### COLT 2025 — Experimental Design for Semiparametric Bandits

Kim, Kim & Oh, COLT 2025.

Core transferable principle:
- target reward component is structured;
- an unknown, potentially adversarial nuisance shift contaminates observations;
- ordinary linear-bandit design is no longer sufficient;
- experimental design and regression must be orthogonalized against nuisance.

### AISTATS 2026 — Best Arm Identification with Semiparametric Nuisance

Kim, AISTATS 2026.

Core transferable principle:
- the scientific goal is **identity selection** under nuisance, not nuisance estimation for its own sake;
- fixed-confidence target identification requires an orthogonalized design;
- sample allocation must be shaped by target differences after nuisance removal.

PMFS setting:
- target identity = source candidate \(s\);

## 3. PMFS-specific scientific pathology

Native PMFS movement values candidate disagreement:

\[
V_{\rm PMFS}(x)=\operatorname{Var}_{s\sim\pi}[h_s(x)].
\]

But \(h_s(x)\) is generated under one forward contract.

If transport changes,

\[
h_s(x;a)
\approx
h_s(x;0)+g_s(x)^Ta.
\]

Then part of the apparent between-source variation may be caused by transport nuisance rather than source identity.

Therefore:

> high simulator disagreement can be **transport-confounded evidence**.

This is a sharper scientific statement than "the model is uncertain."

## 4. New scientific object: source–transport confounding

For source pair \(s,r\),

\[
\Delta h_{sr}(x)=h_s(x)-h_r(x),
\]

\[
\Delta g_{sr}(x)=g_s(x)-g_r(x).
\]

Across measurement history \(B\):

\[
d_{sr,B}=[\Delta h_{sr}(x)]_{x\in B},
\]

\[
J_{sr,B}=[\Delta g_{sr}(x)^T]_{x\in B}.
\]

If

\[
d_{sr,B}\in\operatorname{col}(J_{sr,B}),
\]

then a transport perturbation can reproduce the source difference to first order.

The two source hypotheses are locally **transport-confounded** under that measurement set.

The identifiable source component is

\[
P^\perp_{J_{sr,B}}d_{sr,B}.
\]

This is the central scientific object.

## 5. Main module — Transport-Orthogonal Identification

Define

\[
D^\perp_{sr}(B)
=
\|P^\perp_{J_{sr,B}}d_{sr,B}\|^2.
\]

Aggregate over current PMFS source belief:

\[
\mathcal I_\perp(B)
=
\frac12
\sum_{s,r}\pi_s\pi_rD^\perp_{sr}(B).
\]

Select the next measurement by marginal gain:

\[
U_{\rm TO}(x|B)
=
\mathcal I_\perp(B\cup\{x\})
-
\mathcal I_\perp(B).
\]

### Critical reduction

If transport nuisance is absent,

\[
U_{\rm TO}(x|B)
=
\operatorname{Var}_{s\sim\pi}[h_s(x)].
\]

So PMFS is the zero-nuisance special case.

This is important for paper structure:
- we preserve PMFS's candidate-probability-map philosophy;
- we reinterpret and generalize its actual movement statistic.

## 6. Auxiliary module candidate A — nuisance-learning switch

A purely source-seeking action can be useless when all current source evidence is strongly transport-confounded.

Define a source-blind global confounding index, e.g.

\[
K_t
=
1-
\frac{\mathcal I_\perp(B_t)}
{\mathcal I_0(B_t)+\epsilon},
\]

where \(\mathcal I_0\) is nominal accumulated pairwise separation.

Interpretation:
- low \(K_t\): source information is mostly transport-invariant -> keep source-identification mode;
- high \(K_t\): source evidence is mostly explainable by transport -> collect a measurement that best reduces transport uncertainty / improves nuisance geometry.

This should not be implemented until the main transport-confounding phenomenon is observed on repaired Native data.

## 7. Auxiliary module candidate B — identifiability-aware declaration

PMFS may become numerically confident even when the leading source hypotheses remain transport-confounded.

A future declaration gate could require both:
- posterior/source-score concentration;
- sufficient transport-orthogonal separation from competing candidates.

This would turn "confidence" into **identifiable confidence**.

Do not implement yet; declaration/stopping has direct prior-art collisions and must be treated as an auxiliary only.

## 8. Why a PMFS-like drift-diffusion toy is still useful

The toy is only a **mechanism unit test**.

It asks:
- can an observation be nominally source-discriminative but fully nuisance-confounded?
- can a complementary second observation break that confounding?
- does orthogonal design recover source identity under a controlled mismatch?
- do destructive nulls kill the effect?

The toy is not:
- the big idea;
- the claimed novelty;
- the physical model proposed for real deployment.

If the controlled toy fails, the implementation is algebraically/mechanistically wrong and should be killed before House experiments.

## 9. Baseline-recovery evidence now supporting the problem formulation

Corrected R1 House01 seed0, same 20 observations and 87 candidate regions:

- A: frozen R2 source + GMRF + R2 params -> truth rank 48/87;
- B: frozen R2 source + ground-truth wind + R2 params -> 18/87;

This is one snapshot only and cannot establish method performance.

But it shows that source identity can change strongly with the forward contract while observations and source-candidate geometry are fixed.

That is consistent with the source–transport/forward-nuisance confounding hypothesis.

## 10. Novelty boundaries

Do NOT claim:
- first nuisance-aware GSL;
- first robust GSL;
- first active model discrimination;
- first sequential OED with nuisance;
- first DRO gas sensing;
- first multi-model odor localization;
- first Rényi/information-driven OSL.

The novelty, if evidence supports it, must be narrower:

> explicitly decomposing PMFS candidate-source disagreement into transport-confounded and transport-orthogonal components and actively collecting complementary mobile measurements that make source identity identifiable after quotienting/removing the shared transport nuisance tangent.

## 11. Hard data gates

### Gate G0 — source-blind confounding exists
On repaired Native data:
- estimate \(g_s(x)\) from controlled transport perturbations;
- show nontrivial fractions of high-native-variance cells have high transport confounding;
- show sensitivity estimates are reproducible.

If not, kill.

### Gate G1 — complementary measurements break confounding
Find measurement pairs/short histories where:
- each individual cell is highly confounded;
- joint transport-orthogonal source separation is positive.

If this only exists in a synthetic toy and not in House data, demote.

### Gate G2 — truth-source rank
Equal measurement budget:
- Native PMFS movement;
- transport-orthogonal movement;
- random/reachable control.

Primary endpoint:
- truth-containing candidate rank.

Independent plume realizations required.

### Gate G3 — mechanism null
Destroy candidate-specific transport sensitivity geometry while preserving marginal scales.

The advantage must disappear.
