# 唯一候选：局部风创新的源条件响应对比

日期：2026-09-12。分析基线：`75b3adca0cf79930add72cffa6d399721ab42e28`。本文件只提出一个可实现、可立即被本地反例淘汰的机制；没有修改 `cer_ratio_m1`、controller、旧证据或研究判决，没有访问 VM 或保护 rawbank。

**结论：新增信息的入口存在，但输入可用不等于机制可行；该候选目前不纳入因果算法实现。** 候选针对“同一静止位置的局部风变化如何先于浓度变化”，而非再拟合整条浓度曲线。其非平凡假设是可测局部风创新对未建模输运残差具有条件正交性，并且候选源对这种变化的响应方向不同。现有证据尚未建立这两点；尤其不能把 GMRF 残差、风差分或候选共享随机数直接当作外生干预。若这两项缺失，不能给该模块加“因果主创新”标签。

## 1. 为什么只考虑这个机制

保存的 H01/H02 alias 是旧表示的同列：不同源在每个已记录位置的 `legacy_hit_probability` 完全相等。对这列做共同重权不能制造区别。底座却另有未进入该列的信息：连续浓度、静止/移动状态、带时间戳的局部风。源位置可能改变**浓度对风变化的有向响应**，即使它们具有相同的长期 hit frequency。

这是一项待测量的可能性，不是“有风变化便可定位”的结论。该候选不重新提交既有完整气丝时序 + FOPDT 的峰值/尾部拟合，也不用 V3 oracle 半径；旧 H01 SA/SB 的 1/2 失败继续作为必过反例。

历史 `cer_ratio_m1` 在 H01/H02 的终点收益及三个 House 的 AUC 收益原样保留。新模块首先独立输出影子响应对比；未通过下面的源证据门前，不乘进历史 M1R 后验，也不以新的离线胜负覆盖历史闭环结果。

## 2. 一个明确的数学对象

记 `F_i^-` 为第 i 个风观测到来前已知的历史，包括至此前的浓度、位姿、已执行动作、局部风和占据地图。初始只取同一打印坐标、`is_moving=0`、采样连续的静止片段。该限制由可部署动作状态定义，不依赖真源、气体 hit 或最终表现；最终脚本不读取回放 iteration 字段。

定义

```
z_i = w_i - m_i(F_i^-)
r_i,h = log(1 + y_i+h / 1 ppm) - a_i,h(F_i^-)
```

`m` 和 `a` 必须在 i 之前拟合/更新；在线只在 `i+h <= 当前时刻` 后计入这对样本，不使用未来风场或未来路线。原型的 `m=w_i-1` 只能称风增量基线，不能称已验证 martingale innovation。`a` 是候选共同的过去浓度预测；拟合时不能接收源标签或 candidate id。`h` 是统一物理时间网格，不能按 House 挑峰；尚未冻结合法响应窗口前不得报告调参后的 PASS。

对固定点源 s，定义响应导数

```
b_i,h(s; J) = d/d delta E[ log(1 + Y_i+h / 1 ppm)
                           | do(S=s), F_i^-,
                             do(Flow = Flow_base + J_i delta) ] at delta=0 .
```

这里 `J_i` 必须把二维真实流场扰动参数映射为空间场；它不是“改一个局部读数”的操作。真实场 `Flow` 影响局部测风 W，也影响气体；局部 W 是观测而非可随意操控的真实场。`J_i` 及风观测模型目前缺失，因此 `b(s;J)` 只是明确暴露假设的待实现对象。后文简写 `b(s)`。它不是旧 `p_sim(s,i)` 的权重。地图决定气体可达性，已有路径决定采样点；源点在整段联合响应中固定，不能每个气丝重抽。区域候选的合法处理是先对每个固定点算整段响应/证据，再按区域内先验边缘化，不能把代表中心解释成精确真源。

一个直接的观测同分布反例是：模型 A 为 `W=U, Y=beta*W+epsilon`；模型 B 为 `W=U, Y=beta*U+epsilon`。二者产生相同的 W、Y 观测分布，但在 A 中改变 W 会改变 Y，在 B 中只改变 W 的读数不会改变 Y。因而 wind–gas covariance、响应回归或风增量满秩都无法单独识别 `do(W)` 效应，更不能自动识别真实场干预。即使这个问题被解决，源坐标仍须通过经验证的 source-conditioned 响应字典进入，不能由协方差推导来源方向。

若在被使用的响应窗口内存在有效局部线性表示

```
r_i,h = q * b_i,h(s*)^T z_i + u_i,h,
E[z_i u_i,h | F_i^-] = 0,
Q_i = E[z_i z_i^T | F_i^-],
```

则对任一候选可检验矩

```
g_i,h(s,q) = z_i r_i,h - q * Q_i b_i,h(s).
```

未知正增益 q 必须用事先固定、所有候选相同的 nuisance 规则处理；例如在较早完整静止片段拟合一个飞行级正增益，在随后完整片段评分，不能每个源、每个事件任意拟合增益。若实际释放率/传感机制不能支持这个共享增益假设，则本机制在此设定不成立；不要通过增加任意事件级自由度救回。

实现可输出各静止片段的平均矩及候选残差范数，作为**源响应失配分数**。未建立相关性/尺度校准前，不把该范数或其指数称为 proper likelihood、Bayes factor 或 anytime-valid e-value，也不据它直接生成高置信后验。重叠窗口和同一片段内采样不作为独立重复。

它能在何种意义上破除 alias：旧概率相等不推出 `b(s)=b(r)`。如果新响应向量在剔除共同 nuisance 后不成相同的正比例，且观测矩具有非零响应，源 s 与 r 才可能被该信息区别。必须直接保存所有旧 alias 的新向量及差值见证。只靠数值 epsilon、坐标先验、叶面积或对全零响应加 floor 不算破除。

## 3. 与普通生成式 Bayes 的实际区别

现有 `counterfactual_likelihood.score_candidates` 对同 provider 的整条预测浓度经 FOPDT 后计算高斯工作似然并边缘化成员；均值幅度和衰减尾错配能主导其排序。本候选试图只使用风创新与后续浓度残差的条件矩，允许一类**与合法创新正交的平均响应失配**。因此它不是旧 Gaussian likelihood 改温度，也不是 source/context 重权。

这不构成“比 Bayes 更因果”的定理。正确建模同一风响应、相关误差和 nuisance 的普通贝叶斯同样能利用该信息。可能的研究贡献只能是：证明明确的半参数失配类下该响应对比仍有效，同时给出可实施的假设检查和跨条件验证。若唯一收益是换了更好的 forward 或观测特征，则按改进观测模型报告；若同输入普通生成式 Bayes及匹配降频对照完全解释收益，则不能声称独立因果贡献。2026 理论审查文件中的论文没有替本候选证明上述矩条件。

## 6. 最短可证伪门，按顺序停止

**G1：先审查干预映射与条件正交性的准入。** 必须先给出独立可核验的局部测风–真实空间流场干预映射 `J_i`、观测模型及条件正交性的依据，明确排除第 2 节的观测同分布混杂反例需要什么额外信息。当前本地输入可用门不能提供这些识别条件。可用全部合格静止片段按时间预序检查过去可预测残留，并以同位姿内反向时间响应和源盲破坏配对作负对照；但任何一次“未拒绝”都不能证明外生性。若映射/正交性仍无依据，或残差明显保留风相关的输运/传感误差，状态保持 `CAUSAL_ADMISSION_NOT_ESTABLISHED`，不实现因果响应核、不运行新 forward，也不靠后续匹配得分绕过。重复采样不能当独立统计显著性。

**G2：只有 G1 准入后，才生成 source-blind 响应字典。** 固定地图、三个 House 的合法历史、已获准的导数算子和 nuisance 规则，对保存的完整候选集合生成新响应。先冻结参数及响应文件哈希，再由独立评价层读真源区域与旧 alias。若 H01/H02 含真源叶仍有相同响应的竞争叶，或差异在 nuisance 消除后为零，判 `NO_GO_RESPONSE_ALIAS_PERSISTS`。每一源都只剩零响应或所有数据都被移除也失败。不得以该门的可编程性反过来代替 G1 所缺的识别依据。

**G3：同输入、同支持的最小源证据比较。** 唯一核对三个 House 各自的真源区域 proper score、真源–最佳错源对比及旧 alias 区分。只有在矩分数已校准成合法预测分布后才计算 proper score；未校准阶段只能报告响应残差/排序，不宣布源证据门 PASS。对照必须包含旧 M1R、同导数/浓度输入的普通生成式 Bayes，以及与新模块相同停止片段/更新次数/实际覆盖的 M1R。须另保留已失败的 H01 SA/SB 同代码对照，不能避开 SA。各 House 都要提供实际非零证据覆盖，全部弃权不算成功。

G3 通过后才有理由接统一参数闭环。固定轨迹离线结果不能保证保留 H01/H02 的真实闭环收益；这个保留要求必须由同期配对运行检验。当前没有运行授权范围外的新 House/seed，也没有独立确认资产，最终主创新目标仍未完成。

## 7. 当前必须明确承认的具体缺口

1. **局部风干预映射缺失。** 当地风读数变化不唯一规定沿源到传感器通路的场变化。`Flow→W` 和 `Flow→gas` 的观测结构，不能被替换为 `do(W)→gas`。把传感器单元扰动、全场同向扰动或 GMRF 更新当作同一干预会给出不同 `b(s)`；现有日志不能自动选择正确一种。需要独立可核验的观测/干预映射，而非默认继续调风 provider。
2. **条件正交性未建立。** 没有来源独立的外生风工具。未观测上游状态可以同时影响当地风和后续气体，传感器噪声也可能让“风创新”只有测量噪声而没有输运刺激。满秩 G0 不解决它。
3. **源响应差异未计算。** 当前未有 `b(s)` 的 alias 见证；不能根据源坐标不同就宣称响应不同。若对应响应只有正比例差异，而 q 未知，该机制仍不识别。
4. **分数尺度和跨域假设未校准。** 条件矩不是自动 likelihood；飞行级正增益、源变化率、局部线性窗口及传感时延的适用性尚未建立。不能重用 evaluator-only V3 半径代替它们。

因此本文件的准确状态为 `CAUSAL_ADMISSION_NOT_ESTABLISHED`，该候选目前不纳入因果算法实现；输入可用不等于机制可行。已完成的是可部署信息提取层及可复现 G0；没有选定可部署源修复，更没有主创新 PASS。下一项真正缺失的是 G1 所要求的局部测风–真实流场干预映射与条件正交性依据，然后才有资格讨论 G2 的源响应字典/alias 检验；若无法给出，该候选应被淘汰，不再将更多 provider 运行作为默认续命手段。
