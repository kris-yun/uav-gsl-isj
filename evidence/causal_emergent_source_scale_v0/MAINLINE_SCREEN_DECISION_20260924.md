# Mainline Screening Decision after R0

Date: 2026-09-24

Decision:

- **Track B — causal emergence / multiscale source identifiability: ADVANCE as provisional main-innovation candidate.**
- **Track A — temporal encounter history: retain as auxiliary candidate.**

## Why B advances

R0 establishes encounter/support statistics as reproducible.

The project's repeated failures also show a second robust pattern:
fine source-cell rank can change while nearby source-basin evidence survives.

Causal-emergence / effective-information theory addresses whether a coarser state description can be more informationally effective than a noisy microscopic description.

An exploratory 18-source R0 hierarchy screen shows a non-monotonic held-out normalized source-information pattern under spatial coarse-graining, and spatially coherent partitions strongly outperform random groupings of identical sizes.

This signal is not confirmatory but is specific enough to justify a >=143-source gate design.

## Why A is not discarded

A discrete first-order encounter-history model carries more held-out source information than independent encounter probabilities on the R0 panel, and destroying temporal order degrades its advantage.

Thus event history is real information.

However:
- current observations are only 10 snapshots, not continuous event times;
- first observed detection is not true first passage;
- snapshot support is not encounter count;
- recent olfactory-search literature already treats encounter statistics and spatiotemporal correlation as important.

Therefore A is currently better positioned as a temporal auxiliary module than as the paper's single main scientific idea.

## Main scientific thesis under test

> Turbulent plume randomness may make PMFS's finest source cells over-resolved relative to the information actually present in encounter observations. A causal-emergence criterion can identify a source macrostate scale at which source information is maximally reproducible, then retain that macro uncertainty in the PMFS probability map instead of forcing a falsely precise cell estimate.

This thesis is now allowed to proceed to gate design, not yet to experiment execution.
