## 3. Primary far-domain theory

### Turbulent transport

X. M. de Wit et al.,
“Data-driven Mori–Zwanzig modeling of Lagrangian particle dynamics in turbulent flows,”
PNAS 123(13), 2026.
DOI: `10.1073/pnas.2525390123`.

This work explicitly treats reduced turbulent Lagrangian dynamics as depending on current resolved variables plus their past history, with unresolved orthogonal dynamics generated by omitted degrees of freedom.

## 4. GSL / plume prior-art screen

Targeted literature searches through 2026-09-24 found **no direct match** for Mori–Zwanzig projection or memory-kernel minimization in gas/odor/plume source localization.

This is a screening result, not proof of exhaustive novelty.

Important adjacent occupied areas:

### Sequential deep probabilistic GSL — occupied

S. Kim et al.,
“Deep Probabilistic Indoor Gas Source Localization via Physical Dependency-Guided Sequential Inference,”
arXiv:2608.16221, 2026.

It sequentially conditions inferred wind/concentration fields to estimate a source posterior. Therefore “sequential inference” or “using intermediate physical fields” cannot be our novelty.

### Spatial / behavioral memory in OSL — occupied

Bio-inspired navigation papers already use spatial memory/search memory. Therefore “robot remembers where it has been” cannot be our novelty.

### Generalized Langevin plume simulation — occupied as forward modeling

Atmospheric Lagrangian dispersion models such as QES-Plume use generalized Langevin equations to model particle/velocity dispersion.

Therefore “use a Langevin equation for plume simulation” cannot be our novelty.

The candidate distinction is:

> Apply Mori–Zwanzig/GME **at the inference representation level** to the partially observed plume, explicitly testing whether the memory induced by eliminating turbulent degrees of freedom contains source-stable information across independent realizations.

## 5. Why Wavelet Scattering is HOLD, not mainline

2025 astronomy and applied-harmonic-analysis work shows scattering statistics can capture non-Gaussian multiscale structure, but GSL already contains wavelet-based source-localization architectures and simple multiscale summaries did not provide a robust offline rescue here.

Wavelet/scattering may become an auxiliary observable encoder only if MZ M0/M1 establishes the memory mechanism first.

## 6. Why the first M0 test is deliberately simple

M0 uses a finite-memory autoregressive reduced dynamics rather than a neural network.

Reason:

- if even a controlled finite-memory model cannot turn temporal memory into held-out source identity, immediately escalating to a neural sequence model would be an engineering rescue;
- if memory is load-bearing, M1 can then introduce the actual second-order innovation: an MZ source collective variable / memory-kernel objective.
