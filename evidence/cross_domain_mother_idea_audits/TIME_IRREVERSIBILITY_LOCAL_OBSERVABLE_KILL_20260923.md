# Time-irreversibility candidate-local observable kill test

Date: 2026-09-23  
Branch: `research/cross-domain-mother-idea-audits-20260923`  
Status: **NO-GO FOR DIRECT PMFS LOCAL-OBSERVABLE TRANSFER**

## Question

After the long-trajectory time-arrow phenomenon passed a necessary-phenomenon screen, test the only justified PMFS mapping:

> At the actual StopAndMeasure/source-update location, does the causal measured block contain time-direction information that can be compared with the source-hypothesis local internal sequence?

No source truth, future pose, future gas, or GADEN field is used in this gate.

## Frozen PMFS observation contract

The accepted independent HCMC runs use:

- `measurement_settle_samples=0`;
- `measurement_block_samples=10`;
- gas threshold from the common algorithm default `th_gas_present=0.1` because the frozen runner does not override it.

The PMFS source update therefore receives a ten-sample current measurement block, not the long trajectory used in the earlier CStar phenomenon screen.

Thus every actual update block has a constant binary sequence:

- five runs: `0000000000`;

## Decisive mechanism result

For a binary hit observable, every antisymmetric transition current

`J_ij(lag) = P(i -> j) - P(j -> i)`

is exactly zero for every valid lag in all six first-update blocks.

Therefore the measured side contains no local time-arrow signal for the candidate-local same-observable comparison.

Any candidate ranking obtained by minimizing distance to this zero current would merely prefer candidates with low local dynamical activity. It would not be evidence that a source hypothesis reproduces a measured source-conditioned arrow of time.

## Analog-gas rescue check

Using raw ppm instead of the hit observable does not rescue the intended mother mechanism cleanly.

At the H03 source-update location:

- the ground-truth gas channel is zero throughout the relevant stationary tail;
- the measured sensor channel remains positive and decays toward zero;
- the simulator reports `sensor=asymmetric`.

Hence a substantial time direction in the analog measured sequence can be generated by the sensor response memory itself while no plume gas is present at the robot.

The Native candidate replay exposes particle/cell occupancy, not the same asymmetric sensor output dynamics. Comparing analog sensor arrow to candidate occupancy arrow would therefore compare different observables/dynamical systems unless a separate observation model were introduced.

That would be a new rescue construction rather than the predeclared same-observable kill test.

## Decision

**DIRECT CANDIDATE-LOCAL TIME-IRREVERSIBILITY TRANSFER = NO-GO.**

This is stronger than a weak localization result:

1. the long-trajectory time-arrow phenomenon does exist;
2. but the actual PMFS local update contract collapses the binary time-arrow to zero in all six accepted independent first updates;
3. the residual analog time direction is contaminated by asymmetric sensor memory in at least H03;
4. therefore the intended mechanism is not available at the point where it would replace Native PMFS candidate evidence.

Do not tune lag sets, state bins, thresholds, or block length on these six runs to rescue the line.

Do not build a posterior or closed-loop method from this transfer.

## Consequence for the three-layer research protocol

Layer 1 is failed for this specific PMFS mapping, so Layers 2 and 3 are not entered.

Resume the mother-idea search under a genuinely different source-information mechanism while keeping the PMFS probability-map chassis.
