# M5 Physical Gap Audit — Native PMFS vs High-Fidelity GADEN Filament Dynamics

Date: 2026-09-23  
Branch: \`research/generative-lagrangian-filament-world-model-v1\`

## Decision

\`PHYSICAL MODEL GAP = REAL / STRUCTURAL\`

M5 is not attempting to learn the same transition equation already used by PMFS.

Official PMFS and GADEN differ structurally in dimensionality, obstacle interaction and gas physics.

## 1. Native PMFS filament dynamics

Official PMFS \`Simulations::moveFilament()\`:

\[
v_t
=
w_{2D}(X_t)
+
\epsilon_t,
\qquad
\epsilon_t\sim\mathcal N(0,\sigma^2I).
\]

Then:

\[
X_{t+\Delta}
=
X_t+\Delta v_t.
\]

State:
- 2-D position only.

No explicit:
- vertical motion;
- buoyancy;
- filament sigma state;
- age-dependent spreading state.

## 2. PMFS obstacle interaction

\`moveAlongPath()\` checks whether the path intersects non-free cells.

In the active implementation, the filament advances in small increments until the next increment would enter an obstacle, then backs out that increment.

Thus a blocked component of motion is effectively stopped.

The PMFS source contains the explicit comment that a better solution would be a **deflection** so filaments move along the wall rather than stopping.

This is a concrete known approximation in the native forward model.

## 3. GADEN filament dynamics

High-fidelity GADEN \`RunningSimulation::MoveSingleFilament()\` contains:

### 3-D advection

\[
X' = X + W_{3D}(X)\Delta t.
\]

### Buoyancy / gravity

Vertical motion includes a gas-property/concentration-dependent terminal buoyancy velocity.

### Stochastic displacement

Independent Gaussian perturbations are added in x/y/z.

### Dynamic filament width

\[
\sigma_{t+\Delta}
=
\sigma_t
+
\frac{\gamma}{2\sigma_t}\Delta.
\]

This changes concentration contribution with filament age.

### Outlet dynamics

Filaments entering outlet cells are removed.

## 4. GADEN obstacle deflection

GADEN \`StepTowards()\` does not simply stop at a wall.

When a proposed path enters an obstacle:

1. restore the previous valid position;
2. estimate the wall/cell normal;
3. compute the remaining desired displacement;
4. remove its normal component:
   \[
   d_{\rm tangent}
   =
   d-
   {\rm proj}_{n}(d);
   \]
5. recursively advance along the tangential remainder.

Thus obstacle interaction produces wall-following/deflected trajectories.

This mechanism is absent from Native PMFS.

## 5. Why this matters for source localization

Candidate-source identity is inferred through the spatial hit patterns generated by these trajectories.

Near obstacles/doorways/recirculation structures, PMFS can predict:

- where a filament stops;
- which corridor it enters;
- how frequently a cell is hit;

differently from a higher-fidelity trajectory model.

Therefore a transport world model can affect source identity even if the same wind field is used.

## 6. M5 learning target revised

Do not learn raw displacement from zero.

Use PMFS as the low-fidelity reference:

\[
X^{PMFS}_{t+\Delta}
=
\Phi_{PMFS}(X_t,W,O,\xi).
\]

Learn a stochastic high-fidelity correction:

\[
\boxed{
X^{HF}_{t+\Delta}
=
X^{PMFS}_{t+\Delta}
+
R_\theta(
X_t,W,O,\sigma,\Delta,\xi
)
}
\]

or learn the high-fidelity source-agnostic transition conditioned on the same physical context while always retaining PMFS as a baseline/anchor.

The residual should be largest where the simplified physics is inadequate:
- near walls;
- near outlets/openings;
- regions with 3-D/vertical transport;
- age/spread-dependent regimes.

## 7. Crucial anti-overclaim baseline

Because GADEN's detailed physics are known, M5 must compare against a hand-coded stronger physical reference.

At minimum include:
- PMFS native;
- PMFS + explicit GADEN-like wall deflection where feasible;
- simple heteroscedastic stochastic corrector;
- learned generative transport.

If copying one known wall-deflection rule produces the full source-rank gain, the generative-world-model claim is unnecessary.

## 8. Scientific opportunity

The strongest version of M5 is therefore:

> **distill a reusable high-fidelity, source-agnostic stochastic transport world model from Lagrangian simulation/experimental trajectories, and use counterfactual source injection to make high-fidelity candidate replay feasible inside PMFS.**

This is not “replace one PMFS formula with a neural network.”

It changes the source-forward object from:
- a hand-coded low-fidelity random walk

to:
- a learned distribution over high-fidelity physical transport trajectories.

## 9. Current verdict

Physical justification: **stronger after source-code audit**.

Main unresolved gate remains empirical:
- whether the high-fidelity correction is learnable/source-relevant;
- whether a generative model is required beyond explicit known-physics corrections.
