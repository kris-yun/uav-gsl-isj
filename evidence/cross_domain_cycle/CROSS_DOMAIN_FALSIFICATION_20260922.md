## A. Causal-emergence / dynamical-reversibility transfer

### Mother theory
- 2025 npj Complexity: *Dynamical reversibility and a new theory of causal emergence based on SVD*, DOI 10.1038/s44260-025-00028-0.
- Public implementation: https://github.com/try6/dynamic_reversity_based_on_SVD
- 2025 *Causal Emergence 2.0: Quantifying emergent complexity*, arXiv:2503.13395.
- Scite citation-neighborhood check found multiple 2025–2026 follow-ons, including SVD-based causal emergence for Gaussian iterative systems and 2026 Patterns papers on emergent complexity / causal-emergence landscape.

### Second-innovation proxy
Treat candidate sources as interventions and their simulated hit-probability fields as a source→effect channel. Build a candidate-response matrix, spatially standardize candidate fields, extract macro response modes by SVD, choose the macro dimension source-blind by stable rank, and score the measured response in that macro response space.

### Observation-erasure control
For H02_R2026092211, the measured field was replaced by the zero vector while retaining only the candidate bank and source-blind macro construction.

- real measured-field macro endpoint: **0.9207755383 m**
- zero-observation macro endpoint: **0.9207755383 m**

They are exactly equal at reported precision.

H01_R2026092201 is an additional warning: its recorded measured hit-probability field is effectively constant (std ≈ 9.7e-17), yet the macro proxy still produces a structured ranking.

### Decision
**NO-GO for this causal-emergence proxy.**

Reason: the apparent source-localization gain can be generated by candidate-bank/partition geometry even after measured source evidence is erased. This violates the post-HCMC rule that geometry-only/candidate-only evidence must not explain the gain.

The causal-emergence mother theory is not rejected in general; this particular static SVD source-channel transfer is rejected.

## B. Mori–Zwanzig residual-memory transfer

### Mother theory
Scite 2025–2026 screen identified:
- PNAS 2026, *Data-driven Mori–Zwanzig modeling of Lagrangian particle dynamics in turbulent flows*, DOI 10.1073/pnas.2525390123.
- 2026, *Learning turbulent transport via Mori--Zwanzig graph neural networks*, arXiv:2606.14918.
- 2026, *Partial Observation of Linear Systems with the Mori-Zwanzig Formalism*, arXiv:2606.23341.
- 2025 Proc. Royal Society A, *Mori–Zwanzig latent space Koopman closure for nonlinear autoencoder*, DOI 10.1098/rspa.2024.0259.

The common scientific idea is that projecting an unresolved high-dimensional turbulent system onto observed variables induces a resolved term plus non-Markovian memory and orthogonal fluctuation.

### Second-innovation proxy tested
For each source candidate:
1. sample its static simulated hit-probability field along the actual 1500-step robot trajectory;
2. transform and standardize the measured gas trace and candidate expected trace;
3. project the measured trace onto the candidate trace;
4. compute how much fixed dyadic-lag residual memory is removed relative to the unconditioned measured trace;
5. rank candidate leaves by memory removal;
6. evaluate the same development top-5% endpoint clone.

Fixed principal lag family: 1,2,4,8,16,32,64 samples. H01_R1 was also checked with shorter/longer dyadic families and remained poor.

### New-plume results so far
- H01_R2026092201: 5.7811 m vs Native 4.5967 m — worse
- H01_R2026092202: 4.6149 m vs 4.2738 m — worse
- H02_R2026092211: 4.0878 m vs 6.9341 m — better
- H02_R2026092212: 5.1035 m vs 4.3579 m — worse
- H03_R2026092221: 4.3556 m vs 7.9527 m — better

True-source leaf ranks were not consistently high (examples: H01_R1 ~0.31, H02_R1 ~0.19, H03_R1 ~0.58), so endpoint improvements in isolated Houses are not sufficient evidence of a source-identifying memory mechanism.

### Decision
**NO-GO for the lightweight residual-memory transfer.**

Do not tune lag ranges or combine it with instantaneous fit after viewing these development outcomes. A future Mori–Zwanzig route would need a genuinely candidate-conditioned temporal counterfactual model / memory kernel, not this static-field-along-path surrogate.

## Process lesson
Two apparently promising cross-domain theories were not promoted merely because their mother theory is prestigious or their old-data effect is large.

The new standard remains:
- observation-erasure / geometry-only control;
- old + independent-plume development sets;
- source-position/wind interventions;
- destructive structure controls;
- only then a fresh, never-viewed holdout.
