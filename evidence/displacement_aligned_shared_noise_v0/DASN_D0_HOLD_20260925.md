# DASN D0 Result — Shared Localization Error Exists, Displacement Specificity Not Yet Separable

Date: 2026-09-25

Decision:

**D0_HOLD_SHARED_ERROR_NOT_DISPLACEMENT_SPECIFIC**

No new simulation, final target, or inference-model development is authorized.

## 1. Data and frozen split

Only the completed D1R House02/W2 reference bank was used:

- 168 source cells;
- 16 independent realizations/source;
- 10 frozen times x 30 probes;
- raw concentration transformed by log(1+ppm) for ordinary readouts.

Probe views:

- A = 1-based odd probes, 15 probes;
- B = 1-based even probes, 15 probes;
- all 10 times retained.

Directions:

- forward: reps 1..8 train, reps 9..16 diagnostic;
- reverse: reps 9..16 train, reps 1..8 diagnostic.

Reverse is a dependent robustness check, not fresh confirmation.

## 2. Same-realization shared localization error is real

Primary statistic:

T = average over sources of the trace of the source-centered cross-view localization-error covariance.

### Ridge coordinate readout

Forward:

- T = **0.02564 m²**;
- pairing-destruction 95% null upper bound ≈ **0.00808 m²**;
- Monte-Carlo p < **2e-4**;
- median A/B localization error ≈ **0.459 / 0.632 m**.

Reverse:

- T = **0.02147 m²**;
- pairing-destruction 95% null upper bound ≈ **0.00764 m²**;
- Monte-Carlo p < **2e-4**.

### Shrinkage-LDA posterior-mean readout

Forward:

- T = **0.02786 m²**;
- pairing-destruction 95% null upper bound ≈ **0.00489 m²**;
- Monte-Carlo p < **2e-4**;
- median A/B localization error ≈ **0.274 / 0.456 m**.

Reverse:

- T = **0.02568 m²**;
- pairing-destruction 95% null upper bound ≈ **0.00428 m²**;
- Monte-Carlo p < **2e-4**.

Therefore the effect is not a single-decoder artifact.

## 3. Common amplitude/gain does not explain it

Residualizing source-centered localization error against each realization's common log total concentration leaves the paired signal essentially intact.

Examples:

- Ridge forward: 0.02564 -> **0.02602 m²**;
- Ridge reverse: 0.02147 -> **0.02158 m²**;
- LDA forward: 0.02786 -> **0.02479 m²**;
- LDA reverse: 0.02568 -> **0.02180 m²**.

Thus an ordinary one-dimensional common plume-gain explanation is insufficient.

## 4. Boundary effects do not create the signal

The complete 168-source panel contains 110 internal and 58 boundary cells.

Shared error remains positive when internal sources are analyzed alone.

Examples:

- Ridge forward internal T = **0.02390 m²**;
- Ridge reverse internal T = **0.02191 m²**;
- LDA forward internal T = **0.02318 m²**;
- LDA reverse internal T = **0.02895 m²**.

No boundary-source deletion was used.

## 5. Direct local source-sensitivity projection is strongly paired

Using training references only, estimate the local source-response Jacobian J_s from adjacent source means in the frozen grid.

Project each diagnostic observation residual onto span(J_s) with a fixed relative Tikhonov ratio 1e-2.

Forward:

- displacement-projection T = **0.20064 m²**;
- pairing-null 95% upper ≈ **0.02745 m²**.

Reverse:

- displacement-projection T = **0.37652 m²**;
- pairing-null 95% upper ≈ **0.08295 m²**.

The signal remains after common-gain residualization:

- forward ≈ **0.18444 m²**;
- reverse ≈ **0.35823 m²**.

Using the wrong source's Jacobian strongly reduces the raw effect:

- forward true J: 0.20064;
  source-shuffled-J median ≈ 0.0560, q95 ≈ 0.1210;
- reverse true J: 0.37652;
  source-shuffled-J median ≈ 0.0847, q95 ≈ 0.1744.

Thus local source sensitivity is relevant in the raw residual geometry.

## 6. But a generic low-rank plume factor explains most of the apparent displacement component

A generic PCA residual factor model is learned from the training half only.

With only **2 latent factors** — the same dimensionality as source displacement — it explains about **52%** of residual observation variance.

After removing those two generic factors, the local-J displacement statistic falls sharply:

- forward: 0.20064 -> **0.05325 m²**;
- reverse: 0.37652 -> **0.06204 m²**.

The residual pairing signal remains above its pairing-destruction null.

However the stronger displacement-specific test is no longer stable across split directions.

After factor-2 removal, compare the true local J_s against source-shuffled Jacobians:

- forward:
  - true J residual T = **0.05325 m²**;
  - shuffled-J median ≈ **0.01234**;
  - shuffled-J q95 ≈ **0.07765**;
  - Monte-Carlo p ≈ **0.10**;
- reverse:
  - true J residual T = **0.06204 m²**;
  - shuffled-J median ≈ **0.01148**;
  - shuffled-J q95 ≈ **0.04938**;
  - Monte-Carlo p ≈ **0.017**.

Therefore the claim that the shared stochastic component is specifically tied to local source-displacement sensitivity does not survive the strongest equal-dimension generic-factor attack in both directions.

## 7. Scientific interpretation

What D1R now supports robustly:

> the same plume realization creates a reproducible shared localization error across disjoint probe subsets.

What D1R does **not** yet uniquely identify:

> that this shared localization error is a distinct two-dimensional source-displacement-like noise mechanism rather than a projection of ordinary low-rank plume variability.

This is exactly the non-identifiability warning in the Pro reassessment:

a nonzero displacement-like covariance component is not sufficient evidence when ordinary residual structure can reproduce it.

## 8. Decision

Under the frozen DASN mechanism logic:

**D0_HOLD_SHARED_ERROR_NOT_DISPLACEMENT_SPECIFIC**

Reason:

- shared paired error: PASS;
- readout robustness: PASS;
- common-gain control: PASS;
- boundary control: PASS;
- pairing destruction: PASS;
- raw local-J relevance: PASS;
- equal-dimension generic-factor / local-J specificity across both directions: **NOT PASS**.

Therefore:

- do not formulate a new covariance likelihood;
- do not generate final targets;
- do not request new GADEN runs;
- do not call this an information-limiting physical noise mode;
- retain the shared-error phenomenon as a mechanistic clue.

## 9. Next implication

The mechanism-first reassessment has now done its job:

the strongest currently reproducible fact is **shared localization error**, while the specific displacement-noise decomposition remains non-identifiable.

Any next mainline must make a prediction that separates:
- generic low-rank plume factors,
from
- truly source-location-relevant stochastic structure,

before a new model family is built.
