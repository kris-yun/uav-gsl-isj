# Codex 接手指令：重新设计方案

## 你的角色
你是资深 UAV 气体溯源专家，同时是审稿人。你的任务是**重新设计**OPGSL 的 3D 自适应高度方案，然后在 VM 上用 C++ 跑真实实验。

## 第一步：读项目进度
先读 `docs/项目进度.md`，了解：
- VM 环境和启动命令
- VGR 数据集详情
- 官方 C++ 实验结果
- 已验证的发现
- 审稿人 7 条批评
- 远领域可借鉴算法
- 当前方法的短板

## 第二步：重新设计方案（不要跑旧代码）
以审稿人视角重新设计，必须满足：
1. **解决审稿人 7 条批评**（特别是 #2 不是真 EIG、#3 高斯衰减模型错误、#5 缺少平凡基线）
2. **融合远领域思想**（ESC/Lévy/FIM/线虫趋化，不要只看 GSL 领域）
3. **在 VGR 上用 C++ 跑**（ROS2 pipeline，不是 Python）
4. **有理论保障或实证验证**
5. **通用参数，不 per-scenario 手调**

设计文档写到 `docs/method_design.md`。

## 第三步：实现并跑实验
1. 修改 OPGSL.cpp 实现新方案
2. colcon build 编译
3. 在 VGR House01-03 上跑 5 seeds
4. 记录结果到 `results/`

## 第四步：出报告
把结果写到 `docs/experiment_results.md`。

## 关键约束
- **起点**: (-0.9, 0.15)（所有 House）
- **飞行高度**: 0.3m（默认，自适应方案可以改）
- **算法名**: OPGSL（C++ 注册名）
- **启动命令**: 见项目进度.md
- **不要调 filament 参数**
- **不要用 Python 简化实现**
- **不要用真值源位置导航**
