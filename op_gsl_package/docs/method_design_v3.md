## 1. 问题定义

**输入**: UAV 搭载单点气体传感器 + 风速仪，在未知 3D 室内环境中定位未知高度的气体源。
**输出**: 源的 3D 位置估计 (x̂, ŷ, ẑ)。
**约束**: 源高度未知，不能使用真值导航，所有参数通用默认。

### 1.1 真正未解决的科学问题

近五年文献 (2021-2026) 中，UAV 气体源定位的 **源高度未知问题** 是真正未解决的：

| 方法 | 年份 | 高度假设 | 局限 |
|------|------|---------|------|
| PMFS (Ojeda) | 2024 | 已知 | 内部仿真依赖，不处理高度 |
| GrGSL (Monroy) | 2023 | 忽略 | 2D 梯度跟随 |
| SurgeCast (Burgues) | 2021 | 忽略 | 固定高度状态机 |
| 3D Klinotaxis (ISJ 2025) | 2025 | 未知 | 仅仿真，无理论保证，固定菜单 |

**唯一考虑高度的 competitor: 3D Klinotaxis (ISJ 2025)**
- 生物启发的 klinotaxis，从 9 个固定高度选
- 无理论保证，仅仿真验证
- 我们的优势：连续高度空间 + ESC 理论保证 + 显著层物理动机

## 2. 方法架构

### 2.1 三阶段状态机

```
Phase 0: EXPLORE (无气体检测)
  ├── 水平: Lévy 飞行探索 (μ=2)
  ├── 垂直: Lévy 高度采样 (μ=2)
  └── 转换: 首次检测到 gas > threshold → Phase 1

Phase 1: CALIBRATE (首次检测到气体)
  ├── 水平: 停留在当前位置附近
  ├── 垂直: 6 点线性扫描 + 显著层检测
  └── 转换: 扫描完成 → Phase 2

Phase 2: TRACK (残差 ESC 梯度跟踪)
  ├── 水平: 化学趋向导航
  ├── 垂直: 残差 ESC 连续梯度跟踪
  └── 转化: 连续 15 步无 hit → 回到 Phase 0 (带 60s 冷却)
```

## 3. 残差 ESC (核心创新)

### 3.1 问题

标准 ESC 假设 y = f(u)，其中 u 是控制输入（高度 z），y 是标量输出（浓度 c）。
但在 GSL 中，浓度是 c(x,y,z)——三维空间坐标的函数。水平运动导致的浓度变化远大于高度变化。

### 3.2 解决方案

从观测浓度中减去水平场估计器的预测值：

```
r(t) = c_obs(t) - c_hat(x_t, y_t)
```

其中 c_hat(x,y) 由 WR-SFE（Wind-Relative Spatial Field Estimator）提供。
残差 r(t) 近似只依赖于高度 z，满足 ESC 的单输入假设。

### 3.3 ESC 更新方程

```
高通滤波:  η(t) = α_h · η(t-1) + (r(t) - r(t-1))    // 标准 Krstic 形式
解调:      ξ(t) = η(t) · sin(ωt) · 2/a(t)
低通滤波:  Ĝ(t) = α_l · Ĝ(t-1) + (1-α_l) · ξ(t)
高度更新:  ẑ(t+1) = ẑ(t) + K · Ĝ(t)
振幅衰减:  a(t+1) = a(t) · (1-λ),  λ=0.005
```

## 5. 审稿人可能的质疑及回应

**Q1: ESC 假设违反——水平运动干扰梯度估计**
A: 残差 ESC 通过减去水平场估计器的预测值，隔离高度依赖的信号分量。WR-SFE 在每个观测点更新，提供实时的水平场基线。

**Q2: Lévy 飞行在高度搜索中的物理动机**
A: μ=2 的 Lévy 分布是 3D 稀疏目标搜索的数学最优（Stromboli 2026 证明）。高度空间是 1D 的，Lévy 飞行的无标度特性确保同时覆盖所有高度尺度。

**Q3: 显著层扫描的物理基础**
A: 借鉴 WMO 探空仪显著层选择（60 年全球实战），检测浓度剖面中偏离线性插值的点，对应大气热分层导致的气体聚集层。

**Q4: 消融实验是否充分？**
A: 5 种配置（A0-A4）覆盖所有模块组合。每个配置 15 runs（3 House × 5 seeds），使用 Wilcoxon 秩和检验和 Cohen's d 效应量。
