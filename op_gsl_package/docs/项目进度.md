## 关键决策记录
1. **ESC → BO+GP**: ESC(2003)太老，审稿人会质疑创新性。BO+GP用UCB选高度。
2. **BOED → IG-AI**: BOED是常见框架，审稿人会说"又是BOED"。IG-AI来自计算神经科学×信息几何，跨域距离远，有定理可证。
3. **模块堆砌 → 统一机制**: 5个模块不是独立的，是同一组测地线方程在不同Fisher度量下的特例。
