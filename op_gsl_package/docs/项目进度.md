## 八、当前方法的短板（必须正视）

1. **2D 平面上 GrGSL 比我们好**（VGR: GrGSL 0.52m vs Ours 1.07m）
2. **EIG 高度选择只是从固定菜单选**，不是真正的连续自适应
3. **高斯垂直衰减假设物理上不对**（室内有天花板反射、热分层、障碍物通道效应）
4. **ESC 高度跟踪（Python 测试）效果一般**（1.47m，不如固定 z=2.0 的 1.15m）
5. **OPGSL 官方 C++ 结果不稳定**（seed 0: 0.88m, seed 1/2: 6.2-6.4m）
