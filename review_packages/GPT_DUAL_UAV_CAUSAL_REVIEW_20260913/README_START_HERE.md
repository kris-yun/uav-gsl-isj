# GPT审阅入口：PMFS因果主创新与双无人机路线

日期：2026-09-13

## 请先看结论

当前证据支持“无人机位置动作会改变气体响应”，也支持H03数据存在可检测的时间不可逆性；但它们都没有把响应唯一对应到真实泄漏源。单无人机、单气体通道、连续未知泄漏、不允许源开关、不建立候选响应库的条件下，已经测试的同数据变换均未形成跨数据集因果源定位。

拟讨论的新路线是：使用两架无人机作为两个同步移动接收器。它尚未实现、尚未运行，也不应被当作已确定方案。核心审阅问题是：它是否真正补上缺失的空间识别信息，以及怎样与经典单机PMFS进行公平比较。

## 当前研究目标

目标不是让后验更平滑或偶然降低一个终点误差，而是建立一个审稿人可接受的主创新：

1. 机制必须在贝叶斯累积前改变候选源之间的相对证据；
2. 改善必须跨环境成立，不能只在H01/H02有效、H03退化；
3. 机制必须有可核查的2026年跨领域理论来源，并明确二次创新；
4. 小门槛先用失败的H03验证，不运行完整House/seed组合；
5. 理论、代码、预注册和原始证据必须先冻结并上传，再运行实验。

## 已有正证据

- M1R确实修改了PMFS内部候选似然，而不是只修后验。
- 暴露的House123 seed12开发结果：终点误差在H01/H02改善、H03退化，即2/3；时间积分AUC在3/3改善。
- Rank-2与DPISC物理位置干预在不同运输条件下产生了方向一致的源效应。
- CFIR正确方向明显优于符号反转对照，说明H03数据中存在可检测的全局时间箭头。

这些结果只能证明“效应存在”，不能证明“效应唯一识别真源”。

## 设备与真实任务边界

- 真实任务：工厂突发连续泄漏，不能要求关闭或调制未知源。
- 现有设备：FKT-AQI-L，扩散式，约1 Hz上报，T90不超过约15 s；最多配置六种气体，可记录历史数据并提供API。
- 小规模实飞可能使用挥发酒精；烟饼对应颗粒物实验，不应与酒精/VOC混为同一物理通道。
- 用户有大型无人机并可让两台无人机同时飞。把两台完整设备在同一架无人机上拉开1--2 m不现实；把第二台固定在户外地面又很可能长期测不到羽流。

## 拟审阅路线

两架无人机同时搭载同类VOC设备：一架执行搜索，另一架保持由地图和局部风决定的源盲相对队形。两路同步数据构成不同空间位置的同一泄漏观测。

公平性通过三组实验拆分：

1. `S1-PMFS`：一架无人机、经典PMFS；
2. `D2-PMFS`：两架无人机、标准PMFS联合两路观测；
3. `D2-CAUSAL`：与D2-PMFS完全相同的两架无人机、轨迹、气体数据和时长，只替换为候选级因果联合证据。

硬件增益由`D2-PMFS - S1-PMFS`衡量；算法增益必须由`D2-CAUSAL - D2-PMFS`证明。论文若采用该路线，研究范围将从单无人机PMFS改为双无人机协同因果源定位。
